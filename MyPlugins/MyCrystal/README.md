# My Crystal（マイ・クリスタル）

入ってきた音を短く切って（スプライス）、**音程を変えたり逆再生したりしながら重ねていく**エコーです。
くり返すたびに 1 オクターブずつ上がっていく「きらきらした響き」や、逆再生のエコー、声の後ろの「幽霊の声」が作れます。
本人の Mac にある市販のグラニュラー・エコーに実際に音を通して測り、粒の切り方・つなぎ方・くり返しの減り方・フィルター・色付け・GATE/DUCK を同じ動きに合わせ込んだオリジナルです（名前・見た目・プリセット名は別物）。

- 種類: エフェクト（AU）。Logic では「Audio Units → MyPlugins → My Crystal」
- 遅れ: なし（元の音は遅れません）
- 使い方の基本: **センド（Aux）に挿して MIX 100 %**。曲の中の数か所で、センド量をオートメーションで上げて使う「飛び道具」です
- リードボーカルに直接挿しっぱなしにすると、言葉がうねって埋もれます。センドで使い、下の GATE/DUCK か VOCAL DUCK で歌の間は下げてください

## 上の帯

| ボタン | 何をする |
|---|---|
| **REVERSE / FORWARD** | 切った音を逆再生するか、そのまま再生するか |
| **SYNC** | ON = SPLICE と DELAY を音符（1/4 など）で決める。Logic のテンポについていき、粒も拍の区切りで頭から始まる |
| **ANALOG** | ON = やわらかい色付け（大きい音ほど丸く潰れる）。OFF = DIGITAL（何も足さない。−0.1 dB で頭打ち） |
| **TWEAK** | 細かい設定の段を出す・しまう |
| **FACTORY PRESETS** | 内蔵プリセット 15 個 |

## 1 段目: つまみ

| つまみ | 何をする | 目安 |
|---|---|---|
| INPUT | エフェクトに入る音量（元の音は変わらない）。上げると ANALOG の色付けが強くなる | 0 dB |
| **PITCH** | 粒の音程（±3 オクターブ）。ふだんは半音ごとに止まる。**shift を押しながら回すとセント単位** | +12 st（1 オクターブ上）、+7（5 度）、+5（4 度）、−12 |
| **SPLICE** | 1 回に切る長さ。短い（30 ms 以下）= 金属的なザラザラ、長い = はっきりしたエコー。だいたいこの長さがエコーの間隔になる | 300〜700 ms（SYNC なら 1/4） |
| **DELAY** | 粒が鳴るまでの追加の待ち時間 | 0〜500 ms |
| **RECYCLE** | くり返しの量。PITCH を変えていると、くり返すたびにさらに上がる（下がる）。100 % ではずっと鳴り続ける | 20〜70 % |
| MIX | 元の音と効果の割合（センドなら 100 %） | センド 100 %／直接挿すなら 15〜35 % |
| OUTPUT | 効果の音量（元の音は変わらない） | 0 dB |

## 2 段目: 粒の様子と GATE / DUCK

- **GRAINS** … 左（L）と右（R）で、今どの辺りの音を読んでいるか。色の付いた帯 = 粒が読む範囲（SPLICE の幅、DELAY の分だけ右へ）
- **THRESHOLD** … GATE / DUCK が反応する大きさ。まわりの輪 = 入ってくる音の大きさ（赤 = 越えている）
- **GATE / DUCK** … 真ん中 = 切り
  - 右へ回す = **DUCK**: 弾いている・歌っている間（THRESHOLD より大きい間）は効果をその dB だけ下げる。止まると効果が出てくる
  - 左へ回す = **GATE**: 大きく弾いた時だけ効果が出る

## TWEAK（細かい設定）

| つまみ | 何をする |
|---|---|
| PITCH OFFSET | 左を下げ、右を上げる量（セント）。少し（5〜15）でステレオの厚み |
| SPLICE OFFSET | 右の SPLICE を左より短くする（%）。左右で粒がずれて広がる |
| DELAY OFFSET | 右の DELAY を左より短くする（%） |
| SMOOTHING | 粒のつなぎ目の長さ。上げるほど、ぼやけてなめらか（1 粒の半分まで） |
| LOW CUT / HIGH CUT | 効果の低い音・高い音を削る（12 dB/oct）。くり返しの中にあるので、**くり返すたびに細く・暗くなる** |
| ATTACK / RELEASE | GATE / DUCK が効くまでの時間・戻るまでの時間 |
| DUCK MODE | GATE / DUCK で下げるもの: Output = 聞こえる効果 / Recycle = くり返しだけ / Both = 両方 |
| FEEDBACK | Mixed = 左右を混ぜてくり返す / Dual = 左右別々 / Ping-Pong = くり返しが左右に跳ねる |

## 画面のいちばん下

- **LINK 欄**: ボーカルに挿した Fader Pilot と同じ LINK 番号にすると、歌っている間だけ効果を VOCAL DUCK の dB だけ下げます
- **GAIN MATCH**（プリセット欄の左端）: ON にすると、挿しても・つまみを回しても音量が変わらないようにそろえます（既定 OFF。センドで MIX 100 % のときは比べる元がないので効きません）
- **プリセット欄**: 自分のプリセットの保存・読み込み、UNDO / REDO

## おすすめ設定

1. **歌の最後の一語を逆再生で飛ばす**: センドに挿して FACTORY → Vocal Reverse Throw。フレーズの終わりだけ、センド量をオートメーションで上げる
2. **クリーンギターをきらきらに（シマー）**: Guitar Octave Shimmer。後ろに Lumen Rooms を挿すと、シマーリバーブの代わりになる
3. **パッドのように 5 度を重ねる**: Fifth Pad（センド）
4. **サビ前の吸い込み**: Reverse Swell。サビの直前の 1 小節だけセンドを上げる
5. **弾き終わった時だけ広がる**: Bloom When You Stop（DUCK で、弾いている間は引っ込む）
6. **声を加工っぽく太く**（デチューン＝音程を少しずらすこと。ずれ方はいつも同じ）: Detune Double を直接挿して MIX 30〜40 %。自然な 2 本録りの感じは Twin Take

## 注意

- **調に合わない音程（+1・+3 など）は和音とぶつかります**。迷ったら ±12・+7・+5
- RECYCLE を上げて PITCH を上に積むと、高い音がどんどん痛くなります。HIGH CUT を 4〜6 kHz に下げると落ち着きます。下に積むと低い音がこもるので LOW CUT を上げてください
- PITCH OFFSET・SPLICE OFFSET を大きくすると、モノラルで聞いたときに音が薄くなる所があります（左右がずれているため）
- RECYCLE 100 % ではいつまでも鳴ります（DIGITAL では 0 dBFS で止まる）。止めたいときは RECYCLE を下げてください
- FEEDBACK が **Mixed のとき、RECYCLE 70 % を超えると、真ん中に定位した音のくり返しが少しずつ大きくなって止まらない**ことがあります（左右を足して戻すため。本物と同じ）。長く回すなら 70 % 以下か Dual に
- 効果の音は、元の音より 0.6 ms だけ遅れて出ます（エコーなので聞いて分かる差ではありません）

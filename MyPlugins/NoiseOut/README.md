# Noise Out（ノイズ・アウト）

録った音から **ブーンというハム（HUM）・サーッという雑音（NOISE）・部屋の響き（ROOM）・口のピチャ音／息／吹かれ（VOICE FIX）** を取るプラグインです。
本人の Mac にある市販の音声修復ソフトのうち 6 つ（ハム取り・声のノイズ取り・響き取り・口のクリック取り・息の調整・吹かれ取り）に、
作った試験音を実際に通して測り（約 1,500 通り）、下げる量・効き始めの速さ・周波数ごとの効き方を同じ動きに合わせ込んだオリジナルです（名前・見た目は別物）。

- 種類: エフェクト（AU）。Logic では「Audio Units → MyPlugins → Noise Out」
- 遅れ: 6144 サンプル（48 kHz で 0.128 秒）。息や吹かれを「少し先まで聴いてから」決めるため、1.0（0.043 秒）より増えました。
  Logic が自動でずらすので、ミックスでは気になりません。**録音しながらのモニターには向きません**（録り終えた音に使う）
- 挿す場所: ボーカル・ナレーション・ギターやベースのライン録りなど、**1 つの楽器のトラック**。
  ミックス全体やステレオのバスに ROOM を使うと、乾いて痩せた音になります
- 並びは固定で **HUM → 口のピチャ音 → NOISE・ROOM・息・吹かれ（この 4 つは同時に）**。使わないものは OFF（最初は NOISE だけ ON）

## 画面の見方

- 下に 4 つの段（**HUM・NOISE・ROOM・VOICE FIX**）と右の OUTPUT。各段の左上のボタンで ON / OFF。OFF の段のつまみは薄くなります
- **DETAIL**（各段の右上）: 押すと、その段のつまみが細かい設定に入れ替わります（もう一度押すと戻る）。ふだんは触らなくて大丈夫です
  - 細かい設定を初期値から変えていると、DETAIL の字が段の色になり、右に点が付きます
  - **DETAIL をダブルクリックすると、その段の細かい設定だけ初期値に戻ります**
- 上のグラフ:

| 色 | 何を表すか |
|---|---|
| 灰色の山 | 入ってくる音（左の目盛り、dB） |
| 緑の線 | NOISE が「ここまでは雑音」とみなしている大きさ（ADAPTIVE は自動で追った値、LEARNED は覚えた形） |
| 上から垂れる赤 | いまどれだけ下げているか（右の目盛り、0〜−40 dB） |
| 黄色の縦線 | HUM が削っている周波数（ハムの倍音） |

## HUM（ハム取り）

ノッチ（とても細い谷）を、ハムの周波数とその倍音に並べて削ります。直流のずれ（DC オフセット）も一緒に取ります。
本物のハム取り（固定ノッチの設定）と同じ形で、波形の差は −80 dB（聞き分けられない）まで合わせました。

| つまみ | 何をする | 目安 |
|---|---|---|
| **HUM**（ボタン） | ON / OFF | ハムがあるときだけ |
| **AUTO / 50 Hz / 60 Hz** | AUTO = ハムの周波数を自分で探す（鳴り始めから 1〜2 秒）。見つからない間は何もしません | 迷ったら AUTO |
| REDUCTION | 谷の深さ。60 dB でハムは消えます。浅くすると谷も細くなる | 60 dB（本物の初期値） |
| HARMONICS | 削る倍音の数（1 = 基本だけ） | ハム 8、アンプのジーという音 12〜16 |
| DETAIL → WIDTH (Q) | 谷の幅（Q 300〜2000）。Q を上げると細く（音楽に触れにくいが、効くまで少し時間がかかる）、下げると太く（少し揺れるハムも取れるが、倍音の間の音も削れる。Q 300 で HARMONICS 8 本なら最大 −5 dB、12 本 −9 dB、16 本 −13 dB） | Q 1000（本物の初期値、つまみの真ん中） |

- 東日本の電源は 50 Hz、西日本は 60 Hz。AUTO はそのすぐ近く（50 Hz・60 Hz の ±0.3 Hz）だけを探します。
  この範囲には楽器の音程が入らないので、ベースの低い音（B1 = 61.7 Hz など）をハムと間違えません
- 周波数がぶれずに 0.5 秒以上続く山だけをハムとみなします（声や響きの倍音は動くので選ばれません）
- 50 / 60 Hz より上の倍音だけのジー音も、強い倍音が 4 本以上あれば見つけます。それでも「searching」のままなら、50 Hz か 60 Hz を選んでください
- 一度見つけた周波数は曲と一緒に保存されるので、開き直したとき・再生し直したときもすぐ効きます
- HUM の ON / OFF と HARMONICS の変更は、プチッと鳴らないように 0.04 秒かけて切り替わります
- REDUCTION を浅く（30 dB 以下）すると、谷が効ききるまで数秒かかり、ハムが急に止まった所（リージョンの終わりなど）の後ろに少しハムが鳴き残ります。
  本物の同じ設定も同じ動きです。ふだんは REDUCTION 60 dB・WIDTH 1000 のままがおすすめ（止まって 2 秒後には聞こえない大きさ）

## NOISE（ノイズ取り）

エアコン・パソコンのファン・サーッという音など、**ずっと鳴っている雑音**を下げます。本物の声用ノイズ取りに合わせました。

| つまみ | 何をする | 目安 |
|---|---|---|
| **NOISE**（ボタン） | ON / OFF | |
| **MUSIC / DIALOGUE** | MUSIC = 歌・楽器向け（伸ばした音や響きの尾を自然に残す）。DIALOGUE = 話し声向け（言葉の切れ目で素早く効く。1.0 と同じ音） | 歌・楽器は MUSIC（初期）、ナレーションは DIALOGUE |
| **ADAPTIVE / LEARNED** | ADAPTIVE = 静かな所の音から雑音を自動で追う（本物の初期設定と同じ）。LEARNED = LEARN で覚えた雑音の形を使う | ふだんは ADAPTIVE |
| **LEARN**（ボタン） | 押してから、**声の入っていない雑音だけの所**を再生すると、3 秒聴いて自動で終わり、LEARNED に切り替わります。もう一度押すとそこで終わり | 曲の頭の無音部分など |
| REDUCTION | 雑音を下げる量（dB）。上げすぎると水の中のような音（ピロピロ）になります | 8〜14 dB（初期 12） |
| THRESHOLD | どこまでを雑音とみなすか。+ にするとたくさん取る、− にすると小さい声を守る | 0 |
| DETAIL → GENTLE | 下げ方をなめらかにして、ピロピロを出にくくする（少しだけ取る量が減る）。本物の「Gentle」に合わせた | 音楽で水っぽく感じたら |

- ADAPTIVE は、**長く伸ばした声や持続音を少しずつ雑音と覚えて下げる**ことがあります。8 秒伸ばした母音の最後で:
  MUSIC は本物と同じ −1.6 dB。DIALOGUE は本物が −7.1 dB まで削るのに対して Noise Out は −1.8 dB（本物のこの癖はまねていません）。
  気になるときは LEARN を使うか、下の LINK で Fader Pilot とつなぐと防げます
- 覚えた形は曲と一緒に保存されます
- ADAPTIVE で追った雑音の大きさは、再生を止めたり位置を移動したりしても覚えたままです（最初からやり直すのは、プラグインを入れ直したときだけ）

## ROOM（部屋鳴り取り）

声のあとに残る部屋の響き（お風呂っぽさ）を下げます。1.1 で本物の響き取りの動きに近い方式に作り直しました。
少し前に鳴った音から「今ごろ残っているはずの響き」を予想して、その分だけ下げます。

| つまみ | 何をする | 目安 |
|---|---|---|
| **ROOM**（ボタン） | ON / OFF | 部屋鳴りが気になるときだけ |
| REDUCTION | 響きを下げる量。**マイナスにすると逆に響きを足します** | 6〜10（初期 10） |
| TAIL | 部屋の響きの長さ（秒）。長くするほど、後ろのほうの響きまで取ります | 狭い部屋 0.5〜1 秒、広い部屋 1.5〜3 秒 |
| DETAIL → LOW / LOW-MID / HIGH-MID / HIGH | 帯域ごとの取る強さ（6 = ふつう、0 = その帯域の響きは残す、10 = かなり強く取る。本物と同じく 6 から少し動かすだけでよく効きます）。だいたい 〜600 Hz / 600 Hz〜1.5 kHz / 1.5〜4 kHz / 4 kHz〜 | こもった狭い部屋は LOW-MID を上げる、お風呂っぽい高い響きは HIGH を上げる、声が痩せたら LOW を下げる |

## VOICE FIX（口のピチャ音・息・吹かれ）

声・ナレーション用の 3 つです。どれも最初は OFF。ボタンで ON にして、つまみ 1 本で強さを決めます。

| つまみ | 何をする | 目安 |
|---|---|---|
| **MOUTH**（ボタン）＋ SENSITIVITY | 口のピチャ音・唇の「チッ」という、とても短い高い音を取る。上げるほど小さいピチャ音も取る | 4（初期）。上げすぎると t・k の子音が丸くなる |
| **BREATH**（ボタン）＋ REDUCTION | フレーズの間の息を下げる（dB）。深くしても息の端は少し残ります（本物と同じ） | 8〜12 dB（初期 12） |
| **PLOSIVE**（ボタン）＋ STRENGTH | 「パ」「バ」でマイクに息が当たった「ボフッ」という低い音を取る | 5（初期） |
| DETAIL → MOUTH FREQ SKEW | − = 低めの鈍いピチャ音も探す、+ = 高く鋭いものだけ | 0 |
| DETAIL → BREATH SENSITIVITY | 上げるほど息とみなす音が増える（上げすぎると「す」「しゅ」も下がる） | 5 |
| DETAIL → PLOSIVE SENSITIVITY | 上げるほど小さい吹かれも取る | 5 |
| DETAIL → PLOSIVE FREQ LIMIT | この周波数より下だけを削る。大きいボフッは上げる、声の低い所を残したいなら下げる | 200 Hz |

- 段の下に、直近 10 秒に取ったピチャ音の数と、いま息・吹かれを何 dB 下げているかが出ます
- PLOSIVE は、吹かれのない所でも声の 180 Hz より下を少し下げます（初期設定で約 −7 dB。本物も同じ動き）。声の低い所を残したいときは DETAIL の FREQ LIMIT を下げてください
- MOUTH の SENSITIVITY を上げても、ピチャ音のないふつうの歌・声の高域はほとんど触りません（本物と同じ）
- この 3 つは、本物を合成した試験音（声の合成音声＋作ったピチャ音・息・吹かれ）で測って合わせました。実際の録音では効き方が少し違うことがあります。
  DELTA で「取った音」を聴いて、声の大事な所が入っていないか確かめてください

## 右の欄

- **DELTA** … 取った音だけを聴く（0.015 秒かけて切り替わる）。ここに声がはっきり聞こえたら、その段の REDUCTION を下げてください
- **OUTPUT** … 出口の音量

## 画面のいちばん下

- **LINK 欄**（左）: ボーカルに挿した **Fader Pilot と同じ LINK 番号**にすると、歌っている間は NOISE の自動の追いかけ（ADAPTIVE）を止め、
  **歌の切れ目の雑音だけを覚えます**。伸ばした声を雑音と勘違いして削る失敗を防げます（本物にはない機能）
- **GAIN MATCH**（右の欄の左端）: ON にすると、挿しても・つまみを回しても音量が変わらないようにそろえます（既定 OFF。DELTA の間は効きません）
- **プリセット欄**: 自分のプリセットの保存・読み込み、UNDO / REDO
- **FACTORY PRESETS**（右上）: 内蔵プリセット 12 個

## 内蔵プリセット

| 名前 | 使いどころ |
|---|---|
| Init | 初期状態（NOISE だけ、MUSIC） |
| Home Vocal + Air Conditioner | 宅録ボーカルのエアコン・ファンの音 |
| Home Vocal - Room Echo | 宅録ボーカルの部屋鳴り（NOISE 少し＋ROOM） |
| Narration / Podcast | 話し声。DIALOGUE で雑音を多めに取り、響きも少し取り、口のピチャ音・息・吹かれも ON |
| Guitar / Bass Line - Hum | ライン録りのハム（AUTO・倍音 12）と少しの雑音 |
| Amp Buzz (many harmonics) | アンプのジーという音（倍音 16） |
| Gentle (just a little) | 少しだけ（GENTLE も ON） |
| Big Room - Dry It Up | 広い部屋で録った音の響きを大きく取る |
| Small Boxy Room (muddy) | 狭い部屋のこもった響き（DETAIL で LOW-MID を強く） |
| Bright Bathroom-like Echo | お風呂っぽい高い響き（DETAIL で HIGH を強く、LOW を弱く） |
| Vocal Clean-up: Clicks + Breaths | 歌の口のピチャ音と息を少し |
| Plosive Fix (p / b pops) | 吹かれだけを取る |

## 1.0 で保存した曲を開いたとき

- NOISE は **DIALOGUE で開く**ので、1.0 と同じ音のままです（新しく挿したときは MUSIC）
- ROOM は作り直したので、ON にしていた曲では効き方が少し変わります（本物に近くなりました）
- VOICE FIX は OFF のまま。遅れは 0.128 秒に増えますが、Logic が自動でずらします
- 1.0 で保存した**自分のプリセット**（プリセット欄で保存したもの）は MUSIC で開きます。1.0 と同じ音にしたいときは DIALOGUE を押してください

## おすすめの手順

宅録ボーカル:
1. まず NOISE だけ ON（初期状態）で再生し、DELTA を押して「取った音」に声が混じっていないか確かめる
2. 曲の頭などに声のない所があれば、そこを再生して LEARN を押す（3 秒で自動で終わる）
3. 部屋鳴りが気になるときは ROOM を ON。REDUCTION 6 くらいから
4. 口のピチャ音・息が気になるときは VOICE FIX の MOUTH・BREATH を ON

ナレーション・ポッドキャスト:
1. FACTORY PRESETS の「Narration / Podcast」を選ぶ
2. DELTA で取った音を聴き、言葉が混じっていたら NOISE の REDUCTION か、VOICE FIX の SENSITIVITY を下げる

ギター・ベースのライン録り:
1. ブーンと鳴るときは HUM を ON（AUTO）。ジーという音なら HARMONICS を 12〜16 に

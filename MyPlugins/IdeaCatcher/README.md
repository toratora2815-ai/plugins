# Idea Catcher（アイデア キャッチャー）

思いついた鼻歌を、キー 1 つで録って、**キーとテンポが入ったきれいな MIDI** にする Mac アプリです。
できた MIDI は、Splice の音と同じように **つかんで Logic のトラックへドラッグ** すれば入ります（Logic を勝手に開いたり操作したりはしません）。
メニューバー（画面右上）の電球のアイコンで、いつも待っています。

## 使い方

1. どのアプリを使っていても **⌃⌥I**（control + option + I）を押す → 録音が始まります（メニューバーのアイコンが赤くなる）
2. 鼻歌を歌う
3. もう一度 **⌃⌥I** を押す（または 4 秒黙ると自動で止まる）
4. 数秒で MIDI ができます。画面を出して（メニューバーの電球 →「画面を出す」）、
   **真ん中のピアノロールをつかんで、Logic のトラックの入れたい小節へドラッグ**
   - Logic は落とした位置（小節の頭）に入れます
   - 「⠿ MIDI をドラッグ → Logic」の帯からドラッグしても同じです
   - 最初の音がある小節の頭が、MIDI の頭です。1 拍目より前から歌い出した（弱起）ときは、1 小節前から入っています（ピアノロールに「弱起あり」と出るので、歌い出しの 1 小節前に落とす）

## 1.4.0 で変わったこと
- **Logic は開きません**。新しいプロジェクトは作らず、今開いているプロジェクトへドラッグで入れる形にしました
- **口ドラムはなくしました**（鼻歌だけ）
- **余分な音を自動で掃除**します（下の「きれいな MIDI にするために」）
- **クオンタイズ**：細かさ（なし / 1/4 / 1/8 / 1/16 / 1/8 3連）と、寄せる強さ（100% / 75% / 50%）を選べます
- **手直しの画面**：いらない音を消す、高さを直す、割れた音をつなぐ。声と MIDI を聴き比べられます
- 鼻歌の強弱（ベロシティ）のばらつきを、80〜110 に縮めて聞きやすくしました

## きれいな MIDI にするために（自動の掃除）
録り終えてから、前後を見て次のものを直します。
1. 声がとぎれて割れた同じ音（すき間 40 ms 未満）→ 1 つにつなぐ（わざと「タタタ」と言い直した音はそのまま）
2. しゃくり・すべり（行きたい音の手前の短い音）→ 行きたい音に吸収
3. 短すぎるかけら（60 ms と 32 分音符の長いほうより短い）→ 隣の音にまとめる。ぽつんとあるものは消す
4. 一瞬のオクターブ飛び → 元の音に戻してつなぐ
5. 前後に何もない、小さくて短い音 → 消す
6. 単音なので、重なった音は後ろの音の頭で切る

## クオンタイズ
「クオンタイズ」のボタンを押すと選べます。
- 細かさ：なし / 1/4 / 1/8 / 1/16 / 1/8 3連
- 寄せる強さ：100%（ぴったり）/ 75%（おすすめ）/ 50%（人っぽさを残す）
- 音の **出だしだけ** 拍に寄せ、長さはそのまま。寄せて重なった所は次の音の頭で切ります
- 最初の設定：カウントインやタップでテンポが分かっている録音は **1/16・75%**。テンポを自動で調べただけの録音は **なし**（テンポの判定が外れていると、全部の音がずれたままそろってしまうため）。
  まず「鼻歌」のテンポが合っているか（÷2 / ×2 / − +）を確かめてから、クオンタイズを入れてください
- テンポが分かっている録音で選び直すと、次からその細かさが最初の設定になります

## 手直し
「手直し」を押すと、ピアノロールが大きく出ます（4 小節ずつ。ホイールで横へ）。
| 操作 | すること |
|---|---|
| 音をクリック | 選ぶ（shift ＋クリックで足す、⌘A で全部、何もない所をクリックで選ぶのをやめる） |
| 上下にドラッグ／↑ ↓ キー | 半音ずつ上げ下げ（shift ＋ ↑ ↓ で 1 オクターブ）。何も選んでいないと全部の音 |
| delete／「消す」 | 選んだ音を消す |
| J／「つなぐ」 | 選んだ音を 1 つの音にまとめる（割れてしまった音を直すとき。高さはいちばん長い音） |
| ⌘Z／「1 つ戻す」 | 1 つ前に戻す |
| 「最初の状態」 | 手直しをやめて、録ったまま（自動の掃除をしたところ）に戻す |
| ▶ MIDI ／ ▶ 声 ／ ▶ 両方 | 聴き比べ（もう一度押すと止まる。スペースで MIDI） |
| esc／「閉じる」 | 閉じる。直した内容は MIDI ファイルに残り、開き直しても残ります |

- 試し聴きは、アプリの中の簡単な音で、Mac の標準の出力から鳴ります（鼻歌のテンポの速さ）

※ 初めて録るときは「マイクへのアクセス」の確認が出るので「許可」を押してください。

**できた MIDI はどこ？** → **「ダウンロード」フォルダ**にも自動で入ります（アプリを開かなくていい）。
通知をクリックすると、Finder でその MIDI が選ばれた状態で開きます。メニューバーの電球 →「できた MIDI を Finder で表示」でも。
元のファイル（声・設定と一緒）は `~/Music/Idea Catcher/日付 時刻/` にあります。コピーを置く場所は「その他…」でデスクトップ・置かないにも変えられます。

**画面を出すには** → メニューバーの電球 →「画面を出す」か、アプリのアイコン（アプリケーションフォルダ・Spotlight）をクリック。

## 1.1.0 で増えたこと

### さかのぼり録音（押す前の声も残す）
画面下の「さかのぼり録音」を ON にすると、マイクを開いたまま直前 30 秒を覚えておきます。
- 鼻歌を歌い終わってから ⌃⌥I を押しても、その鼻歌から録れます（2 秒黙っていた所より後ろの声のかたまりを残す）
- メニューバーの電球 →「直前を残す」なら、押した時点までで止めてすぐ MIDI に
- ON の間はマイクを使っているので、メニューバーにオレンジの点が出続けます

### テンポを決める 2 つの方法
- **タップ**: 録音中に **スペース**（または画面の TAP）を拍に合わせて 4 回以上たたくと、そのテンポと拍の位置を使います。
  録音中だけスペースを横取りするので、そのあいだ他のアプリでスペースは効きません（「その他…」で OFF にできる）
- **カウントイン**: 「カウントイン」で BPM を選ぶと、クリックが 1 小節（4 回）鳴ってから録音。次の 1 拍目が 1 小節目になります。
  「録音中もクリックを鳴らす」も選べます（マイクにクリックが入らないよう、ヘッドホンで）

### 重ねて録る
「＋ 重ねて録る」で、今のアイデアの声を流しながら、もう 1 本録れます（1 小節カウントしてから、小節の切れ目でループ）。
- 例: メロディーを録る → 重ねてベースラインを鼻歌で → Logic には「Melody」「Melody 2」のトラックが入る
- テンポとキーは最初のものに合わせます。2 本目以降は「Melody 2」…のトラックになります
- 失敗したら「＋ 重ねて録る」→「最後に重ねたものを消す」
- 前の声がマイクに入らないよう、ヘッドホンで

### 様子が画面の上に出る（HUD）
ほかのアプリを使っているときに録ると、画面の上の真ん中に「録音中 0:12」「カウント 3」「できました Am · 92 BPM」などが出ます。
できたら Mac の通知が出ます（クリックで Finder に MIDI を表示）。

### 声も Logic に入れる
画面の「声の録音 (WAV) をドラッグ」を、MIDI と同じ小節の頭に落としてください（`Voice for Logic.wav` = 1 小節目の頭にそろえた声。重ねたものは全部まとめて 1 本）。
（1.3 までの「Logic で開いたあと声を自動で読み込む」は、Logic を開かなくなったのでやめました）

### マイクは Mac 本体に固定・ノイズ除去（1.2.0）
- 録音にはいつも **Mac 本体のマイク**を使います（AirPods などをつないでいても）。
  Bluetooth のマイクを開くと、イヤホンが電話用の低い音質に切り替わって Logic の音まで悪くなるためです。
  クリックや重ね録りの音は、ふだんの出力（イヤホンなど）から出ます。「その他…」で固定を外すと「入力…」で選んだマイクになります
- 録り終えた声に**ノイズ除去**をかけてから MIDI にします（保存される声にもかかる）。
  声のない静かな所の音（ファン・空調・パソコンの音）を雑音として覚え、その分を周波数ごとに下げます。30 Hz より下のゴロゴロも落とします
  - 「その他…」で なし / ふつう（標準。最大 -15 dB）/ 強め（最大 -24 dB）
  - 強めは雑音が大きい部屋向け。声の出だしが削れてテンポの判定が変わることがあります
  - 声がずっと鳴っていて静かな所がない録音には、何もしません

### テンポを好きな数字に（1.3.0）
テンポの欄が 2 つあります。
- **TEMPO（曲のテンポ）** … MIDI に書くテンポ。数字をクリックして打つか、− + で変える。
  **音の拍の位置はそのままで、速さだけ変わります**（鼻歌が 150 だったのを 178 にすると、同じフレーズが 178 で鳴る）。「元の速さ」で鼻歌のテンポに戻す
- **鼻歌（鼻歌のテンポ）** … 鼻歌の何秒を 1 拍とみなすか。判定が倍・半分にずれたら ÷2 / ×2、少しずれていたら − +。
  ここを変えると、音が乗る拍の位置（小節線）が変わります
- 例: 鼻歌のテンポが 150 と出た → TEMPO に 178 と打つ → MIDI は 178 BPM、フレーズはそのまま速くなる
- 「声の録音 (WAV)」は鼻歌のままの速さです（曲のテンポを変えると、MIDI とは合わなくなります）

### キーについて
Logic は MIDI ファイルを開くと、ファイルのキーを「グローバル・シグネチャ・トラック」に入れます。
念のため 1 小節目に「Key Am」のようなマーカーも入れています（Logic のマーカーとして見える）。

## 保存される場所

`~/Music/Idea Catcher/日付 時刻/` に

- `Idea 11-05 15.30 Am 92bpm.mid` … できた MIDI（Logic へドラッグするもの）
- `Voice.wav` … 録った声そのまま（重ねたものは `Voice 2.wav` …）
- `Voice for Logic.wav` … 全部の声を 1 小節目の頭にそろえて 1 本にしたもの（Logic に入れる用）
- `info.json` … キー・テンポ・クオンタイズなどの設定と、手直しした音

## しくみ

- 声 → MIDI は VoiceEngine.h（音程を YIN 法で測るエンジン）を、録り終えた音にまとめてかけています
  - 1 回目: 音階なしで音程を集めてキーを当てる（Krumhansl のキーの型と比べる）
  - 2 回目: そのキーの音階に合わせてノートにする。オクターブは真ん中が E4 あたりに来るよう自動
  - そのあと「きれいな MIDI にするために」の掃除をかけます
- テンポは音の出だしの並びの自己相関から、55〜190 BPM で一番そろう間隔（105 BPM あたりを少しひいき）
- MIDI はテンポ・拍子・キー入り。Logic へドラッグすると、拍の位置のまま今のプロジェクトのテンポで鳴ります

## ほかのアプリから操作する

分散通知 `com.myplugins.ideacatcher.command` に、object = `toggle`（録音／停止）/ `start` / `stop` / `show`（画面）/ `open`（画面を出す。1.3 までは Logic で開く）/ `edit`（手直し）/
`tap`（テンポをたたく）/ `catch`（直前を残す）/ `overdub`（重ねて録る）。
Num Deck（1.21.0〜）のタイルの割り当てにも「Idea Catcher」の分類があります（録音する／止める・重ねて録る・直前を残す・テンポをたたく・できた MIDI を出す・画面を出す）。
ターミナルからの例:

```
osascript -l JavaScript -e 'ObjC.import("Foundation"); $.NSDistributedNotificationCenter.defaultCenter.postNotificationNameObjectUserInfoDeliverImmediately("com.myplugins.ideacatcher.command", "toggle", $(), true)'
```

## おすすめ

- 鼻歌は「ラ」や「ル」より「ン〜」「ドゥドゥ」のほうが音程がとりやすいです
- テンポを正しく取りたいときは、スペースで 4 回以上たたくか、カウントインを使う
- MIDI をきれいに拍にそろえたいときは、カウントインかタップでテンポを決めて録る（クオンタイズが最初から 1/16・75% で入ります）

## 入れ方

```
tools/install-app.sh IdeaCatcher
```

（Releases の latest から ~/Applications に入れて、この Mac の署名で署名し直します。マイクの許可が更新のたびに外れません）

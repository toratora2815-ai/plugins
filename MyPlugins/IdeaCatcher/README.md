# Idea Catcher（アイデア キャッチャー）

思いついた鼻歌や口ドラムを、キー 1 つで録って、そのまま **キーとテンポが入った Logic プロジェクト** にする Mac アプリです。
メニューバー（画面右上）の電球のアイコンで、いつも待っています。

## 使い方

1. どのアプリを使っていても **⌃⌥I**（control + option + I）を押す → 録音が始まります（メニューバーのアイコンが赤くなる）
2. 鼻歌か口ドラムをする
3. もう一度 **⌃⌥I** を押す（または 4 秒黙ると自動で止まる）
4. 数秒で MIDI になり、**Logic Pro が新しいプロジェクトとして開きます**
   - テンポ・拍子（4/4）・キーが入った状態
   - 鼻歌は「Melody」トラック、口ドラムは「Drums」トラック（チャンネル 10）
   - 最初の音が 1 小節目の頭

※ 初めて録るときは「マイクへのアクセス」の確認が出るので「許可」を押してください。

## 画面

| 所 | 意味 |
|---|---|
| 赤い丸 | クリックでも録音／停止 |
| KEY ◀ ▶ / メジャー・マイナー | 判定されたキー。違っていたら直せる（MIDI の音の高さはそのまま、キーの表示だけ変わる） |
| TEMPO − + ÷2 ×2 | 判定されたテンポ。半分・倍に間違えることがあるので ÷2 / ×2 で直す（音のタイミングは変わらず、小節線だけ動く） |
| メロディー / ドラム / メロディー＋ドラム | どちらの MIDI を入れるか（自動で選ぶ。押すと切り替わる） |
| クオンタイズ | なし / 1/16 / 1/8。音の出だしを拍にそろえる |
| Logic で開く | 今の設定で Logic の新しいプロジェクトとして開く（直したあとは、もう一度押す） |
| MIDI をドラッグ | 今開いている Logic のプロジェクトに入れたいときは、ここを Logic のトラックへドラッグ |
| 声の録音 (WAV) をドラッグ | 元の声も Logic に入れたいとき |
| 最近のアイデア | クリックで開き直す（キーやテンポを直したものも覚えています） |
| 録音キー | ⌃⌥I / ⌃⌥Space / ⌃⌥⌘R / F13 / ⇧⌘0 から選べる |
| 入力… | マイクを選ぶ |
| ログイン時に起動 | Mac を起動したらすぐ待機させる（おすすめ ON） |
| 止めたら Logic で開く | OFF にすると、録るだけで Logic は開かない（あとで「Logic で開く」） |
| 黙って 4 秒で止める | OFF にすると、キーを押すまで録り続ける（最長 5 分） |

ウィンドウは閉じてもアプリは終わりません（メニューバーで待っています）。終わるときはメニューバーの電球 →「Idea Catcher を終了」。

## 保存される場所

`~/Music/Idea Catcher/日付 時刻/` に

- `Idea 11-05 15.30 Am 92bpm.mid` … Logic で開く MIDI（この名前が Logic のプロジェクト名になる）
- `Voice.wav` … 録った声そのまま
- `info.json` … キー・テンポなどの設定

## しくみ

- 声 → MIDI は Hum Keys と同じエンジン（VoiceEngine.h）を、録り終えた音にまとめてかけています
  - 1 回目: 音階なしで音程を集めてキーを当てる（Krumhansl のキーの型と比べる）
  - 2 回目: そのキーの音階に合わせてノートにする。オクターブは真ん中が E4 あたりに来るよう自動
  - 口ドラムは Hum Keys で LEARN した自分の声の癖を、そのまま使います（Hum Keys の設定を読むだけ。書き換えません）
- 鼻歌か口ドラムかは「鳴っていた所のうち音程がとれた割合」で決めます（50% 以上なら鼻歌）
- テンポは音の出だしの並びの自己相関から、55〜190 BPM で一番そろう間隔（105 BPM あたりを少しひいき）
- Logic には「テンポ・拍子・キー入りの MIDI ファイル」を開かせています。Logic は MIDI ファイルを開くと、それを元に新しいプロジェクトを作ります

## ほかのアプリから操作する

分散通知 `com.myplugins.ideacatcher.command` に、object = `toggle`（録音／停止）/ `start` / `stop` / `show`（画面）/ `open`（Logic で開く）。
ターミナルからの例:

```
osascript -l JavaScript -e 'ObjC.import("Foundation"); $.NSDistributedNotificationCenter.defaultCenter.postNotificationNameObjectUserInfoDeliverImmediately("com.myplugins.ideacatcher.command", "toggle", $(), true)'
```

## おすすめ

- 鼻歌は「ラ」や「ル」より「ン〜」「ドゥドゥ」のほうが音程がとりやすいです
- テンポを正しく取りたいときは、最初の 2 小節くらいは拍がわかるように（足でリズムをとりながら）歌う
- 口ドラムの聞き分けがいまいちなら、Hum Keys の DRUMS で LEARN してから録ると良くなります

## 入れ方

```
tools/install-app.sh IdeaCatcher
```

（Releases の latest から ~/Applications に入れて、この Mac の署名で署名し直します。マイクの許可が更新のたびに外れません）

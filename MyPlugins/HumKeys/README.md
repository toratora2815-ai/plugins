# Hum Keys（ハム・キーズ）

マイクに **鼻歌** を歌うと、Logic の音源がそのまま鳴ります。
**「ドン・タッ・ツッ」** と口で言えば、キック・スネア・ハイハットが鳴ります。
頭に浮かんだメロディやリズムを、鍵盤を探さずにその場で MIDI（音の高さと長さのデータ）にするための、Mac 用の単体アプリです。

- 音階（KEY と SCALE）に合わせて自動で直すので、音程が少しずれていても大丈夫
- Logic とは **仮想 MIDI**（Mac の中だけにある MIDI 機器）「Hum Keys」でつながります。ケーブルも設定も不要
- アプリが出すのは MIDI だけ。音は Logic の音源から鳴ります

---

## インストール

ターミナルで（Claude が入れる場合はこれを実行します）:
```
tools/install-app.sh HumKeys
```
手で入れるときは、Releases の「latest」から `HumKeys.zip` をダウンロード → 解凍 → `Hum Keys.app` を「アプリケーション」へ →
```
xattr -dr com.apple.quarantine "/Applications/Hum Keys.app"
```

### 初回に出る許可
- **「"Hum Keys"がマイクへのアクセスを求めています」** → 「許可」
  - 拒否してしまったとき：「システム設定」→「プライバシーとセキュリティ」→「マイク」で **Hum Keys** をオン

---

## Logic でのつなぎ方

1. Hum Keys を起動（上の「入力を選ぶ」で、歌うマイクを選ぶ）
2. Logic でソフトウェア音源のトラックを作り、**録音可能（R ボタン）** にする
3. 歌う → その音源が鳴ります。録音ボタンを押せば、そのまま MIDI リージョンになります

- Logic は最初から「全部の MIDI 入力」を受け取るので、ふつうは何も設定しなくて OK
- 出てこないとき：Logic を再起動（Hum Keys を先に起動しておく）
- **ヘッドフォン推奨**。スピーカーで鳴らすと、その音をマイクが拾って勝手に鳴ることがあります

## 画面

### 上の行
| ボタン | 役目 |
|---|---|
| **ON / OFF** | MIDI を出す／止める（スペースキー） |
| **MELODY / DRUMS** | 鼻歌モード／口ドラムモード（1 / 2 キー） |
| **入力** | 使うマイク（オーディオインターフェイスの入力など）を選ぶ |
| **PANIC** | 鳴りっぱなしの音を全部止める（esc キー） |

### 左のメーターと GATE
- 水色の棒 ＝ マイクの音量。オレンジの線 ＝ **GATE**（これより小さい音は無視）
- メーターの上を **上下にドラッグ** で GATE を動かせます（ダブルクリックで -45 dB に戻る）
- 部屋の雑音で勝手に鳴るときは GATE を上げる。歌っても反応しないときは下げる

### MELODY（鼻歌）
真ん中のピアノロールに、**水色の点 ＝ 歌った高さ**、**オレンジの棒 ＝ 実際に出した MIDI ノート** が流れます。
右上の大きな文字が今鳴らしている音（Logic と同じ呼び方。真ん中の C ＝ C3）。

| つまみ | 意味 |
|---|---|
| **KEY** | 曲のキー（主音） |
| **SCALE** | 使う音階。音階に無い音を歌うと、一番近い音階の音に直す。Chromatic ＝ 直さない（12 音全部） |
| **OCTAVE** | 出す音を何オクターブ上げ下げするか（男性の声でメロディを高く、ベースを低く、など） |
| **GLUE** | 同じ高さがこの長さ続いたら音にする。短い＝反応が速い／長い＝しゃくりやビブラートで音が揺れにくい |
| **HOLD** | 声がこの長さ途切れたら音を止める。短い＝細かく切れる／長い＝音がつながる |
| **VELOCITY** | DYNAMIC ＝ 声の大きさで強弱／FIXED ＝ いつも 100 |
| **BEND** | ON にすると、音程の細かいゆれ（ビブラート、しゃくり）をピッチベンドで送る。音源のベンド幅を ±2 半音にしておく |
| **MIDI CH** | 出す MIDI チャンネル |

- 同じ高さで「タ・タ・タ」と言い直すと、ちゃんと 3 回鳴ります
- 声が出てから音が鳴るまで、およそ 30 ms。句の最初の音はすぐ鳴らし、しゃくり上げて高さが変わったら鳴らし直します
- 音から音へなめらかに滑っている途中の高さは、音にしません（滑り終わった高さだけを出します）
- Logic で録音すると約 30 ms 遅れて記録されます。**下の TAKE からドラッグした MIDI は遅れなし**（声が出た本当の時刻）です

### TAKE（録り逃し防止）
Logic で録音していなくても、歌った・口で鳴らした MIDI は **全部自動でたまります**。

- 画面下の **TAKE** に、今のテイクが小さなピアノロールで出ます
- **4 秒黙ると 1 テイクの区切り**。そのテイクは自動で `~/Music/Hum Keys` に MIDI ファイル（`Hum Keys 日付 時刻.mid`）として保存されます
- **「⇩ Logic へドラッグ」** をつかんで、Logic のトラック領域に落とすと MIDI リージョンになります（落とした位置が最初の音）
- 記録される MIDI は、反応の遅れを差し引いた **声が出た本当の時刻**。出だしのしゃくりも直した高さで残ります
- **TEMPO**：Logic の曲のテンポに合わせておくと、ドラッグしたテイクが小節に合います
- **フォルダ**：保存したテイクを Finder で開く
- **NEW**：今のテイクを保存して、新しいテイクを始める（4 秒待たずに区切りたいとき）

### DRUMS（口ドラム）
| 口で | 鳴る音 | 最初のノート |
|---|---|---|
| 「ドン」「ブッ」（低い音） | **KICK** | C1（36） |
| 「タッ」「カッ」「プシッ」（中くらい） | **SNARE** | D1（38） |
| 「ツッ」「チッ」（高い、息の音） | **HAT** | F#1（42） |

- 最初のノートは Logic の Drummer / Drum Kit Designer に合わせてあります。各パッドの下で変えられます
- **LEARN**：押してから、その音を口で **4 回** 鳴らすと、あなたの声の癖を覚えます（パッドの枠が光っている間）。
  聞き分けがうまくいかないときは、3 つとも LEARN してください。覚えた内容は次に起動したときも残ります
- **RESET**：覚えた癖を消して、最初の聞き分けに戻す
- **SENS**：どれだけ急に大きくなったら「叩いた」とみなすか（dB）。小さいほど敏感。取りこぼすなら下げる、二重に鳴るなら上げる

## おすすめ設定

| やりたいこと | 設定 |
|---|---|
| メロディのアイデアを残す | MELODY、曲の KEY と SCALE、GLUE 35 ms、HOLD 70 ms、TEMPO を曲に合わせて、歌い終わったら TAKE をドラッグ |
| 音痴が心配／しゃくり癖がある | SCALE を Major Pentatonic（ヨナ抜き）か Minor Pentatonic に、GLUE 60〜80 ms |
| ベースラインを歌う | OCTAVE -1 か -2、HOLD 40 ms（キレよく） |
| シンセのリードで表情を付けたい | SCALE を Chromatic、BEND ON、音源をモノ／レガートに |
| 口ドラムでビートを作る | DRUMS、3 つとも LEARN、SENS 9 dB、Logic の Drum Kit Designer |

## しくみ（参考）
- 音の高さ：声を 12 kHz に間引いて、YIN 法（波の形が何サンプルごとに繰り返すかを調べる方法）で約 2.7 ms ごとに測り、
  直近 5 回の真ん中の値でならす。約 16 ms で 0.4 半音以上動いているあいだは「滑っている途中」として音を変えない
- 口ドラム：音が急に大きくなった瞬間を見つけ、そこから 14 ms の「150 Hz 以下の割合」と「7 kHz 以上の割合」で聞き分ける
  （直前に残っているキックの余韻などは差し引く）
- 設定は `~/Library/Application Support/Hum Keys/Hum Keys.settings` に保存

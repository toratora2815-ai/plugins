# Hum Keys（ハム・キーズ）

マイクに **鼻歌** を歌うと、Logic の音源がそのまま鳴ります。
**「ドン・タッ・ツッ」** と口で言えば、キック・スネア・ハイハットが鳴ります。
頭に浮かんだメロディやリズムを、鍵盤を探さずにその場で MIDI（音の高さと長さのデータ）にするための、Mac 用の単体アプリです。

- 音階（KEY と SCALE）に合わせて自動で直すので、音程が少しずれていても大丈夫
- Logic とは **仮想 MIDI**（Mac の中だけにある MIDI 機器）「Hum Keys」でつながります。ケーブルも設定も不要
- アプリが出すのは MIDI だけ。音は Logic の音源から鳴ります

---

## インストール

ターミナルで（Claude が入れる場合はこれを実行します）:
```
tools/install-app.sh HumKeys
```
手で入れるときは、Releases の「latest」から `HumKeys.zip` をダウンロード → 解凍 → `Hum Keys.app` を「アプリケーション」へ →
```
xattr -dr com.apple.quarantine "/Applications/Hum Keys.app"
```

### 初回に出る許可
- **「"Hum Keys"がマイクへのアクセスを求めています」** → 「許可」
  - 拒否してしまったとき：「システム設定」→「プライバシーとセキュリティ」→「マイク」で **Hum Keys** をオン

## Logic でのつなぎ方

1. Hum Keys を起動（上の「入力を選ぶ」で、歌うマイクを選ぶ）
2. Logic でソフトウェア音源のトラックを作り、**録音可能（R ボタン）** にする
3. 歌う → その音源が鳴ります。録音ボタンを押せば、そのまま MIDI リージョンになります

- Logic は最初から「全部の MIDI 入力」を受け取るので、ふつうは何も設定しなくて OK
- 出てこないとき：Logic を再起動（Hum Keys を先に起動しておく）
- **ヘッドフォン推奨**。スピーカーで鳴らすと、その音をマイクが拾って勝手に鳴ることがあります

### Logic のテンポと小節に自動で合わせる（MIDI クロック）
1 回だけ設定しておくと、Logic の再生に合わせて歌ったテイクが **曲の何小節目に歌ったか** を覚え、テンポも自動で合います。
1. Hum Keys を起動しておく
2. Logic で「ファイル」→「プロジェクト設定」→「同期」→「MIDI」タブを開く
3. 「MIDI クロック」の **送信先** で **Hum Keys** を選び、チェックを入れる
4. 「クロックモード」は **「ソング」で始まるもの**（ソングポジションポインタを送る設定）を選ぶ
   （項目の名前は Logic の版で少し違うことがあります）
5. Logic を再生すると、Hum Keys の下の行が緑で「Logic と同期中 ♩=120.0 ● 再生中」になれば OK

- 同期中のテイクには「17 小節目から」のように出ます。**ドラッグしたら、その小節の頭に落とす**とぴったり元の位置に入ります
- Logic を止めると、そこまでで 1 テイクに区切られます
- 小節は画面下の **TIME SIG**（拍子）で数えます（Logic の拍子と同じにしてください）
- プロジェクトごとの設定なので、新しいプロジェクトではもう一度 2〜4 をしてください

## 画面

### 上の行
| ボタン | 役目 |
|---|---|
| **ON / OFF** | MIDI を出す／止める（スペースキー） |
| **MELODY / DRUMS / AUTO** | 鼻歌モード／口ドラムモード／自動で切替（1 / 2 / 3 キー） |
| **入力** | 使うマイク（オーディオインターフェイスの入力など）を選ぶ |
| **PIN** | いつも手前に出す（Logic の全画面の上にも出ます）。ON のあいだ Hum Keys は Dock とメニューバーから消えます（P キー） |
| **MINI** | 小さい表示（今の音・叩いた音・メーター・ドラッグ・試し聴きだけ）。FULL で戻る（M キー） |
| **PANIC** | 鳴りっぱなしの音を全部止める（esc キー） |
| **AUTO GATE** | 押してから 2 秒静かにすると、まわりの雑音を測って GATE をちょうどいい高さにする |

### 左のメーターと GATE
- 水色の棒 ＝ マイクの音量。オレンジの線 ＝ **GATE**（これより小さい音は無視）
- メーターの上を **上下にドラッグ** で GATE を動かせます（ダブルクリックで -45 dB に戻る）
- 部屋の雑音で勝手に鳴るときは GATE を上げる。歌っても反応しないときは下げる

### MELODY（鼻歌）
真ん中のピアノロールに、**水色の点 ＝ 歌った高さ**、**オレンジの棒 ＝ 実際に出した MIDI ノート** が流れます。
右上の大きな文字が今鳴らしている音（Logic と同じ呼び方。真ん中の C ＝ C3）。

| つまみ | 意味 |
|---|---|
| **KEY** | 曲のキー（主音） |
| **AUTO** | 歌った音から **KEY・SCALE（メジャー／マイナー）・OCTAVE を自動で決める**。声のある所が約 6 秒ぶん集まると決まります（足りなければ「聞いています…」と出るので、そのまま歌う）。ペンタトニックを選んでいるときはペンタトニックのまま |
| **SCALE** | 使う音階。音階に無い音を歌うと、一番近い音階の音に直す。Chromatic ＝ 直さない（12 音全部） |
| **OCTAVE** | 出す音を何オクターブ上げ下げするか（男性の声でメロディを高く、ベースを低く、など）。AUTO は出る音の真ん中が C3〜C4 あたりに来るように選びます |
| **GLUE** | 同じ高さがこの長さ続いたら音にする。短い＝反応が速い／長い＝しゃくりやビブラートで音が揺れにくい |
| **HOLD** | 声がこの長さ途切れたら音を止める。短い＝細かく切れる／長い＝音がつながる |
| **VELOCITY** | DYNAMIC ＝ 声の大きさで強弱／FIXED ＝ いつも 100 |
| **BEND** | ON にすると、音程の細かいゆれ（ビブラート、しゃくり）をピッチベンドで送る。音源のベンド幅を ±2 半音にしておく |
| **EXPR** | ON にすると、**声のゆれ（ビブラートの深さ）を CC1（モジュレーション）**、**声の大きさを CC11（エクスプレッション）** で送る。CC は音源のつまみを動かす MIDI の信号です。ストリングス・管楽器・シンセのリードで、のばした音がふくらんだり揺れたりします |
| **MIDI CH** | 出す MIDI チャンネル |

- 同じ高さで「タ・タ・タ」と言い直すと、ちゃんと 3 回鳴ります
- 声が出てから音が鳴るまで、およそ 30 ms。句の最初の音はすぐ鳴らし、しゃくり上げて高さが変わったら鳴らし直します
- 音から音へなめらかに滑っている途中の高さは、音にしません（滑り終わった高さだけを出します）
- Logic で録音すると約 30 ms 遅れて記録されます。**下の TAKE からドラッグした MIDI は遅れなし**（声が出た本当の時刻）です
- **「ス」「シ」「ハー」などの息の音では音を出しません**（3 kHz より上の音が多い所は、声の高さを測らない）

### AUTO（鼻歌と口ドラムを自動で切替）
鼻歌と口ドラムを、モードを切り替えずに続けて出せます。1 つのテイクに両方が入ります。
- 「ツッ」「チッ」のような **とても高い音はすぐドラム**
- それ以外は、鳴り始めから **90 ms 聞いて決めます**：声の高さが続いて、音量が落ちない → 鼻歌／すぐ消える・高さが滑り落ちる → ドラム
- そのため AUTO では、**その場で鳴る音が少し遅れます**（キック・スネアで約 90 ms）。**TAKE に残る MIDI は正しい位置**です
- ドラムは **MIDI チャンネル 10**、メロディーは MIDI CH で出ます。テイクを Logic へドラッグすると、**メロディーとドラムの 2 トラック**で入ります
- ピアノロールの下に、ドラムと決めた音が K（キック）S（スネア）H（ハイハット）などの印で出ます
- 歌い出しを「タ」「ダ」で始めても、そのあと声がのびれば鼻歌になります
- ドラムの聞き分けは DRUMS で LEARN した内容を使います（LEARN は DRUMS の画面で）

### TAKE（録り逃し防止）
Logic で録音していなくても、歌った・口で鳴らした MIDI は **全部自動でたまります**。

- 画面下の **TAKE** に、今のテイクが小さなピアノロールで出ます
- **4 秒黙ると 1 テイクの区切り**。そのテイクは自動で `~/Music/Hum Keys` に MIDI ファイル（`Hum Keys 日付 時刻.mid`）として保存されます
- **「⇩ Logic へドラッグ」** をつかんで、Logic のトラック領域に落とすと MIDI リージョンになります（落とした位置が最初の音）
- 記録される MIDI は、反応の遅れを差し引いた **声が出た本当の時刻**。出だしのしゃくりも直した高さで残ります
- **▶**：今のテイクをアプリの中の簡単な音で試し聴き（Mac の標準の出力から鳴ります。Return キー）。クオンタイズと手直しが入った形で鳴ります
- **EDIT**：今のテイクの手直し（E キー。下の「テイクの手直し」）
- **Logic へ**：今のテイクを、**ドラッグしないで** 開いている Logic のプロジェクトに入れる（I キー。下の「Logic へ入れる」）
- **履歴**：これまでのテイクの一覧（H キー）。▶ で試し聴き、行をつかんで Logic へドラッグ、× でゴミ箱へ（ゴミ箱から戻せます）
- **フォルダ**：保存したテイクを Finder で開く
- **NEW**：今のテイクを保存して、新しいテイクを始める（4 秒待たずに区切りたいとき。N キー）

### テンポ・拍子・クリック・クオンタイズ（TAKE の上の行）
| つまみ | 意味 |
|---|---|
| **TEMPO** | 曲のテンポ。Logic から MIDI クロックが来ていれば自動で合います（「TEMPO (Logic)」と出ます） |
| **TIME SIG** | 拍子（4/4・3/4・2/4・5/4・6/8・7/8・12/8）。小節の頭の位置、クリックの強拍、MIDI ファイルの拍子に使います |
| **CLICK** | メトロノーム（C キー）。TEMPO で鳴ります。**ヘッドホンで聞いてください**（スピーカーだとマイクが拾って、DRUMS が反応します）。小節の頭は高い音。6/8・12/8 は 8 分 3 つごと、7/8 は 8 分ごとに鳴ります |
| **COUNT-IN** | **1 小節カウントしてから録る**（R キー）。新しいテイクになり、カウントのあとの小節の頭から始まります。CLICK が OFF でもカウントの 1 小節だけは鳴ります |
| **QUANTIZE** | クオンタイズ（音の出だしを拍のマス目に寄せる）。OFF / 1/4 / 1/8 / 1/16 / 1/8 3連 / 1/16 3連（Q キーで切替）。音の長さはそのまま |
| **STRENGTH** | どれだけ寄せるか。100% ＝ ぴったり、75%・50% ＝ ずれを少し残す（人っぽさが残る） |

- **CLICK を鳴らしている間（とカウントインのあと）のテイクは、クリックの小節に合わせて保存されます**。
  ドラッグしたら、Logic の小節の頭に落とすとそのまま拍に合います（TEMPO を Logic と同じにしておく）
- Logic と同期しているときは Logic の拍を使い、Hum Keys のクリックは鳴らしません（Logic のクリックとカウントインを使ってください）
- どちらでもないとき（クリックなしで自由に歌ったとき）は、最初の音を 1 拍目の頭として、TEMPO で拍に直します
- クオンタイズと拍子は、ドラッグ・保存・試し聴きに効きます。あとから変えても、今のテイクの保存ファイルは書き直されます

### Logic へ入れる（ドラッグなし）
「Logic へ」を押すと、Hum Keys が Logic の「ファイル → 読み込む → MIDI ファイル」を代わりに押して、今のテイクを入れます。
- **Logic と同期していたテイク** → Logic の「位置へ移動」（/ キー）で元の小節へ再生ヘッドを動かしてから入れるので、**歌った小節にそのまま入ります**
- **それ以外（クリックやループのテイク、自由に歌ったテイク）** → **今の再生ヘッドの位置（の小節の頭）** に入ります。先に Logic で入れたい小節に再生ヘッドを置いてください
- メロディーとドラムが両方あるテイクは 2 トラックで入ります
- **初回はアクセシビリティの許可が要ります**：「システム設定」→「プライバシーとセキュリティ」→「アクセシビリティ」で **Hum Keys** をオン → もう一度「Logic へ」
- 入れている間（数秒）は、Logic とキーボードを触らないでください（Hum Keys がメニューを押してファイルの場所を打ち込んでいます）
- うまくいかないとき（Logic の別の画面が開いている、メニューが見つからない など）は、下の行に理由が出ます。そのときはドラッグで入れてください
- Logic のキーコマンドで「/」（位置へ移動）を変えていると、小節へは動かせません（再生ヘッドの位置に入ります）

### ループで重ねて録る（LOOP）
2 小節や 4 小節をくり返しながら、1 周ずつ音を重ねて 1 つのテイクにします。口では同時に出せないキック・ハット・メロディーも、重ねればビートになります。
1. TEMPO と TIME SIG を合わせ、**LENGTH**（1 / 2 / 4 / 8 小節）を選ぶ
2. **LOOP の「● 録る」**（L キー）→ 1 小節カウントのあと、ループが始まります（クリックは自動で ON）
3. 1 周目はキック、2 周目はハット、3 周目はスネア…と重ねていく。**前の周で録った音は、ヘッドホンに鳴ります**（アプリの中の簡単な音）
4. 失敗したら **⌫ キー**（Num Deck なら「ループの最後の周を消す」）で、最後に音を入れた周をまるごと消せます
5. もう一度 **「■ 終わる」**（L キー）で終わり → テイクとして保存。「Logic へ」かドラッグで入れる
- AUTO にしておくと、モードを切り替えずにドラムとメロディーを重ねられます
- QUANTIZE を選んでおくと、ループの再生もクオンタイズした形で鳴ります
- 頭より少し早く（1/8 拍まで）出た音は、その周の頭として扱います。ループの終わりをまたいだ音は、終わりで切ります
- 保存される MIDI はちょうど LENGTH の長さ。Logic でリージョンをループさせればそのまま回ります
- Logic の再生中はループ録音できません（Logic を止めてから）

### テイクの手直し（EDIT）
ドラッグの前に、今のテイクをその場で直せます。上がメロディー、下（線の下）がドラムの段です。
| 操作 | すること |
|---|---|
| 音をクリック | 選ぶ（shift ＋クリックで足す、⌘A で全部、何もない所をクリックで選ぶのをやめる） |
| 選んだ音を上下にドラッグ／↑ ↓ キー | 半音ずつ上げ下げ。**ドラムは音の種類を差し替え**（KICK → SNARE → HAT → OPEN HAT → TOM → CLAP の順） |
| shift ＋ ↑ ↓／OCT ↑ ↓ | 1 オクターブ上げ下げ |
| delete／「消す」 | 選んだ音を消す |
| ⌘Z／「1 つ戻す」 | 1 つ前に戻す |
| 「最初の状態」 | 手直しを全部やめて、録ったままに戻す |
| スペース／▶ | 試し聴き |
| esc／「閉じる」 | 画面を閉じる（直した内容はテイクに残ります） |

- 何も選ばずに ↑ ↓ OCT を押すと、**全部の音**が動きます（テイク全体の移調）
- 直したテイクは保存ファイルも書き直されます。直したあとに歌うと、次の音から新しいテイクになります

### DRUMS（口ドラム）
| 口で | 鳴る音 | 最初のノート |
|---|---|---|
| 「ドン」「ブッ」（低い音） | **KICK** | C1（36） |
| 「タッ」「カッ」「プシッ」（中くらい） | **SNARE** | D1（38） |
| 「ツッ」「チッ」（高い、息の音） | **HAT** | F#1（42） |
| 「ツー」「チー」（のばす） | **OPEN HAT** | A#1（46） |
| 「ボン」「ドゥン」（キックより少し高い、響く） | **TOM** | A1（45） |
| 「パッ」「ッパ」（破裂する音） | **CLAP** | D#1（39） |

- KICK / SNARE / HAT は最初から使えます。**OPEN HAT / TOM / CLAP は LEARN してから使えるようになります**（パッドが暗いうちは使われません）
- 最初のノートは Logic の Drum Kit Designer に合わせてあります。各パッドの下で変えられます
- **LEARN**：押してから、その音を口で **4 回** 鳴らすと、あなたの声の癖を覚えます（パッドの枠が光っている間）。
  聞き分けがうまくいかないときは、使う音を全部 LEARN してください。覚えた内容は次に起動したときも残ります
- **OPEN HAT を覚えさせると**、ハイハット系の音は「のびるかどうか」を見てから鳴らすので、ハイハットだけ約 45 ms 遅れて鳴ります
  （TAKE に残る MIDI は遅れなし）。HAT と OPEN HAT の両方を LEARN すると、のばし方の違いも覚えます
- **RESET**：覚えた癖を消す（KICK / SNARE / HAT は最初の聞き分けに戻る。ほかの 3 つは使わなくなる）
- ※ 1.2.0 で聞き分けの仕組みを変えたので、前の版で LEARN した内容は使われません。もう一度 LEARN してください
- **SENS**：どれだけ急に大きくなったら「叩いた」とみなすか（dB）。小さいほど敏感。取りこぼすなら下げる、二重に鳴るなら上げる

## Num Deck から操作する
Num Deck のタイルの割り当て（タイルをクリック）に **「Hum Keys」** の分類があります。好きなキーに置いてください。
ON / OFF、MELODY ⇔ DRUMS、AUTO、CLICK、カウントインして録る、テイクの手直し、クオンタイズを切替、
**テイクを Logic に入れる、ループ録音 開始／終了、ループの最後の周を消す**、テイクを区切る（NEW）、テイクを試し聴き、テイクの履歴、キーとオクターブを自動で、GATE を自動で、
OCTAVE +1 / -1、MINI 表示、いつも手前、PANIC、画面を出す。
Hum Keys が前にいるときも、Num Deck の「Logic が前面のときだけ」の対象になります。

## おすすめ設定

| やりたいこと | 設定 |
|---|---|
| メロディのアイデアを残す | MELODY、曲の KEY と SCALE、GLUE 35 ms、HOLD 70 ms、TEMPO を曲に合わせて、歌い終わったら TAKE をドラッグ |
| 音痴が心配／しゃくり癖がある | SCALE を Major Pentatonic（ヨナ抜き）か Minor Pentatonic に、GLUE 60〜80 ms |
| ベースラインを歌う | OCTAVE -1 か -2、HOLD 40 ms（キレよく） |
| シンセのリードで表情を付けたい | SCALE を Chromatic、BEND ON、音源をモノ／レガートに |
| 口ドラムでビートを作る | DRUMS、使う音を全部 LEARN、SENS 9 dB、Logic の Drum Kit Designer |
| ビートとメロディーを一気に | DRUMS で LEARN → AUTO、CLICK ON か COUNT-IN、QUANTIZE 1/16・75%、ドラッグで 2 トラック |
| 拍ぴったりのフレーズを残す | TEMPO を曲に合わせて COUNT-IN → 歌う → QUANTIZE 1/8 か 1/16（100%）→ ドラッグして小節の頭へ |
| 口でビートを組む | DRUMS で LEARN → AUTO、LENGTH 2 小節、QUANTIZE 1/16・75%、LOOP で 1 周ずつ重ねる → 「Logic へ」 |
| ストリングスやブラスを歌う | EXPR ON、HOLD 100 ms 以上、音源側で CC1・CC11 が効く音色を選ぶ |
| Logic の全画面の横で使う | MINI ＋ PIN。Num Deck のキーで ON/OFF や NEW |

## しくみ（参考）
- 音の高さ：声を 12 kHz に間引いて、YIN 法（波の形が何サンプルごとに繰り返すかを調べる方法）で約 2.7 ms ごとに測り、
  直近 5 回の真ん中の値でならす。約 16 ms で 0.4 半音以上動いているあいだは「滑っている途中」として音を変えない
- 口ドラム：音が急に大きくなった瞬間を見つけ、そこから 14 ms の 6 つの帯域（〜150 / 〜400 / 〜1.2k / 〜3k / 〜7k / 7k Hz〜）の割合で、
  覚えた音のうち一番近いものを選ぶ（直前に残っているキックの余韻などは差し引く）。開いたハイハットは 30〜45 ms の高音の残り方で見分ける
- キー：歌った音の長さを音名ごとに数え、Krumhansl のプロファイル（どの音がどのキーらしいかの表）といちばん合うキーを選ぶ
- Logic との同期：MIDI クロック（1 拍 24 回）とソングポジションポインタから、声が出た時刻が何拍目だったかを計算する
- AUTO：とても高い音（7 kHz〜）が 3 % 以上ならすぐドラム。ほかは 90 ms のあいだに声の高さがとれた割合（3 割弱以上）、高さの幅（外れ値を除いて 3 半音未満）、音量の落ち方（6 dB 未満）で鼻歌かを決める
- クリック：耳に届く時刻（出力の遅れを足した時刻）で拍を数え、その拍の目盛りで声の時刻を拍に直す
- 設定は `~/Library/Application Support/Hum Keys/Hum Keys.settings` に保存

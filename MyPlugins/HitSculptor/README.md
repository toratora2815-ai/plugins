# Hit Sculptor

キックやスネアの**1 打ずつの形**を、つまみで自由に作り直すプラグイン（Logic 用 AU）。
「頭をもっと硬く」「余韻を短く／長く」「部屋の響きを消してカラカラに」「逆に響きを足してウェットに」が 1 台でできます。

鳴り始めを自動で見つけて、その 1 打ごとに処理します。ドラムのトラック（サンプルでも録音でも）に挿すだけ。
ハイハット・パーカッション・ワンショット・ギターやピアノの 1 音など、「鳴り始めがはっきりした音」なら何にでも使えます。
逆再生は別のプラグイン **Flipside** でできます（逆再生には遅れが必要なので、遅れゼロの Hit Sculptor とは分けました）。

## 使い方
1. キックやスネアのトラックに挿す（ドラム全体のバスでも使えますが、1 種類ずつの方が狙いどおりになります）
2. 再生すると、上の画面に**最後の 1 打**が描かれます（灰色 = 元の音、オレンジ = 出てくる音。縦は dB、横は打ってからの時間）
3. つまみを回して、オレンジの形を見ながら耳で決める
4. 迷ったら右上の **PRESET** から選んで、そこから直す

- つまみはダブルクリックで最初の値に戻ります
- 遅れ（レイテンシー）はほぼゼロです（DRIVE 用のオーバーサンプリング分の数サンプルだけ。Logic が自動で補正します）

## つまみ

### SHAPE（形）
- **ATTACK**（−100〜+100 %、真ん中が 0）… 打った瞬間の「頭」の強さ
  - 右へ: パチッと硬く、前に出る（最大 +18 dB くらい）
  - 左へ: 頭がまるく、やわらかく、奥へ
- **SNAP**（1〜50 ms）… どこまでを「頭」とみなすか
  - 短い（2〜8 ms）: クリック・スティックの当たりだけ
  - 長い（20〜50 ms）: 胴鳴り（ボン、の部分）まで含めて押し出す
- **LENGTH**（−100〜+100 %、真ん中が 0）… 1 打の長さ
  - 左へ: 打ってから時間でフェードアウトして**短く**（−50 % で約 0.16 秒、−100 % で約 0.03 秒で 40 dB 下がる）
  - 右へ: 減っていく余韻を持ち上げて**長く**（最大 +24 dB。無音のノイズは持ち上げません）

### ROOM（響き）
- **ROOM**（−100〜+100 %、真ん中が 0）
  - 左へ（DRY）: 打った瞬間より静かな所 ＝ 部屋の響きを下げて、**完全に乾いた音**に（−100 % で響き −30 dB くらい）
  - 右へ（WET）: 小さな部屋の響きを**足す**（低音は響かせないので、キックもこもりません）
- **SIZE** … 足す響きの部屋の大きさ（小 = 狭いブース、大 = 広いホール寄り、響きの長さ約 0.1〜1.8 秒）
- **TONE** … 足す響きの明るさ（左 = こもった、右 = キラッとした）

※ SIZE / TONE は ROOM を右（WET）にしたときだけ効きます

### OUT（出口）
- **DRIVE** … ソフトクリップ（4 倍オーバーサンプリング）。小さい所が持ち上がってピークが丸まり、太く・密に
- **MIX** … 元の音と混ぜる割合（パラレル処理。100 % = 全部加工した音）
- **OUTPUT** … 最後の音量（−24〜+12 dB）

## おすすめ設定
| やりたいこと | ATTACK | SNAP | LENGTH | ROOM | ほか |
|---|---|---|---|---|---|
| キックをタイトに | +30 | 12 ms | −55 | −40 | |
| キックをパンチよく | +60 | 15 ms | −20 | 0 | DRIVE 15 |
| 808 っぽく長く | −10 | 20 ms | +70 | 0 | DRIVE 10 |
| 響きを全部消す | +10 | 15 ms | −30 | −100 | |
| スネアをスナッピーに | +70 | 8 ms | −30 | −20 | |
| スネアを太く | −20 | 25 ms | +40 | +25 | SIZE 45 |
| スネアに大きい部屋 | +20 | 15 ms | +20 | +70 | SIZE 75, TONE 60 |
| ハイハットを乾いて短く | +30 | 5 ms | −60 | −60 | |

PRESET にもこれらが入っています（Tight Kick / Punchy Kick / Long Boom / Clipped Kick / Bone Dry / Snappy Snare / Fat Snare / Big Room Snare / Small Room / Soft Hit / Dry & Short Hats）。

## コツ
- **短く ＋ 響きを足す**（LENGTH −50、ROOM +40）と、元の部屋鳴りを入れ替えたような音になります
- 細かい連打（ロール・ゴースト）で切れすぎるときは、LENGTH を真ん中に寄せてください（各打の頭は必ず残ります）
- ドラムループ全体に挿したときは、いちばん大きい音（キックかスネア）に合わせて効きます

# Horizon Spread

ステレオ感（スプレッド感）を出すいろいろな手法をひとつにまとめたプラグイン（Logic 用 AU）。
Logic の Mastering Assistant の Width や、各社のワイドナーの手法を参考にしたオリジナル設計です。

ページは2つ。音は「CREATE（生み出す）→ SHAPE（整える）」の順に流れます。
CREATE でモノラルっぽい音から広がりを作り、SHAPE で帯域ごとの幅やアタックを整える、という使い方ができます。

## いちばん大事な考え方：モノラルにしても崩れない
音を「真ん中の成分（Mid）」と「左右の差の成分（Side）」に分けて、**Side だけ**を加工します。
モノラル再生（スマホのスピーカーなど）では Side は打ち消し合って消えるので、
どれだけ広げても、モノラルで聴いたときの音は元の音とまったく同じです（テストで確認済み）。

## 画面
- 左上 **MASTER** … 全体のつまみ
- 左下 **SAFETY** … 安全装置（どちらのページでも有効）
- 中央 … **SHAPE / CREATE** のページ切り替え
- 右 **IMAGE** … 音の広がりの表示、相関メーター、帯域ごとの広さメーター
- 右上 **プリセット**メニュー … 用途別の設定を一発で呼び出せます（Logic のプリセットメニューからも選べます）
- 右上 **SIDE SOLO** … 押している間、広がりの成分（Side）だけが聴こえる（確認用。書き出し前に OFF に）
- 右上 **MONO CHECK** … 押している間モノラルで聴ける（確認用。書き出し前に OFF に）
- どのタイルも、量を決めるつまみ（AMOUNT / GAIN / DEPTH など）は右側にあります

## つまみ

### MASTER
- **SPREAD** … 全セクションの効き具合をまとめて調整（0〜100%）。0% で広げる処理が全部オフ
- **MIX** … 加工した音と元の音を混ぜる割合
- **OUTPUT** … 出力音量（-12〜+12 dB）
- **GAIN MATCH**（前の AUTO GAIN。標準 ON。ボタンは画面のいちばん下、プリセット欄の左端）… 広げて大きくなった分を、元の音と同じ音量に自動で戻します（±6 dB まで、ゆっくり）。
  「大きくなったから良く聴こえる」を防いで、広がりだけを聴き比べられます。いま戻している量は IMAGE の右下に出ます

### WIDTH（帯域ごとの広さ）
- **LOW / MID / HIGH** … 低域・中域・高域それぞれの広さ。100% が元のまま、200% で Side が倍、0% でその帯域はモノラル
- **LOW | MID** … 低域と中域の境目（80 Hz〜1 kHz、標準 250 Hz）
- **MID | HIGH** … 中域と高域の境目（1.5〜12 kHz、標準 4 kHz）
- **AUTO** … 押してから曲を 6 秒流すと、帯域ごとの広さを分析して LOW / MID / HIGH を自動で合わせます
  （市販曲によくあるバランスが目安。ほぼモノラルの音には効かないので、そのときは CREATE ページを使います）

### AIR（左右の空気感）
- **GAIN** … Side の高域だけを持ち上げる量（0〜+9 dB）
- **FREQ** … 持ち上げ始める周波数（2〜16 kHz）
- Pro-Q などで「サイドだけ高域を上げる」のと同じ考え方です

### SIDE DRIVE（左右の倍音）
- **AMOUNT** … Side にだけ軽い歪みで倍音を足します。音量はそのままで、左右の成分が耳に届きやすくなります
  - 30% 前後でうっすら、100% ではっきり（Side の 200 Hz より上にだけかかります）

### DYNAMICS（アタックと音量で広さを変える）
- **TRANSIENT** … マイナスに回すと、音の出だし（アタック）を真ん中に寄せて、余韻だけ広げます
  （広げてもパンチがぼやけない）。プラスに回すと、アタックまで広げます
- **DYNAMIC** … 音が普段より静かなところ（イントロ、余韻）は広く、大きいところ（サビの頭など）は少し狭くします。
  サビで音がぼやけるのを防げます（静かなところ最大 +40%、大きいところ最大 -50%）

## CREATE ページ（生み出す）
モノラルっぽい音（ボーカル、ギター、シンセ1本など）から広がりを作るページです。
どのセクションも量のつまみは最初 0% なので、回したものだけが効きます。SPREAD も効きます。

### SHIFT（ずらし）
- **TIME** … 左右で音の始まりをずらす時間（0.1〜25 ms）。5〜15 ms くらいが自然
- **AMOUNT** … 効き具合
- **SAFE / CLASSIC R / CLASSIC L** … SAFE は「遅らせた音を左右逆向きに足す」方式で、モノラルにしても元の音のまま（おすすめ）。
  CLASSIC は片側を本当に遅らせる昔ながらのやり方（R = 右を遅らせる → 音は左寄りに聴こえる、L = その逆）。
  効果ははっきり出ますが、モノラルにすると少しシャリっとした音になります

### DOUBLE（ダブル）
- **AMOUNT** … 効き具合
- **DETUNE** … 少し高い音と少し低い音を作って左右逆向きに足すときの、ずらす量（0〜20 セント）。軽く揺れも付けています。
  同じフレーズを2回録って左右に振ったような感じになります

### BANDS（ばらまき）
- **AMOUNT** … 効き具合
- **BANDS** … 200 Hz〜8 kHz を何本の帯域に分けるか（4〜12）
- **ALT / TILT** … ALT は分けた帯域を交互に左・右へ振ります。TILT は「左は明るく、右は暗く」のなだらかな版

### HAZE（もわっと）
- **AMOUNT** … 効き具合
- **SIZE** … 広がりの雲の大きさ（小さいとタイト、大きいとふわっと）
- **CLOUD / SMOOTH** … CLOUD は左右で違う短い反射で包みます。SMOOTH はまばらなランダムパルス（ベルベットノイズ）で、
  アタックを崩さずにさらっと透明に広げます

### MOTION（ゆらぎ）
- **RATE** … 揺れる速さ（0.05〜2 Hz）
- **FREE / 1/4 / 1/2 / 1 BAR / 2 BARS / 4 BARS** … FREE 以外にすると、Logic のテンポに合わせて揺れます
  （例：1 BAR = 1小節で1周）。再生中は小節の頭と揺れの位置もそろいます。このとき RATE は使いません
- **DEPTH** … 揺れの深さ。広がりの量と、広がる帯域がゆっくり動いて、止まっていない立体感になります

### SAFETY（安全装置）
- **BASS MONO** … この周波数より下の Side を消して、低音を真ん中に固定（20 Hz = OFF、標準 100 Hz）
- **GUARD** … 広げすぎて左右の位相が逆になりそうなとき（相関メーターがマイナス側に行きそうなとき）だけ、
  自動で Side を少し抑えます。もともと広い音を狭めることはしません

## IMAGE の見方
- 点の雲が縦長 → 真ん中寄り、横に広がる → 広い
- **CORRELATION** … +1 に近いほど真ん中寄り、0 付近は広い、**マイナス（赤）はモノラルで音が消えやすい危険ゾーン**
- **GUARD** … GUARD が働いているときは抑えている量（dB）が出ます
- **AUTO GAIN** … AUTO GAIN で戻している量（dB）
- **WIDTH BY BAND** … 低域・中域・高域それぞれの広さ（Side が Mid より何 dB 小さいか）。右に行くほど広い。
  白い線は市販曲によくある広さの目安（AUTO と同じ基準）。0 dB 近く（赤）は Side が Mid と同じくらいで広げすぎ

## おすすめ設定（SPREAD 100%、MIX 100% から）

| 使いどころ | WIDTH (LOW / MID / HIGH) | AIR | SIDE DRIVE | TRANSIENT | BASS MONO |
|---|---|---|---|---|---|
| マスター（ほんのり） | 95 / 110 / 120 % | +1.5 dB @ 12 kHz | 0 % | 0 | 100 Hz |
| マスター（AUTO まかせ） | AUTO を押して 6 秒 | +1 dB | 0 % | 0 | 100 Hz |
| ステレオのピアノ | 80 / 120 / 135 % | +2 dB @ 10 kHz | 15 % | -40 | 150 Hz |
| シンセパッド | 100 / 150 / 170 % | +3 dB @ 8 kHz | 30 % | 0 | 120 Hz |
| ドラムバス | 70 / 110 / 130 % | +2 dB @ 10 kHz | 0 % | -70 | 150 Hz |
| ステレオのコーラス・ハモり | 100 / 140 / 150 % | +2.5 dB @ 9 kHz | 20 % | -30 | 200 Hz |

- まずは SPREAD を 0% → 100% に回して、どれくらい変わるか聴き比べるのがおすすめです
- 最後に MONO CHECK を押して、モノラルでも気持ちよく聴こえるか確認してください

### CREATE のおすすめ設定（SPREAD 100%、SHAPE は初期値のまま）

| 使いどころ | 設定 |
|---|---|
| リードボーカル（ほんのり） | DOUBLE 25%・DETUNE 6 ct、HAZE SMOOTH 20%・SIZE 40% |
| コーラス・ハモり（広く） | DOUBLE 60%・DETUNE 12 ct、SHIFT SAFE 12 ms・40%、HAZE CLOUD 30% |
| モノラルのギター | SHIFT SAFE 10 ms・50%、BANDS ALT 8 本・40% |
| ピアノ | HAZE SMOOTH 30%・SIZE 50%、DOUBLE 15%・5 ct（SHAPE で LOW を 80% に） |
| シンセパッド | HAZE CLOUD 50%・SIZE 70%、MOTION 0.2 Hz・40% |

- CREATE で広げると、左右それぞれの音量が少し（最大 +3 dB くらい）上がりますが、AUTO GAIN が ON なら自動で元の音量に戻ります
- 広げすぎて相関メーターがマイナスに行きそうになったら、GUARD が自動で抑えます

## Plugin Link：ボーカルを上げた瞬間に広がりを少し抑える（v1.3）
自作プラグイン同士が裏で情報をやりとりします。画面のいちばん下の帯の **LINK** を、つなげたいプラグイン同士で**同じ番号（1〜4）**にするだけです。
番号を変えれば、別々の組を 4 つまで同時に作れます。最初は OFF（今までどおり）。帯の左の丸が光っているときは、実際に効いています。

- 同じ LINK 番号の **Fader Pilot** がボーカルのフェーダーを**上げている（＋）間**、SPREAD を少し下げます。声が鳴っていないとき・下げているときは何もしません
- **VOCAL DUCK**（帯の右端、0〜100%、最初は 50%）… 抑える量。+6 dB 上げているとき、100% で SPREAD が半分、50% で 3/4
- 下げるのは約 50 ms、戻るのは約 400 ms でなめらかに。今どれだけ抑えているかは帯の文（`SPREAD -12 %`）でわかります
- 下げるのは SPREAD（全体の効き）だけなので、モノラル互換はそのままです。プリセットを選んでも LINK と VOCAL DUCK は変わりません

使い方の例:
1. ボーカルのトラックに Fader Pilot、オケのバス（ギター・シンセなど）に Horizon Spread を挿す
2. 両方の LINK を **1** にする
3. 再生すると、ボーカルを持ち上げている所でだけ広がりが一歩引く

- **FROM**（LINK の右、v1.3〜）… 同じ LINK に同じ種類の相手が 2 つ以上いるとき、どの Fader Pilot に合わせるか選べます。
  **AUTO** は「いちばん新しく送ってきた相手」。選んだ相手はトラック名で覚えるので、プロジェクトを開き直しても同じ相手につながります
  （その相手がいないときは `(not here)` と出て、AUTO と同じ動きになります）
- v1.3.1 … FROM（相手選び）を追加。Plugin Link のしくみを v2 にした（ほかの自作プラグインも v2 どうしでつながります）

## プリセットの保存・取り消し（画面のいちばん下）
右上のプリセットメニュー（内蔵の 11 個）とは別に、自分の設定を保存できます。
- **UNDO / REDO** … つまみの操作を 1 手ずつ取り消し・やり直し（100 手まで。画面を閉じても残ります。オートメーションの動きは入りません）
- **< >** … 前／次の自分のプリセット。真ん中の名前を押すと一覧（Save as... / Delete / Show preset folder in Finder）
- **SAVE** … 今のつまみに名前を付けて保存（~/Library/Audio/Presets/MyPlugins/Horizon Spread。Logic のプリセットと同じ場所）。呼び出した後につまみを変えると、名前の後ろに * が付きます
- LINK の番号はプリセットで変わりません

## 中身
入力 → CREATE（SHIFT → DOUBLE → BANDS → HAZE で Mid から Side を作って足す → MOTION）→ Mid / Side に分解 → Side を4帯域に分割（24 dB/oct のクロスオーバー。Mid も同じ位相回転を通して位相を揃える）
→ 帯域ごとの幅 → AIR（Side のハイシェルフ）→ TRANSIENT（速い包絡と遅い包絡の差でアタック検出）
→ SIDE DRIVE（4倍オーバーサンプリングで倍音の差分だけを作って足し、音量は自動で戻す）
→ DYNAMIC → GUARD（Side が Mid に迫りすぎたら抑える）→ MIX → AUTO GAIN → OUTPUT → SIDE SOLO / MONO CHECK → 出力
（MIX と GUARD の基準になる「元の音」は、CREATE を通す前の入力）

- 遅れ（レイテンシー）：約 61 サンプル（48 kHz で 1.3 ms）。Logic が自動で補正します
- 負荷：全部 ON にしても 1 コアの約 1.7%（Apple シリコン）
- 入力がモノラルのトラック（Logic の「Mono → Stereo」で挿す）にも対応

## テストで確認したこと
- SPREAD 0%：周波数特性が完全に平ら（±0.00 dB）、左右の漏れ -140 dB 以下
- 全部最大にしても、モノラルにした音は元と同じ（差 -147 dB）
- WIDTH・BASS MONO・AIR が想定どおりの量だけ効く
- SIDE DRIVE 0% では倍音ゼロ、100% で倍音 -16 dB、音量は ±0.1 dB 以内
- TRANSIENT -100：アタックの Side が約 -30 dB、余韻は変化なし
- GUARD：広げすぎた音の相関を -0.32 → +0.11 に戻す。元から広い音は削らない
- つまみを 30 秒間めちゃくちゃに動かしても発振・暴走なし（CREATE を含む全部のつまみ）
- CREATE を全部 0% にすると、前の版（1.0.0）とまったく同じ音
- CREATE（SAFE 系）と SHAPE を全部最大にしても、モノラルにした音は元と同じ（差 -140 dB）
- モノラルの音への効き（相関、+1 = 真ん中）：SHIFT SAFE +0.04、DOUBLE +0.54、BANDS ALT +0.80 / TILT +0.57、HAZE CLOUD +0.18 / SMOOTH +0.01
- DOUBLE：1 kHz の音から、ちょうど ±8 セントの音（1004.6 Hz / 995.4 Hz）ができる
- GUARD：CREATE で広げすぎた音の相関を -0.67 → +0.13 に戻す
- AUTO GAIN：広げて +2.5 dB 大きくなった音を、元の音量（差 0.01 dB）に戻す
- SIDE SOLO：出てくる音は Side と同じ（差 -140 dB）。モノラルの音で CREATE なしなら無音
- DYNAMIC 100%：音が大きいところの Side が -6 dB、静かなところは広がる
- 帯域メーター：HIGH の WIDTH を 200% にすると HIGH の表示だけ +6 dB 動く
- CLASSIC L：左が 10 ms 遅れ、右はそのまま

## インストール（Logic）
1. GitHub の Actions の実行結果ページ下の「Artifacts」から「HorizonSpread-macOS」をダウンロードして解凍
   （または Releases の「latest」から `HorizonSpread.zip`）
2. ターミナルで:
   ```
   cp -R ~/Downloads/*/*.component ~/Library/Audio/Plug-Ins/Components/
   xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/Components
   ```
3. Logic を起動 → Audio Units → MyPlugins → Horizon Spread
   出ないときは「Logic Pro → 設定 → プラグインマネージャ」で再スキャン

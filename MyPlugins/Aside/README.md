# Aside（アサイド）… ひとりごと秘書

**Num Deck のボタン（または ⌃⌥M）を押してから「明日の3時までに見積もり送る」のように一言言うと、リマインダーに入れる** Mac アプリです。
時刻のある打ち合わせなどは、カレンダーの予定になります。メニューバー（画面右上）の吹き出しのアイコンで待っています。

- **ふだんはマイクを閉じています**。押したときだけ開き、言い終わったら（または 12 秒話さなければ）自動で閉じます（v1.1.0）
- 声は **Mac の中だけ** で文字にします（外のサーバーに送りません。それができない Mac では聞きません）
- 声も文字も、やることにならなかったものは残しません
- 設定で「いつも聞く」にすると、ボタンなしで、きっかけの言葉（あとで・〜しなきゃ など）があるつぶやきだけを拾う形にもできます

## Num Deck から使う

1. Num Deck のタイルをクリック → **Aside（ひとりごと秘書）** → **一言メモ（押してから話す）**
2. そのキーを押す → 右上に「どうぞ。やることを一言」と出る → 話す
3. 言い終わると「リマインダーに入れました」と出ます。違っていたら **取り消し**（「最後のメモを取り消す」もタイルにできます）
4. 聞いている途中でもう一度押すか、右上の窓をクリックすると、やめてマイクを閉じます

## 例

| つぶやき | 入るもの |
|---|---|
| あ、あとで請求書出さなきゃ | やること「請求書出す」 |
| 明日の3時までに見積もり送らないと | やること「見積もり送る」 明日 15:00 |
| 金曜の夜8時に田中さんと打ち合わせ、忘れないように | **予定**「田中さんと打ち合わせ」 金曜 20:00（カレンダー、10 分前に通知） |
| 来週の月曜に経費精算しなきゃ | やること「経費精算する」 来週の月曜 |
| 30分後に洗濯物取り込まないと | やること「洗濯物取り込む」 30 分後 |
| 今日は天気がいいな | （何もしない） |

- **きっかけの言葉**: あとで / 〜しなきゃ / 〜しないと / 〜しなくちゃ / 忘れないように / 忘れないうちに / メモして / リマインド / 〜しとかないと など
- **わかる日時**: 今日・明日・明後日・〇曜・来週の〇曜・20日・11月20日・11/20・3時・3時半・午後3時・朝・昼・夕方・夜・30分後・2時間後
  （「3時」だけのときは午後 3 時。時刻だけで、もう過ぎていれば明日）
- 打ち合わせ・会議・ミーティング・面談・予約・アポ などの言葉があって時刻もあれば、カレンダーの予定に

## 使い方

1. Aside を開く → 初めて「一言メモ」を押したときに「マイク」「音声認識」「リマインダー」の確認が出たら「許可」
2. 入れたものは「リマインダー」アプリの **「ひとりごと」** リストに（リストは自動で作ります）

**⌃⌥M**（control + option + M）… Num Deck のボタンと同じ「一言メモ」。一言メモでは、きっかけの言葉がなくてもメモします
（聞いている間、メニューバーのアイコンがオレンジのペンになります）

## 画面とメニュー

| 所 | 意味 |
|---|---|
| 一言メモ | 押してから一言（「いつも聞く」のときは「聞く / 聞くのを止める」になります） |
| 上の欄 | いま聞こえている文（途中）と、声の大きさ |
| 入れたもの | 新しい順。取り消し・どのつぶやきから入れたか |
| メニューバー → 取り消す | 最後に入れたものを取り消す |

## 設定

| 項目 | 意味 |
|---|---|
| いつも聞く | 最初は OFF（押したときだけ聞く）。ON にすると、きっかけの言葉のあるつぶやきをずっと拾う |
| いつも聞くとき: Logic が前にあるときは聞かない | 最初は ON（歌や録音で反応しないように） |
| きっかけの言葉がなくても全部メモ | 「いつも聞く」のとき、聞こえた文を全部やることにする（ふつうは OFF） |
| キー | 「一言メモ」のキー |
| リマインダーのリスト名 | 最初は「ひとりごと」 |
| ログインしたら起動 | いつも聞いていてほしいときは ON |

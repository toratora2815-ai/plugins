# Aside（アサイド）… ひとりごと秘書

作業中の **「あ、あとで請求書出さなきゃ」のようなひとりごとだけを拾って、リマインダーに入れる** Mac アプリです。
時刻のある打ち合わせなどは、カレンダーの予定になります。メニューバー（画面右上）の吹き出しのアイコンで、いつも聞いています。

- 声は **Mac の中だけ** で文字にします（外のサーバーに送りません。それができない Mac では聞きません）
- 声も文字も、やることにならなかったものは残しません
- **きっかけの言葉** があるときだけ動きます。ふつうのおしゃべりや歌では何もしません

## 例

| つぶやき | 入るもの |
|---|---|
| あ、あとで請求書出さなきゃ | やること「請求書出す」 |
| 明日の3時までに見積もり送らないと | やること「見積もり送る」 明日 15:00 |
| 金曜の夜8時に田中さんと打ち合わせ、忘れないように | **予定**「田中さんと打ち合わせ」 金曜 20:00（カレンダー、10 分前に通知） |
| 来週の月曜に経費精算しなきゃ | やること「経費精算する」 来週の月曜 |
| 30分後に洗濯物取り込まないと | やること「洗濯物取り込む」 30 分後 |
| 今日は天気がいいな | （何もしない） |

- **きっかけの言葉**: あとで / 〜しなきゃ / 〜しないと / 〜しなくちゃ / 忘れないように / 忘れないうちに / メモして / リマインド / 〜しとかないと など
- **わかる日時**: 今日・明日・明後日・〇曜・来週の〇曜・20日・11月20日・11/20・3時・3時半・午後3時・朝・昼・夕方・夜・30分後・2時間後
  （「3時」だけのときは午後 3 時。時刻だけで、もう過ぎていれば明日）
- 打ち合わせ・会議・ミーティング・面談・予約・アポ などの言葉があって時刻もあれば、カレンダーの予定に

## 使い方

1. Aside を開く → 「マイク」「音声認識」「リマインダー」の確認が出たら「許可」
2. あとはふだんどおり作業しながら、思いついたことをつぶやくだけ
3. 入ると右上に小さく「リマインダーに入れました」と出ます。違っていたら **取り消し**
4. 入れたものは「リマインダー」アプリの **「ひとりごと」** リストに（リストは自動で作ります）

**⌃⌥M**（control + option + M）… 「次の一言をメモする」。押してから 12 秒以内に言ったことは、きっかけの言葉がなくてもメモします
（メニューバーのアイコンがオレンジのペンになります）

## 画面とメニュー

| 所 | 意味 |
|---|---|
| 聞く / 聞くのを止める | 聞くのを止めると、マイクも閉じます |
| 上の欄 | いま聞こえている文（途中）と、声の大きさ |
| 入れたもの | 新しい順。取り消し・どのつぶやきから入れたか |
| メニューバー → 取り消す | 最後に入れたものを取り消す |

## 設定

| 項目 | 意味 |
|---|---|
| Logic が前にあるときは聞かない | 最初は ON（歌や録音で反応しないように。Logic から別のアプリに移るとまた聞きます） |
| きっかけの言葉がなくても全部メモ | 聞こえた文を全部やることにする（ふつうは OFF） |
| キー | 「次の一言をメモする」のキー |
| リマインダーのリスト名 | 最初は「ひとりごと」 |
| ログインしたら起動 | いつも聞いていてほしいときは ON |

## 確認用

```
Aside.app/Contents/MacOS/Aside --snapshot <フォルダ>
```

見本の画面を PNG に書き出します。`tools/test_parser.cpp` は、つぶやきから「やること」と日時を取り出す部分の単体テスト（17 例）。

# Twin Take

1 本だけ録った歌やギターを、「同じフレーズを 2 回（以上）録って重ねた」ように聞かせるダブラーです（Logic 用 AU）。

ふつうのダブラー（コーラスやデチューン）は、ずれ方がいつも同じなので「揺れている 1 本」に聞こえます。
Twin Take は、**音の頭ごとに**タイミング・音程（数セント）・音色・音量を選び直します。
なので、別の人（または別のテイク）が横で歌っている・弾いているように聞こえます。

- 原音は変えません（VOCAL では遅れもゼロ）。足すのはダブルだけです
- 同じ所は、再生のたび・書き出しでも同じダブルになります（曲の位置と TAKE とトラック名で決まります）

## 似ているものとの違い
- **Horizon Spread**（CREATE の DOUBLE・SHIFT）… 1 本の音のまま左右に広げる。モノにすると元の音に戻る
- **Echo Drift の Chorus Doubler・My Crystal の Detune Double** … いつも同じずれの、加工っぽい厚み
- **Twin Take** … 音ごとにずれ方が変わる「別テイク」。モノでも厚みが残る

## どこに挿すか
1. 歌・ギターのトラックの、**EQ・コンプの後、リバーブの前**に挿します
2. モノのトラックなら、Logic のプラグインのメニューで **「Mono → Stereo」** を選んで挿します
   （モノのままだとダブルが左右に広がりません。画面の上に注意が出ます）
3. 同じトラックで、Horizon Spread の DOUBLE・SHIFT とは重ねないでください（揺れが二重になります）

## 画面
- 上の帯
  - **VOCAL / GUITAR** … 使い方を選びます
  - **MONO** … 押している間だけモノで聴けます（スマホのスピーカーの確認用。保存も書き出しもされません）
  - **FACTORY PRESETS** … 内蔵プリセット
- 真ん中 … 大きいつまみ（DOUBLE・LOOSE・WIDTH・LOW KEEP）と、VOICES・TAKE
- **TAKES** … 各ダブルが、原音からどれだけずれて（横）・何セントずれているか（縦、上が高め）を点で表示します。
  音の頭ごとに点が動き、薄い点はその前の音です
- いちばん下 … Plugin Link の LINK 欄、GAIN MATCH・プリセット・取り消し（UNDO / REDO）

## 使い方（MODE）
- **VOCAL** … 原音はまん中のまま、ダブルを左右（1 本ならまん中）に足します
  - ダブルはいつも原音より 12〜45 ms 後ろにします。前に出すと、歌の位置が揺れてノリが走って聞こえるためです
  - 子音（サ行・タ行の頭）と息はダブルしません（本物の 2 本録りでもエンジニアが消す所です）。ダブルの高域も少し下げます
  - 遅れゼロなので、録音中に挿したままでも大丈夫です
- **GUITAR** … 1 本録りのギターを、原音は左・ダブルは右に置きます
  - ダブルは原音の前か後ろに 10〜25 ms ずれます（0 付近は使いません。そろうと真ん中に 1 本に聞こえるため）
  - 前か後ろかは TAKE で決まり、曲の途中では入れかわりません（音ごとに入れかわると、右だけ一瞬途切れるため）。逆がよければ TAKE を変えてください
  - このために原音を 40 ms 遅らせます。Logic が自動で補正するので、再生・書き出しの位置はずれません
  - 録音中は、Logic の **Low Latency Mode**（設定 → オーディオ → 一般）で外れます
  - LOW KEEP より下の低音は、原音をまん中に置きます（低音が片側に寄らないように）
  - DOUBLE は 0 dB くらいがおすすめです（左右の大きさがそろいます）

## つまみ
| つまみ | 中身 | 標準 |
|---|---|---|
| **DOUBLE** | ダブル 1 本の大きさ（原音に対して）。いちばん左で OFF。原音の大きさは変わりません | −6 dB |
| **LOOSE** | TIGHT ⇄ LOOSE。テイクの違いの大きさです。タイミングのずれ・音程（±2〜9 セント）・音色・音量をまとめて動かします | 30 % |
| **WIDTH** | ダブルを左右にどこまで広げるか（GUITAR は原音とダブルを左右にどこまで離すか） | 80 % |
| **LOW KEEP** | これより下はダブルしません（低音がにごらない・モノでも崩れにくい）。いちばん左で OFF | 200 Hz |
| **VOICES** | ダブルの本数（VOCAL だけ）。1 = まん中に 1 本、2 = 左右、4 = 重ね（1 本ずつ少し小さく） | 2 |
| **TAKE** | 別のテイクを引き直します（1〜8）。気に入らない所があったら変えてみてください。同じ TAKE でも、トラックが違えば別のテイクになります | 1 |
| **GAIN MATCH** | ON なら、入れても・つまみをいじっても音量が変わりません（いちばん下の欄の左端） | OFF |

## 内蔵プリセット
| 名前 | 中身 | 使いどころ |
|---|---|---|
| Lead Thick | 1 本・−8 dB・LOOSE 20 % | リードの歌をうっすら厚く（まん中のまま） |
| Lead Double | 2 本・−6 dB・LOOSE 30 % | いちばんふつうのダブル |
| Chorus Stack | 4 本・−3 dB・LOOSE 50 %・WIDTH 100 % | サビの重ね |
| Rap Tight | 2 本・−4 dB・LOOSE 10 %・WIDTH 60 % | ラップや速い言葉（ずれを小さく） |
| Guitar L-R | GUITAR・0 dB・LOOSE 40 %・WIDTH 100 % | 1 本録りのギターを左右に |

## 気をつけること
- **GUITAR はモノに弱い**です。左右を足すと、ずらした 2 本が重なって音色が少し変わります。MONO ボタンで確かめてください
- VOCAL でも、DOUBLE を 0 dB 近くまで上げると、モノで音色の凸凹が深くなります。−6 dB くらいまでが安全です
- 止めたまま（再生していない状態で）歌って聴いているときは、毎回違うダブルになります。再生中は、同じ所は同じダブルです
- 再生を始めた所・ループの頭・位置を飛ばした直後は、次の音の頭までダブルが少し違うことがあります（最初の音の頭から先は、書き出しと同じです）
- VOCAL で、伸ばしている音の途中にループ（サイクル）の頭があると、そこでダブルが 10〜30 ms ほど抜けます（LOOSE が大きいほど長い）。書き出しには出ません
- トラックの名前を変えても、ダブルは変わりません。トラックを複製すると、複製したほうは別のテイクになります

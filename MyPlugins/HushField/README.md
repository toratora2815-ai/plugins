# Hush Field

耳に刺さる響き・キンキン・ボワつきを、**鳴った瞬間だけ**自動で下げるプラグイン（Logic 用 AU）。
「動的なレゾナンス抑制」の有名な製品の**音の振る舞いを測って**、同じ考え方で作り直したオリジナル設計です
（名前・見た目は別物）。

## どうやって合わせたか
本物を Mac の中で直接動かし、テスト音（ピンクノイズ＋とがった音、色の違うノイズ、細かい音の列など）を通して、
「どこを・どれだけ・どの速さで」削るかを数百通り測りました。その数字に近づくように、Hush Field の中の数値を自動で合わせています。
- 遅延は同じ: 通常 2304 サンプル、LINEAR PHASE 3456、LOW LATENCY 0
- 削り方は「先読みして解析 → 削る量のカーブから最小位相フィルターを作ってかける」という同じ形

## 左のつまみ
- **soft / hard** … soft はなめらかに、hard はもっと深く（同じ DEPTH でおよそ 2 倍）
- **DEPTH**（0〜10）… どれだけ深く削るか。**5 までは控えめで、そこから上で急に効く**
- **DETAIL**（0〜10）… どれだけ細い山を「山」とみなすか
  - 0: 細い響きには反応せず、広い盛り上がりをなだらかに
  - 5: 山の前後 ±7% くらい
  - 10: 山のすぐ近く（±2%）だけを、とても深く
- **ATTACK**（0〜10）… 削り始める速さ。0 でほぼ即、2.5 で約 7 ms、5 で約 45 ms、10 で約 1 秒
- **RELEASE**（0〜10）… 元に戻る速さ。0 で約 0.1 秒、5 で約 0.2 秒、10 で約 1 秒

## グラフ（処理する帯域をしぼる）
上からぶら下がるオレンジが「今どこを何 dB 削っているか」、下の青がスペクトル、ミントの線が**帯域カーブ**です。
帯域カーブは「その周波数をどれくらい強く処理するか」。0 の線がふつう、上に行くほど強く、**一番下（-10）まで下げるとその帯域は処理しない**。

- **ダブルクリック**（何もない所）… 帯域を追加（最大 8 本）
- **点をドラッグ** … 左右で周波数、上下で強さ（ローカット・ハイカット・バンドリジェクトは左右だけ）
- **点の上でホイール** … 幅（Q）、カットなら急さ（SLOPE）
- **点をダブルクリック** … その帯域を ON/OFF
- **右クリック** … 形（Low cut / Low shelf / Bell / Bandpass / Band reject / Tilt / High shelf / High cut）、ソロ、ステレオのどちら側に効かせるか、削除
- **⌥（option）を押しながら点をつかむ** … つかんでいる間だけ、その帯域の音だけを聴ける（どこを狙っているか確かめる）
- 右上のメニューで、削る量の表示の深さ（6 / 12 / 24 / 48 dB）

### 例: ハイハット・シンバルの「刺さる所だけ」
プリセット **Hi-hat / cymbal - harsh only, keep air** がこの形です。
1. Low cut を 2.5 kHz に（それより下＝スティックの胴鳴りは触らない）
2. Bell を 5 kHz あたりで +4（耳に刺さる所を強めに）
3. High shelf を 10 kHz から -10（**上のシャリシャリ・空気感はそのまま残す**）
4. ⌥ を押しながら Bell の点をつかむと、狙っている帯域だけが聴こえるので、一番痛い所に合わせる

## 下の段
- **STEREO** … L/R か M/S。LINK（左右の削り方をそろえる量）、FOCUS（左/Mid だけ〜両方〜右/Side だけ）
- **MAX CUT** … これより深くは削らない（いちばん右で off）
- **TILT（low / high）** … DETAIL / ATTACK / RELEASE を、低域側・高域側で別々に何倍にするか（0.1x〜10x）
  例: 低域は ATTACK をゆっくり（ATK LO 3x）にして、低音のアタックを残す
- **OUTPUT** … MIX（原音と混ぜる）、WET（処理した音の音量）、OUT（最後の音量）
- **BYPASS / DELTA** … DELTA は「削った音だけ」を聴く
- **quality** … normal / high / ultra（解析を細かく。遅延は変わらない）
- **LOW LATENCY** … 遅延 0（録音中に）。そのかわり低域の狙いが粗くなる
- **LINEAR PHASE** … 位相を崩さない（遅延が 1152 増える）

## 上の段
- **Presets** … Init / Vocal / Hi-hat・cymbal / Acoustic guitar / De-ess / Mud cleaner / Mix bus / Master
- **A / B** … 2 つの設定を切り替えて比べる。A>B で今の設定をもう片方へ写す
- **SC** … どこを削るかを、サイドチェーンの音で決める（Logic のプラグイン画面右上の「サイドチェーン」でトラックを選ぶ）。**SC LISTEN** でサイドチェーンの音を聴く

## Plugin Link：Balance Scope と組む（v1.1）
自作プラグイン同士が裏で情報をやりとりします。画面のいちばん下の帯の **LINK**（LINK OFF / LINK 1〜4）を、つなげたいプラグイン同士で**同じ番号**にするだけです。最初は OFF。
（下の段の STEREO の **LINK** つまみ＝左右の削り方をそろえる量 とは別物です）

- **受け取る**: 同じ LINK の **Balance Scope** が見つけた「出すぎの帯域」（上位 2 か所）に、**ベルを足して強めに処理**します。
  強さは出すぎの量に応じて +2〜+8（2 か所目は控えめ）、約 0.8 秒でなめらかに出入りします。自分で置いた帯域カーブはそのまま
  - LINK 欄の右の **FOLLOW**（最初は ON）を OFF にすると、受け取らずにいつもどおり動きます
  - 帯の文の例：`Balance Scope: excess -> +4.3 at 2.87 kHz`（出すぎがないときは `Balance Scope: nothing sticking out`）
- **送る**: いまどこをどれだけ削っているか（100 Hz〜16 kHz を 16 本）。Balance Scope のグラフに青緑の棒で出ます
- **FROM**（LINK の右）… 同じ LINK に Balance Scope が 2 つ以上いるとき、どれに従うか選べます（AUTO = いちばん新しく送ってきた相手。トラック名で覚えます）

使い方の例: ボーカルに Hush Field、その後ろ（かマスター）に Balance Scope → 両方の LINK を 1 → 再生して 3 秒ほど待つ

## プリセットの保存・取り消し（画面のいちばん下）
上の段の **Presets** は最初から入っている 8 個。自分の設定は、いちばん下の右の帯で保存できます。
- **UNDO / REDO** … つまみの操作を 1 手ずつ取り消し・やり直し（100 手まで。画面を閉じても残ります）
- **< >** … 前／次の自分のプリセット。真ん中の名前を押すと一覧（Save as... / Delete / Show preset folder in Finder）
- **SAVE** … 今のつまみに名前を付けて保存（~/Library/Audio/Presets/MyPlugins/Hush Field。Logic のプリセットと同じ場所）
- LINK の番号はプリセットで変わりません

## GAIN MATCH（画面のいちばん下、プリセット欄の左端）
押して ON にすると、このプラグインを入れても、つまみをいじっても**音量が変わらなくなります**。音色の変化だけを聴き比べられます（大きいほうが良く聞こえる錯覚を消す）。
- ON にした直後と、プラグインの画面でつまみを触った後・プリセットや UNDO を使った後に、入口と出口の音量を測って補正を決めます。約 3 秒でほぼ決まり、鳴っている所が 10 秒たまったら**固定**します（演奏の強弱はそのまま残ります。短い区間で追いかけないので、音量が揺れません）
- オートメーションでつまみが動いても測り直しません（書き出しの結果が、再生を始めた位置で変わらないように）。Logic の Smart Controls・コントロール表示・MIDI コントローラーで動かしたときも測り直しません。測り直したいときは、プラグインの画面でつまみを触るか、GAIN MATCH を OFF → ON
- 上げる補正は +12 dB まで、下げる補正は −24 dB まで
- ボタンに今の補正量が出ます（例 `GAIN MATCH -4.2` = 4.2 dB 下げている。`...` は測っている途中）
- 測るのは音が鳴っている所と、止まってから 3 秒の響き・エコーの残りまで（入口・出口の両方で）。それより後の無音は数えません
- 補正量は曲と一緒に保存されます。開き直しても同じ音量です（別のトラックへコピーしたとき＝トラック名が違うときだけ、自動で測り直します）
- OFF にすると補正なし（音量が変わってもよいとき）。最初は OFF です
- コツ: 補正は「測っている間に鳴っていた部分」で決まります。歪み系は入ってくる音の大きさで必要な補正が変わるので、**曲のいちばん使う部分（サビなど）を鳴らしながら ON にする**のがおすすめです
- DELTA・SC LISTEN・帯域のソロ・BYPASS の間は効きません（戻すと覚えた補正に戻ります）。LINEAR PHASE の遅れも計算に入れています
- A/B を切り替えても GAIN MATCH の ON/OFF は変わりません

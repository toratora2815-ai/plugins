# Third Time（サード タイム）… 「3回目」検出係

Mac での操作をそっと見ていて、**同じ手順を 3 回くり返したら「この流れ、今日 3 回目です。自動にしますか？」と知らせる** アプリです。
「自動にする」を押すと、次からは **⌃⌥1** などのキー 1 つで、その手順をくり返せます。
メニューバー（画面右上）の「3」のアイコンで、いつも見張っています。

## なにを見ているか

| 操作 | 例 |
|---|---|
| アプリの切り替え | 「Google Chrome を前に」 |
| ⌘ や ⌃ のショートカット | 「⌘C（コピー）」「⇧⌘S（別名で保存）」 |
| 特別なキー | Return / Esc / Tab / F1〜F12 |
| 名前のある所のクリック | 「「保存」を押す」「「検索」の欄をクリック」「「新規フォルダ」（メニュー）」 |
| 文字の入力 | 「文字を入力」という 1 つの操作になるだけ。**打った文字の中身は記録しません** |

- 記録はこの Mac のメモリの中だけ（アプリを終わると消えます）。保存するのは「自動にした流れ」と「もう出さない」にした流れだけ
- パスワード管理アプリ（1Password・Bitwarden・パスワード・キーチェーンアクセスなど）の操作は最初から見ません（設定で足せます）

## 知らせるときのルール

- 同じ順番の操作（3〜10 個）が **3 回目** になったとき（設定で 2〜5 回目に変えられます）
- 1 回の流れが 3 分以内のもの
- 同じキーの連打や、名前のないクリック・文字の入力だけの並びは知らせない
- 流れがまだ続きそうなとき（前の回はどれも次も同じ操作だった）は、手が止まる（5 秒）まで待ってから、いちばん長い形で知らせる
- 一度知らせた流れは、その日はもう知らせない。「もう出さない」にすると、ずっと知らせない

## 自動にした流れをくり返す

1. 右上の知らせ、または一覧の「自動にする」を押す → 空いている **⌃⌥1〜9** が割り当てられます
2. そのキー（またはメニューバーの ▶、一覧の「▶ 実行」）でくり返します
   - アプリの切り替え → そのアプリを前に
   - ショートカット・特別なキー → そのキーを送る
   - クリック → 同じ名前のボタンや欄を探して押す（見つからなければ、ウィンドウの中の同じ位置をクリック）
   - **文字の入力 → そこで止まって待つ**ので、自分で入力して **⌃⌥T**（または右上の「続ける」）
3. 途中でやめるときは右上の「やめる」

※ うまくいかない所があったら、右上の知らせに理由が出ます（押す所が見つからない など）。

## 最初にやること（1 回だけ）

1. Third Time を開く → 上の帯の **「入力監視を許可」** → システム設定で Third Time を ON
2. **「アクセシビリティを許可」** → システム設定で Third Time を ON（押した所の名前を知る・くり返すために使います）
3. Third Time を開き直す
4. 「設定」→「ログインしたら起動」を ON にしておくと、いつも見張っていてくれます

## 設定

| 項目 | 意味 |
|---|---|
| 何回目で知らせるか | 2〜5 回目（最初は 3 回目） |
| 見ないアプリ | ここに書いたアプリの操作は記録しない |
| 「もう出さない」を元に戻す | 出さないにした流れを、また知らせるように |
| 今日の記録を消す | 今日見た操作を全部忘れる |

## 確認用

```
"Third Time.app/Contents/MacOS/Third Time" --snapshot <フォルダ>
```

見本の画面を PNG に書き出します。`tools/test_finder.cpp` は「3 回目」を見つける部分の単体テスト（3 回目で 1 度だけ知らせる、連打・遅い流れ・出さないにした流れは知らせない、2 万操作でも 1 ms 以下）。

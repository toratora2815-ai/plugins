# Flipside

**何でも逆再生**するプラグイン（Logic 用 AU）。声・サンプル・ループ・ドラム、どれにも使えます。
やり方は 2 つあります。

1. **LIVE REVERSE** … トラックに挿すだけで、曲のテンポに合わせて「1 拍ごと」「1 小節ごと」などに区切って逆向きに鳴らす
2. **FILE REVERSE** … オーディオファイルを画面に落とすと、丸ごと逆向きにした WAV を作る → そのまま Logic へドラッグ

## LIVE REVERSE（トラックの上で、曲に合わせて）
1. 逆再生したいトラック（ボーカル、ドラム、サンプルなど）に挿す
2. **GRID** で区切る長さを選ぶ（1/16・1/8・1/4・1/2・1 BAR・2 BARS）
3. **REVERSE** で、どの区切りを逆にするか選ぶ
   - **EVERY SLICE** … 全部逆
   - **EVERY 2ND** … 2 つに 1 つだけ逆（普通 → 逆 → 普通 → 逆）
   - **EVERY 4TH** … 4 つ目だけ逆（フレーズの終わりだけ「キュルッ」と）
   - **OFF** … 逆にしない
4. 再生する。下の帯の **◀ REV** の枠が逆向きに鳴る所で、白い枠が今鳴っている所です

- 区切りは**小節の頭にそろいます**（Logic が再生中のとき。止まっているときは自由に区切ります）
- 逆にするには「その区切りを全部聞き終わる」必要があるので、**区切り 1 つ分だけ遅れ**ます。
  Logic がこの遅れを自動で補正するので、再生した音は**もとの位置にぴったり収まります**
  - そのぶん、このプラグインを挿したトラックで**録音しながら聞く（モニター）と遅れて聞こえます**。録るときは外すかバイパスしてください
  - GRID を変えると遅れも変わります。変えたら一度再生を止めて、もう一度再生してください
  - 曲の途中でテンポが変わる所では、区切りがずれることがあります

### つまみ
- **FADE**（1〜50 ms）… 区切りのつなぎ目をなめらかにする長さ。プチッと鳴るなら長く、歯切れよくしたいなら短く
- **MIX** … 元の音と逆再生の割合（100 % = 逆再生の枠では逆の音だけ）
- **OUTPUT** … 最後の音量

### おすすめ
| やりたいこと | GRID | REVERSE | FADE |
|---|---|---|---|
| ボーカルを全部逆に（不思議な声） | 1/2 か 1 BAR | EVERY SLICE | 10 ms |
| フレーズの終わりだけ逆に | 1/4 | EVERY 4TH | 6 ms |
| ドラムループを崩す | 1/8 | EVERY 2ND | 3 ms |
| キック・スネアを「吸い込む」音に | 1/4 | EVERY SLICE | 2 ms |
| 逆と順を混ぜる | 1/2 | EVERY SLICE | MIX 50 % |

## FILE REVERSE（ファイルを丸ごと逆に）
1. Finder からオーディオファイル（WAV / AIFF / FLAC / MP3 / M4A など）を、下の点線の箱に落とす（箱をクリックして選んでも OK）
2. 右に **◀ ファイル名 reversed.wav** の箱が出たら完成。保存先は「ミュージック → Flipside」
3. その箱を**ドラッグして Logic のトラックに落とす**と、逆向きの音がそのまま入ります（箱をクリックすると Finder で表示）

- **TRIM SILENCE**（標準 ON）… 頭と終わりの無音（-60 dB より小さい所）を切ります。
  元の音の終わりの無音が逆にすると頭に来て「鳴り出しが遅い」ことになるのを防ぎます
- 端には 3 ms の短いフェードを入れて、プチッと鳴らないようにしています
- 元のファイルは変えません（いつも新しいファイルを作ります。同じ名前があれば番号を付けます）
- 20 分までのファイルに対応

### コツ: 「逆再生リバーブ」（声の前に吸い込む響き）
1. 声を FILE REVERSE で逆にして Logic に入れる
2. そのトラックにリバーブ（Nebula など）を 100 % でかけて、バウンスする
3. バウンスしたファイルを、もう一度 FILE REVERSE で逆に → 声の手前から響きが吸い込まれる音になる

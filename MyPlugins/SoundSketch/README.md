# Sound Sketch（サウンド スケッチ）

探したい音を **口で言う** と、手元のサンプル（Splice でダウンロードした音など）から似ている順に並べる Mac アプリです。
「ドゥン」→ キック、「ツッ」→ ハット、「パッ」→ スネア、「シューッ↑」→ ライザー、のように探せます。

## 使い方

1. Sound Sketch を開く（最初は `~/Splice/sounds` を自動で読み込みます）
2. 左の赤い丸を押す（またはスペースキー）→ 探したい音を口で言う
3. 言い終わって少し黙ると自動で止まり、似ている順に並びます（1 位はすぐ鳴ります）
4. 気に入った音は
   - **クリック** … 試聴（もう一度クリックで止める）
   - **ドラッグ** … そのまま Logic のトラックへ
   - **ダブルクリック** … 「この音に似た音」をさらに探す
   - **右クリック** … Finder で表示・場所をコピー

※ 初めて録るときは「マイクへのアクセス」の確認が出るので「許可」を押してください。録った声は保存しません。

## 画面

| 所 | 意味 |
|---|---|
| 名前でしぼる | ファイル名やフォルダ名に入っている文字でしぼる（スペースで区切ると全部入っているもの） |
| すべて / キック / スネア … | 音の種類でしぼる（ファイル名とフォルダ名から当てています） |
| ▶ 自分の声 | さっきの口マネを聴き直す |
| マイク… | 使うマイク（入力）とスピーカー（出力）を選ぶ |
| フォルダ… | 探すフォルダを足す・外す。Splice の音、Logic の Apple Loops、ミュージック フォルダはワンクリックで足せます |
| % | 似ている度（口マネとの近さ。数字そのものより順番を見てください） |

## うまく探すコツ

- **長さもまねる**: 短い音は短く「ツッ」、伸びる音は「ツーー」
- **明るさをまねる**: 低い音は口をすぼめて「ドゥ」「ボン」、高い音は歯で「ツ」「チッ」「シッ」
- **動きをまねる**: 上がる音は「シューッ↑」と高くしていく、下がる音は「ヒューン↓」
- 種類が決まっているなら、先に「キック」などでしぼると早い
- いい音が見つかったら、ダブルクリックで「それに似た音」を広げていくと速い

## Splice について

- 探せるのは **この Mac にダウンロード済みの音** です（Splice のアプリでダウンロードした音は `~/Splice/sounds` に入ります）
- まだダウンロードしていない Splice の全カタログは、Splice の公開の仕組み（API）がないため、ここからは探せません
  （全カタログから探したいときは、Splice のアプリ自体の「音で探す」機能を使ってください）

## しくみ（くわしく知りたい人向け）

1 つの音から 48 個の数字（音量の形・明るさとその動き・ノイズっぽさ・帯域のバランス・長さ・立ち上がり）を取り出して比べています。
声はキックほど低く、ハットほど高くは出せないので、口マネの明るさは広げてから比べます。
読み込んだ結果は `~/Library/Application Support/Sound Sketch/index.bin` に保存され、次からは変わったファイルだけ読み直します。

## 確認用

```
"Sound Sketch.app/Contents/MacOS/Sound Sketch" --snapshot <フォルダ> <口マネの wav>
```

画面を PNG に書き出します。`tools/test_engine.cpp` は特徴の取り方の単体テスト（作った音で、口マネから正しい種類が 1 位に来るか）。

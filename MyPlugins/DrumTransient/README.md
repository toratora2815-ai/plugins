# Drum Transient

ドラム専用のトランジェント・リミッター（Mac の Logic Pro 用 AU）。
ドラムを何 dB 突っ込んでも、**アタック（鳴り始めの数 ms）が死なず、胴（その後の鳴り）も揺れない**ことだけを考えたリミッターです。
普通のリミッター（2 ミックスやマスター）は Pro-L2 に任せて、こちらはキック・スネア・ドラムバスに挿します。

この Mac に入っている市販のマスター用リミッター（アタックと胴を別々に抑える方式のもの）を実際に音を通して測り、
抑え方の形（天井を越えた分をどう下げるか、抜けたあとどう戻るか）をドラム用に合わせ込んだオリジナルです。名前・見た目は使っていません。

## つまみ
- **PUSH**（0〜20 dB）… どれだけ突っ込むか。出口はいつも CEILING ちょうどまで（越えません）
- **PUNCH**（0〜100%）… アタックをどれだけ残すか。上げるほど、アタックで胴まで下げなくなります（＝アタックの先だけを短く切る）。0% は普通のリミッターに近い
- **BODY**（−100〜+100）… 胴（鳴り終わりの響き）を下げる／上げる。＋で部屋鳴り・余韻が前に出て「つぶした」感じ、−で短くタイトに。0 は何もしない
- **CLIP / LIMIT**（CLIP 0〜100%）… アタックの先を **切る（クリップ）** か、**なめらかに下げる（リミット）** かの割合。
  CLIP を上げるとガツッと前に出て大きく聞こえ、LIMIT 寄りはきれいで丸い
- **RELEASE**（TIGHT ⇄ SMOOTH）… 下げたあと戻る速さ。TIGHT は速く戻って大きく・荒く、SMOOTH はゆっくりで自然
- **LOW KEEP**（OFF / 60 / 90 / 120 / 160 Hz）… この周波数より下は切らない（キックの基音を濁らせない）。808 など伸びる低音には 120〜160 Hz
- **CEILING**（−0.1 / −0.3 / −1.0 dB）… 出口の上限
- **LINK** … 左右を同じ量で下げる（最初は ON。OFF にするとスネアの位置が左右に揺れることがあります）
- **DELTA** … 削った分だけを聴く（どこを削っているか確かめる用）

## LEARN（上の LEARN ボタン）
ドラムを鳴らしながら押すと、鳴っている所を 5 秒聞いて、ちょうどいい **PUSH を 1 回だけ**入れます（LISTEN ○% → PUSH ○ dB と出ます）。
- 「ちょうどいい」は、ヒットごとに切った量（ATTACK）の大きい方（上位 1 割）が、内蔵プリセットごとの目標になる所です。
  Kick・Drum Bus 3 dB、Snare・Breaks 4.5 dB、Init・Room 4 dB、Smash 12 dB（手で選んでいないときは前の目標のまま、最初は 4 dB）
- 1 発だけの強打には引っ張られません。小さすぎて届かないときは 20 dB、もう一度押すと途中でやめます
- 入れた後は GAIN MATCH が測り直します
- PUSH のオートメーションを Touch / Latch にして再生中に押すと、入れた値がオートメーションに書き込まれます（Read のままなら書き込まれません）

## 流れる表示（右）
約 3 秒分を右から左へ流します。
- **青い帯（上から）** … 胴をなめらかに下げた量（BODY）
- **オレンジのトゲ（帯の下に続けて）** … アタックの先を切った量（ATTACK）。上端からトゲの先までが、合わせて削った量です
- **薄い灰色（真ん中）** … 入口の波形（PUSH の後）
- 目盛りは -6 / -12 dB。上の数字は少しの間の最大値

キックのアタックだけにトゲが出て、帯が薄ければ「アタックは残って胴は揺れていない」状態です。帯が厚いときは PUSH を下げるか PUNCH を上げます。

## 内蔵プリセット（上の Presets）
| 名前 | 使いどころ |
|---|---|
| Kick | キックのトラック。基音は切らずに（LOW KEEP 120）、アタックを残す |
| Snare | スネアのトラック。先を切って前に出し、胴を少し |
| Drum Bus | ドラム全体のバス |
| Room / Overheads | ルーム・オーバーヘッド。響きを前に出す（BODY ＋40） |
| Breaks / Loops | サンプルのブレイク・ドラムループを太く |
| Smash (parallel) | 思い切りつぶす。センドで並列に混ぜる用 |

## おすすめの使い方
1. ドラムバスに挿して Presets →「Drum Bus」
2. PUSH を上げていき、ATTACK メーターが 3〜6 dB 振れるくらいに
3. アタックが寂しければ PUNCH を上げる、痛ければ CLIP を下げる（LIMIT 寄りに）
4. **GAIN MATCH を ON にして**聴き比べる（リミッターは大きくなるので、そのままだと何でも良く聞こえます）
- キックとベースが重なる曲・808 では LOW KEEP を 120〜160 Hz に
- DELTA でスネアの胴が丸ごと聞こえるなら、削りすぎ（PUSH を下げるか PUNCH を上げる）

## キック・スネアの迫力（Fire Box と 2 つで）
Fire Box →（その後ろに）Drum Transient の順に挿し、両方の自分のプリセット（画面いちばん下の名前）から同じ名前を選びます。
「キック迫力」「キック迫力 808」「スネア迫力」の 3 つ（~/Library/Audio/Presets/MyPlugins の Fire Box と Drum Transient に置いてあります）。
- Fire Box で太くして（LOUD は OFF。天井は Drum Transient の CEILING だけ）、Drum Transient でアタックを残して止める
- 2 つ挿した状態を Logic の「チャンネルストリップ設定」に保存すると、次からは 1 クリックで呼び出せます
  （チャンネルストリップのいちばん上の「設定」ボタン →「チャンネルストリップ設定を別名で保存…」）
- 遅れは 2 つ合わせて約 59 ms（再生は Logic がそろえます。録音中のモニターには向きません）

## スネアの大きさ（1.1.0）
低音の少ない音（スネア・ハイハット寄りのループ）は、アタックの先を多めに切って前に出します（低音の割合は 0.3 秒かけてゆっくり見るので、ドラムバスで打つたびに変わりません）。
キック・808 など低音の多い音は今までどおりです。

## 遅れ
先読みとクリッパーのために約 9.0 ms（48 kHz で 431 サンプル。1.0.0 は 7.8 ms）遅れます。Logic が自動でそろえるので再生では問題ありません。
録音中のモニターに挿すと遅れて聞こえるので、録音のときは外してください。

## 中身
PUSH → BODY（遅い包絡と速い包絡の差で鳴り終わりを上げ下げ）→ 胴のリミッター（先読み 5 ms、アタックは PUNCH の割合だけ無視、2 段の戻り）
→ クリッパー（4 倍オーバーサンプリング、切ったことで出た歪みの LOW KEEP より下は捨てる。低音の少ない音は、戻した後の行き過ぎももう一度切る）→ 仕上げのリミッター（先読み 1.5 ms）→ CEILING

## プリセットの保存・取り消し（画面のいちばん下）
- **UNDO / REDO** … つまみの操作を 1 手ずつ取り消し・やり直し（100 手まで。画面を閉じても残ります）
- **< >** … 前／次の自分のプリセット。真ん中の名前を押すと一覧（Save as... / Delete / Show preset folder in Finder）
- **SAVE** … 今のつまみに名前を付けて保存（~/Library/Audio/Presets/MyPlugins/Drum Transient。Logic のプリセットと同じ場所）
- LINK の番号と GAIN MATCH はプリセットで変わりません

## GAIN MATCH（画面のいちばん下、プリセット欄の左端）
押して ON にすると、このプラグインを入れても、つまみをいじっても**音量が変わらなくなります**。音色の変化だけを聴き比べられます。
- ON にした直後と、画面でつまみを触った後・プリセットや UNDO を使った後に、入口と出口の音量を測って補正を決めます。約 3 秒でほぼ決まり、鳴っている所が 10 秒たまったら固定します
- 最後がリミッターなので、**下げる補正だけ**です（上げると CEILING を越えるため）
- DELTA の間は効きません
- 最初は OFF。補正量は曲と一緒に保存されます

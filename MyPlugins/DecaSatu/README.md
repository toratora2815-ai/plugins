# Deca Satu（デカ・サチュ）

トラック 1 本ずつに挿す「色付けの歪み（サチュレーター）」です。
軽く挿せば太さと前に出る感じ、上げればザラッとした歪み、PUNISH で完全につぶれた音まで作れます。
手持ちの市販サチュレーターをこの Mac で測り、音の響き・歪み方・つぶれ方（鳴り始めや音が止まったあとの戻り方まで）を合わせ込んだオリジナルです。

## つまみ

| つまみ | 何をするか |
|---|---|
| STYLE（A / E / N / T / P） | 歪み方の性格。下の表を見てください |
| DRIVE（0〜10） | 歪みの量。上げるほど音が大きく・汚くなる |
| PUNISH | DRIVE にさらに約 +14 dB 足す。DRIVE 10 でも足りないとき |
| LOW CUT（20 Hz〜1 kHz） | 歪みの「前」で低域を切る。低音でにごるとき、ここを上げると歪みがすっきりする |
| THUMP | LOW CUT の切れ目に山を足す。低域を切っても「ドン」は残したいとき |
| TONE（−12〜+12 dB） | 明るさ。＋で明るく（低域が減る）、−で暗く（高域が減る）。大部分は歪みの前に効く |
| HIGH CUT（1〜20 kHz） | 歪みの「後」で高域を切る。シャリシャリを落とす。STEEP を押すと急な切れ方 |
| MIX（0〜100%） | 元の音と混ぜる。50% くらいで「太さだけ足す」パラレル処理になる |
| OUTPUT（−24〜+6 dB） | 最後の音量 |

### STYLE の性格

| STYLE | 性格 | 向いているもの |
|---|---|---|
| A | 丸くて素直。高域が少しやわらかい | ボーカル、ベース、全体を少し温かく |
| E | 明るく開いた音。プラスとマイナスで歪み方が違い、ザクッとする | スネア、ギター、前に出したいもの |
| N | 高域が少し暗く、中域が太い。ゆっくり形が変わる | ベース、キック、ドラムバス |
| T | 低い中域に重さ。DRIVE の幅が控えめで、鳴り始めをつかんでつぶす | ドラム、パーカッション |
| P | 低域が締まり、低い中域にパンチ。いちばんガリッとする | シンセ、ドラムを派手に、壊したい音 |

## 画面のいちばん下

- **GAIN MATCH**（プリセット欄の左端）… ON にすると、入れても DRIVE をいじっても音量が変わりません。
  DRIVE を回している最中も、測ってあった量だけ自動で出口を下げます（元の機材の「AUTO」と同じ量）。残りの差は数秒で測って合わせます。
  「歪みが良くなったのか、ただ大きくなったのか」をだまされずに判断できます。OFF なら自由
- **プリセット**（保存・読み込み）と **取り消し・やり直し**
- **LINK 欄** … 前に Gain Stage を挿して同じ LINK 番号にし、MATCH を ON にすると、出口を Gain Stage の TARGET の大きさにそろえます（GAIN MATCH が ON の間はお休み）

## おすすめ設定

| 使いみち | STYLE | DRIVE | その他 |
|---|---|---|---|
| ボーカルを少し前に | A | 2〜3 | MIX 60%、HIGH CUT 12 kHz |
| ベースを小さいスピーカーでも聞こえるように | N | 4〜5 | LOW CUT 80 Hz ＋ THUMP、MIX 50% |
| スネアの芯を太く | E | 5 | TONE −3 dB、HIGH CUT 10 kHz |
| ドラムバスをつぶして派手に | T | 6〜7 | MIX 40%、LOW CUT 60 Hz |
| シンセを壊す | P | 8 ＋ PUNISH | HIGH CUT 6 kHz STEEP |

コツ: GAIN MATCH を ON にして、音量の差にだまされずに DRIVE を決めてください。

## メモ

- 遅れは約 1 ms（52 サンプル、48 kHz のとき）。Logic が自動で合わせるので気にしなくて大丈夫です
- 中では 4 倍の細かさで計算して、歪みで出る耳障りな折り返しノイズを抑えています（96 kHz 以上では 2 倍・1 倍）

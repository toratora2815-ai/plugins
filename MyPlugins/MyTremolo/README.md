# My Tremolo（マイ・トレモロ）

音量を周期的に揺らす「トレモロ」の全部入りです。
本人の Mac にある市販のトレモロ・プラグインを実際に音を通して測り、揺れ方（形・リズム・スウィング・アクセント・入力の大きさへの反応）と、
音の色付け（7 種類の頭打ち・コンプ）を、同じ動きになるように合わせ込んだオリジナルです（名前・見た目・プリセット名は別物）。

- 種類: エフェクト（AU）。Logic では「Audio Units → MyPlugins → My Tremolo」
- 遅れ: 28 サンプル（Logic が自動で補正します）

## 画面の上: つまみ 9 個

| つまみ | 何をする | 目安 |
|---|---|---|
| INPUT | トレモロに入る音量。上げると STYLE の歪み・潰れが強くなる | 0 dB |
| DEPTH | 揺れの深さ。100 % で波の底では音が消える | 40〜100 % |
| GROOVE | 左 = シャッフル、右 = スウィング。2 回ずつ組にして、1 回目を長く（短く）する | 0、ハネる曲は右へ 10〜25 % |
| FEEL | 揺れ全体を拍より前（左 = Rush、走る）／後ろ（右 = Drag、もたる）にずらす | 0、ゆったりなら右へ少し |
| ACCENT | 右 = 2 拍ごとの頭（「1」）だけ強く、ほかを弱く。左 = 頭だけ抜ける | 0 |
| RATE | 自分のテンポ（BPM）。SYNC が OFF のときに使う。TAP で叩いて決められる | 120 |
| WIDTH | 右チャンネルの揺れを先にずらす。100 % で左右が逆になり「オートパン」に | 0（ステレオ感なら 30〜100 %） |
| LOW KEEP | この周波数より下は揺らさない（ベース・キックがポンプしないように） | OFF（ミックスの中なら 120〜180 Hz） |
| OUTPUT | トレモロの後の音量（STYLE の出口側の頭打ちに入る量） | 0 dB |

- **SYNC**（RATE の下）: ON なら Logic のテンポと小節の位置にぴったり合わせて揺れます（いつも ON がおすすめ）
- **STYLE**（右上）: 音の色付け
  - Digital … 何も足さない。出口だけ −0.1 dB で硬く頭打ち
  - Smooth … 2 段の柔らかい頭打ち（標準。大きい音ほど丸くなる）
  - Even … 偶数倍音が多い、温かい歪み
  - Squeeze … 2:1 くらいのコンプで軽く潰す
  - Dense … Squeeze に近く、高い音ほど強く潰す
  - Crunch … 高い音ほど早く歪む
  - Grit … 小さい音から非対称に荒れる（音量は −6 dB ほど下がる）
  - Pump … 極端なコンプ（とても小さくなるので OUTPUT か GAIN MATCH で戻す）
- **FACTORY PRESETS**（右上）: 内蔵プリセット 30 個（つまみ・形・パターンを一度に入れる）

## RHYTHM と SHAPE（つまみの下）

- **RHYTHM** … 揺れ 1 回の長さ。4 Bars 〜 1/32、付点（.）と 3 連（T）もあります。**Pattern** にすると下の RHYTHM タブで描いたリズム
- **SHAPE** … 揺れの形。Sine・Triangle・Square・Soft Square・Round Square・Ramp Up / Down・Trapezoid・Classic・Double Dip・Vintage 1〜5（昔のアンプのトレモロふう）・**Custom**（自分で描く）

## 左下: 今の揺れ方

1 小節（またはリズムの長さ）分の「音量の動き」と、今の再生位置（オレンジの線）。つまみを回すとすぐ形が変わります。

## 右下のタブ

### SHAPE（形を描く）
- SHAPE を **Custom** にすると点を動かせます: クリック = 点を足す、ドラッグ = 動かす、option を押しながらクリック = 消す
- **EDIT** … 今の形を Custom に写して、それを元に描き直す
- **SMOOTH** … 0 = 点から点へ階段状、100 = なめらかにつなぐ。下の選択で曲線の種類（Linear / Sine / Exp / Sym / Rev）
- **SAVE / LOAD** … 描いた形をファイルに保存（`~/Library/Audio/Presets/MyPlugins/My Tremolo/Shapes`）

### RHYTHM（リズムを描く）
- 小節数（1〜4）・拍子（2〜7 拍）・升目（1/4〜1/32）を選んで、升目をクリック = 鳴らす／休み
- shift を押しながら（または右クリック）= 前の 1 回を伸ばす（長い揺れ 1 回にする）。ドラッグでまとめて塗れます
- 1 つの「鳴らす」升目で、選んだ形が 1 回まるごと鳴ります。休みの所は音が消えます（DEPTH 100 % のとき）
- **FILL / CLEAR / SAVE / LOAD**。使うときは RHYTHM を **Pattern** に

### ENVELOPE（入力の大きさで揺れ方を変える）
- **THRESHOLD** … この大きさを超えたら効き始める（まわりの輪が入力の大きさ。赤 = 超えている）
- **ATTACK / RELEASE** … 効き始め・戻りの速さ
- **RATE MOD** … 大きい音ほど速く（+）／遅く（−）、単位はオクターブ。+4 以上にすると「リングモジュレーター」のような音程感のある音になります
- **DEPTH MOD** … + = 大きい音ほど深く（静かな所は浅く）、− = 大きい音ほど浅く（アタックを残す）
- **Env / Gate** … Env = 超えた量に応じて、Gate = 超えたら全開

## 画面のいちばん下

- **LINK 欄**: Fader Pilot（ボーカルに挿したもの）と同じ LINK 番号にすると、歌っている間だけ揺れを浅くできます（VOCAL DUCK の % だけ浅く）
- **GAIN MATCH**（プリセット欄の左端）: ON にすると、挿しても・つまみを回しても音量が変わらないように自動でそろえます（既定 OFF）
- **プリセット欄**: 自分のプリセットの保存・読み込み、UNDO / REDO
  - 自分のプリセットに入るのは「つまみの値」です。描いたパターンと形は、それぞれのタブの SAVE で保存してください（Logic のプロジェクトにはどちらも保存されます）

## おすすめの使い方

1. **ギターのトレモロ**: FACTORY → Amp Trem 系 → DEPTH 60〜80 %、RHYTHM 1/8 か 1/8T、STYLE Smooth
2. **エレピ（Rhodes・Wurli）のステレオトレモロ**: Stereo Keys Pan、WIDTH 50〜100 %、LOW KEEP 150 Hz
3. **シンセパッドを刻む**: Square Gate 1/8 か Soft Chop 1/16、DEPTH 100 %、GROOVE 右へ 10 %（ハネ）
4. **ブレイクの前だけ刻む**: RHYTHM Pattern で 1 小節の後半だけ升目を塗る → オートメーションで DEPTH を上げる
5. **歌の後ろで揺らす**: パッドに挿して LINK を Fader Pilot と同じ番号に、VOCAL DUCK 50 %

## 注意

- WIDTH を大きくしたオートパンは、モノラルにすると揺れが打ち消されて「ただ音量が下がった」ように聞こえます。モノで聴く場面がある曲では 50 % 以下に
- Pump と Grit は音量がかなり下がる色付けです。GAIN MATCH を ON にするか OUTPUT で戻してください
- RATE MOD を大きくした状態で SYNC 中は、速さが変わっている間だけ拍からずれ、戻ると拍に合わせ直します

# Gain Stage

トラックの**入口の音量を、ワンクリックで「ちょうどいい大きさ」にそろえる**プラグイン（Logic 用 AU）。
後ろにつなぐコンプやサチュレーター（Wool Fuzz / Porch Drive など）は、入ってくる音量で効き方が大きく変わります。
最初に Gain Stage でそろえておくと、プリセットや README の「おすすめ設定」が、そのとおりの効き方になります。

## 使い方
1. トラックの**いちばん最初**（ほかのプラグインより上）に挿す
2. 曲のいちばんよく鳴る所（サビなど）を再生する
3. **LEARN** を押す → 音が鳴っている所だけを 5 秒ぶん測って、自動で止まる
4. **GAIN** が「TARGET になる値」に自動で入る。OUT のメーターの白い線（TARGET）あたりに緑のバーが来ていれば OK

- LEARN は**押したときに 1 回だけ**ゲインを決めます。そのあとは自動で動きません（プロジェクトに保存されます）
- 測っている途中でもう一度押すと、それまでに測った分で決めます
- 無音や息（-60 dB より小さい所）は数えません。無音だけだったときは「No signal…」と出て、ゲインは変わりません
- GAIN は手で直すこともできます（ダブルクリックで 0 dB）
- 遅れ（レイテンシー）はゼロです

## つまみ・ボタン
- **GAIN** … かけるゲイン（-36〜+36 dB）。LEARN で自動で入る
- **TARGET** … そろえたい大きさ（-36〜0 dB、最初は -18 dB）。ダブルクリックで -18 dB に戻る
- **RMS / PEAK** … 何で測るか
  - **RMS**（普通はこちら）… 平均の大きさ。プラグインの効き方はこちらで決まることが多い
  - **PEAK** … いちばん大きい瞬間。ピークをそろえたいとき（ドラムの単発など）
- **Ø POLARITY** … 極性（波形の上下）を反転。2 本のマイクで録った音が打ち消し合うときに
- **MONO** … 左右を足してモノラルに
- **SWAP L/R** … 左右を入れ替え
- **IN / OUT メーター** … 緑が RMS、オレンジの線がピーク（0 dB 近くで赤）、白い線が TARGET
- 下の帯 … 最後に LEARN した結果（測った大きさと、決めたゲイン）

## おすすめの TARGET
| 使い方 | TARGET | 測り方 |
|---|---|---|
| ふつうのトラック（ボーカル・ギター・シンセ） | -18 dB | RMS |
| 歪み系（Wool Fuzz / Porch Drive）の前 | -18 dB | RMS |
| ドラムの単発・打楽器 | -10 dB | PEAK |
| 小さめにしたいパッド・アンビエンス | -24 dB | RMS |

-18 dB（RMS）は、多くのアナログ機材をまねたプラグインが「ちょうどいい」と想定している大きさです。

## Fader Pilot との違い
- **Gain Stage** … 最初に 1 回だけ決めて、あとは動かない（入口の準備）
- **Fader Pilot** … 曲の間ずっと、フェーダーを自動で上げ下げし続ける（音量のばらつきをならす）

両方使うときは「Gain Stage → （EQ・コンプなど）→ Fader Pilot」の順がおすすめです。

## Plugin Link：Balance Scope に GAIN を知らせる（v1.1）
自作プラグイン同士が裏で情報をやりとりします。画面のいちばん下の帯の **LINK** を、つなげたいプラグイン同士で**同じ番号（1〜4）**にするだけです。最初は OFF。
- Gain Stage は、今の GAIN・TARGET・RMS/PEAK・LEARN したか・入口と出口の音量を送ります
- 同じ LINK の **Balance Scope** の帯に `Gain Stage +4.5 dB (learned)` のように出ます。
  「このトラックは入口でどれだけ持ち上げてあるか」を、Balance Scope を見ながら確かめられます
- 音は何も変わりません（知らせるだけ）
- 同じ LINK の **Wool Fuzz / Porch Drive** は、MATCH が ON なら出口の音量を Gain Stage の TARGET にそろえます（Gain Stage が **RMS** のときだけ）。
  歪みを深くしても音が大きくならないので、音色だけで比べられます

## プリセットの保存・取り消し（画面のいちばん下）
- **UNDO / REDO** … つまみの操作を 1 手ずつ取り消し・やり直し（100 手まで。画面を閉じても残ります。オートメーションの動きは入りません）
- **< >** … 前／次の自分のプリセット。真ん中の名前を押すと一覧（Save as... / Delete / Show preset folder in Finder）
- **SAVE** … 今のつまみに名前を付けて保存（~/Library/Audio/Presets/MyPlugins/Gain Stage。Logic のプリセットと同じ場所）。呼び出した後につまみを変えると、名前の後ろに * が付きます
- LINK の番号はプリセットで変わりません

## メモ
- メーターの RMS は、0 dB のサイン波で -3 dB になる測り方です
- モノラル・ステレオどちらのトラックにも挿せます
- PLUGIN_CODE: Gnst

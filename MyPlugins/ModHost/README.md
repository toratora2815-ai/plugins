# Mod Host（モッド・ホスト）

好きな AU エフェクトを **この中に読み込んで**、そのプラグインの **どのつまみでも** 自動で動かすための「入れ物」プラグインです。
Logic の Modulator は音源にしか効きませんが、Mod Host に入れたエフェクトなら、リバーブの MIX でもディレイのフィードバックでも動かせます。

- 例: キックが鳴った瞬間だけリバーブの MIX を下げる（SIDECHAIN）
- 例: ディレイのフィードバックを 4 小節かけて上げる（LFO・SAW UP・4 BARS）
- 例: フィルターの周波数を 16 分で段々に動かす（STEPS）

## 使い方

1. トラックのエフェクトに「Audio Units → MyPlugins → Mod Host」を入れる
2. 上の **CHOOSE A PLUGIN ▾** から、中に入れるエフェクトを選ぶ（メーカーごとに並んでいます）
   - 選んだプラグインの画面が、Mod Host の上半分に出ます（**HIDE UI** で隠せます）
3. 下の **MOD 1〜4** のタブで、動かし方を選ぶ（下の「モジュレーターの種類」）
4. 行の **LEARN** を押してから、中のプラグインの動かしたいつまみを少し回す → その行につながります
   - または、行の名前のところ（「— choose a knob ▾」）をクリックして、一覧から選ぶ
5. 行の横長のバー（AMOUNT）で、どれだけ動かすかを決める（-100〜+100 %。マイナスにすると逆向き）
   - つないだ直後は +50 % になります。ダブルクリックで 0 %
   - 右の線: **白い縦線＝つまみの元の位置**、**色の丸＝今の位置**
6. いらなくなった行は右の **X** で外す（つまみは元の位置に戻ります）

中のプラグインのつまみを手で回すと、そこが新しい「元の位置」になり、そこを中心に動きます。
1 つの MOD から 4 か所まで、全部で 16 か所までつなげます。同じつまみに 2 つの MOD をつなぐと足し算になります。

## モジュレーターの種類（TYPE）

| 種類 | 動き | 使うつまみ |
|---|---|---|
| **LFO** | 波の形でくり返し揺らす | SHAPE（SINE / TRIANGLE / SAW UP / SAW DOWN / SQUARE）、SYNC＋長さ か RATE、PHASE（始まりの位置） |
| **ENV (input)** | 入ってくる音の大きさに合わせて動く | ATTACK（上がる速さ）、RELEASE（戻る速さ）、GAIN（感度。上げると小さな音でも大きく振れる） |
| **SIDECHAIN** | 別のトラックの音の大きさで動く（キックなど） | ENV と同じ |
| **RANDOM** | でたらめに動く（再生するたびに同じ動き） | SYNC＋長さ か RATE、SMOOTH（0 = 段々、上げると、なめらかに移る） |
| **STEPS** | 段の値を順番に（ステップシーケンサー） | SYNC＋1 段の長さ か RATE、STEPS（段の数）、SMOOTH。右の画面をドラッグして段を描く |

- **SYNC**: ON で曲のテンポに合わせる（1/32〜8 BARS。T は 3 連、. は付点）。再生中は曲の位置にぴったり合うので、何度再生しても同じ場所で同じ動きになります
- **BI / UNI**: BI は元の位置から上下に、UNI は元の位置から片側（AMOUNT がプラスなら上だけ）に動きます。ENV と SIDECHAIN は UNI がおすすめ

### サイドチェーンのつなぎ方（Logic）

Mod Host の画面の右上にある「サイドチェーン」のメニューから、キックなどのトラックを選びます。
MOD の TYPE を **SIDECHAIN** にすると、そのトラックの音で動きます。

## 通り道（BANDS ページ）

上の **MOD / BANDS / MORPH** ボタンで下の画面を切り替えます。BANDS ページでは、中のプラグインの前後をこう通します。

入力 →（帯域に分ける）→ 送る分 × **DRIVE** → 中のプラグイン → **MIX** で元の音と混ぜる → **AUTO GAIN** → **OUT**

| つまみ | 何をするか |
|---|---|
| **DRIVE** | 中のプラグインに入れる音量（-24〜+24 dB）。歪み系なら、ここを上げると深く歪む。元の音側は変わらない |
| **MIX** | 中のプラグインを通った音と元の音の割合。MIX のない歪みでもパラレル（芯を残して歪みを足す）にできる |
| **OUT** | 最後の音量 |
| **AUTO GAIN** | 入口と出口の音量を比べて、出口を自動でそろえる（-24〜+12 dB、約 0.5 秒で追う）。「大きくなったから良く聞こえる」を防いで、音色だけで比べられる。入口が静かな間（リバーブの残りだけの所）は動かない |
| **BANDS** | ON で LOW / MID / HIGH の 3 つに分け、帯域ごとに **SEND**（中のプラグインへ送る量）を決める。送らなかった分はそのまま通る |

- グラフの **縦の線をドラッグ** で帯域の分け目（SPLIT LOW 40 Hz〜2 kHz / SPLIT HIGH 500 Hz〜16 kHz）を動かす
- グラフの **帯域をクリック** で、その帯域の SEND を 0 % ⇔ 100 %（BANDS が OFF のときは、最初のクリックで ON）
- 分け方は Linkwitz-Riley（足し合わせると元どおりになる分け方）。BANDS を ON にして SEND を全部 100 % にしても音は変わりません
- 元の音は、中のプラグインの遅れ（レイテンシー）の分だけ遅らせて混ぜるので、ずれません

### 前後の比較（見える化）

帯域を分けるのは Mod Host なので、中のプラグインのグラフには帯域分けや MIX の影響が出ません。そこで Mod Host が、自分に入ってきた音と出ていく音を比べて見せます。

- グラフ: **灰色 = 入口（IN）**、**オレンジ = 出口（OUT）** のスペクトル（見やすいように高音側を少し持ち上げて描いています）
- 下の 3 つの箱: 帯域ごとに
  - **LEVEL** … 出口が入口より何 dB 大きいか（オレンジ = 大きくなった、青 = 小さくなった）
  - **WIDTH** … 広がり（サイドの割合 %）が入口 → 出口でどう変わったか
- 数字は約 1 秒でならしてあります。帯域の分け目は SPLIT の位置。BANDS が OFF でも、その分け目で比べます

## MORPH ページ（2 つの設定の間を行き来）

1. 中のプラグインのつまみを好きな形（A）にして **STORE A**
2. つまみを別の形（B）にして **STORE B**（MORPH は自動で B 側に）
3. **MORPH** のバーを動かすと、A と B で違うつまみが全部いっしょに動きます
   - 切り替え式のつまみ（ON/OFF・種類など）は真ん中で切り替わります
   - MOD で動かすには、行き先に「◆ Mod Host: MORPH」を選ぶ（例: SAW UP・4 BARS でクリーン → ぐしゃぐしゃへ）
- MORPH を使っている間、A と B で違うつまみは MORPH が決めます（手で回しても MORPH を動かすと戻ります）。**CLEAR** でやめる

## Mod Host 自身のつまみも MOD で動かせる

行の名前のところをクリック →「◆ Mod Host」から、DRIVE / MIX / OUT / MORPH / SEND LOW・MID・HIGH / SPLIT LOW・HIGH を選べます。
- 例: ENV → DRIVE（強く弾いた所だけ深く歪む）、SIDECHAIN → MIX（キックの間だけリバーブを引っ込める）、LFO → SPLIT HIGH（歪む帯域が動く）

## 画面のいちばん下（LINK・プリセット・取り消し）
### Plugin Link：ほかの自作プラグインの数値で動かす
自作プラグイン同士が裏で情報をやりとりします。いちばん下の帯の **LINK**（LINK OFF / LINK 1〜4）を、つなげたいプラグイン同士で**同じ番号**にするだけです。最初は OFF。
番号を変えれば、別々の組を 4 つまで同時に作れます。帯の左の丸が光っているときは、相手とつながって効いています。
- MOD の TYPE を **LINK (Fader Pilot / Balance Scope)** にすると、同じ LINK の相手が送る数値で動きます
  - **Fader Pilot** がいれば、そのフェーダー位置（-12〜+12 dB を 0〜100 %）。例: ボーカルを持ち上げている間だけ、オケのリバーブの MIX を下げる
  - Fader Pilot がいなければ **Balance Scope** のオケの音量（-60〜0 dB を 0〜100 %）。例: オケが大きい所でディレイを控えめに
  - ATTACK / RELEASE でならし、GAIN で振れ幅を大きくできます。BI / UNI や AMOUNT はほかの種類と同じ
- 帯の文の例：`Fader Pilot ride -> LINK = 62 %`。相手が見つからないときは `waiting for Fader Pilot or Balance Scope`
- **FROM**（LINK の右）… 同じ LINK に同じ種類の相手が 2 つ以上いるとき、どれを使うか選べます（AUTO = いちばん新しく送ってきた相手。トラック名で覚えます）

### 自分のプリセットと取り消し
- **UNDO / REDO** … つまみの操作を 1 手ずつ取り消し・やり直し（100 手まで。画面を閉じても残ります）
- **< >** … 前／次の自分のプリセット。真ん中の名前を押すと一覧（Save as... / Delete / Show preset folder in Finder）
- **SAVE** … 今のつまみに名前を付けて保存（~/Library/Audio/Presets/MyPlugins/Mod Host。Logic のプリセットと同じ場所）
- プリセットに入るのは Mod Host 自身のつまみ（MOD の設定・AMOUNT・DRIVE / MIX など）だけです。中に入れたプラグイン、つないだ先、STEPS の段、MORPH の A / B は入りません
- LINK の番号はプリセットで変わりません

## おすすめ設定

- **キックでリバーブをよける**: 中に Lumen Rooms などのリバーブを入れる → MOD 2 を SIDECHAIN、ATTACK 2 ms、RELEASE 250 ms、UNI → LEARN で MIX（Dry/Wet）→ AMOUNT -60 %
- **ディレイのフィードバックを 4 小節で上げる**: MOD 1 を LFO、SHAPE = SAW UP、SYNC ON、4 BARS、UNI → フィードバックの元の位置を低めにして AMOUNT +60 %
- **ベースを低音はそのままで歪ませる**: 中に Wool Fuzz → BANDS ON、SPLIT LOW 150 Hz、LOW の SEND 0 %、MIX 60 %、AUTO GAIN ON → DRIVE で歪みの深さを決める
- **高い所だけ響かせる**: 中にリバーブ（Lumen Rooms など）→ BANDS ON、LOW と MID の SEND 0 %、SPLIT HIGH 3 kHz（WIDTH の数字で広がった量が見える）
- **クリーン → クランチを 4 小節で**: 中に Porch Drive → GAIN を低くして STORE A、上げて STORE B → MOD 1 を LFO・SAW UP・4 BARS・UNI、行き先「◆ Mod Host: MORPH」AMOUNT +100 %
- **フィルターを 16 分で刻む**: MOD 4 を STEPS、1/16、STEPS 8、SMOOTH 10 % → カットオフに AMOUNT +70 %、段を描く
- **ゆらゆらコーラス風**: MOD 3 を RANDOM、1/2、SMOOTH 100 %、BI → ピッチやディレイタイムに AMOUNT +10 %

## メモ

- 中に入れたプラグインの設定・つないだ先・元の位置は、Logic のプロジェクトと一緒に保存されます
- 開いた Mac にそのプラグインが入っていなくても、保存し直して中身が消えることはありません
- Mod Host の MOD の設定と AMOUNT（16 か所）は Logic のオートメーションで動かせます
- つないだつまみは約 1.3 ms（64 サンプル）ごとに動かしています。つないでいないときは中のプラグインをそのまま 1 回で通します
- 中のプラグインの遅れ（レイテンシー）は、そのまま Logic に伝えます
- 中に入れられるのは AU のエフェクト（Mod Host 自身は入れられません）
- **Logic 純正のエフェクト（ChromaVerb、Pedalboard、Channel EQ など）は AU ではないので入れられません**。自作のプラグイン（Wool Fuzz、Porch Drive、Lumen Rooms など）、市販のプラグイン、Apple の AU（AUDistortion、AUDelay など）が入ります

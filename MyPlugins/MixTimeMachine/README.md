# Mix Time Machine（ミックス・タイムマシン）

Logic でバウンス（書き出し）したミックスを**自動で全部とっておいて**、
「v3 と v7、どっちが良かった？」を**音量をそろえて・同じ位置で・一瞬で**切り替えて比べる Mac 用のアプリです。

- バウンスするだけで、勝手に一覧に増えます（何も操作しなくていい）
- 同じ名前で書き出し直して上書きしても、**前の版のコピーが残っている**ので戻れます
- 音量を自動でそろえるので、「大きい方が良く聞こえる」錯覚にだまされません
- **ブラインドテスト**：どっちがどっちか伏せて5回選ぶと、本当に好きな方がわかります
- **何が変わったか**を数字と文章で表示（例：「B は低音 +1.4dB、PLR が 1.2dB 低い＝潰れている」）

プラグインではなく単体のアプリです。Logic の音には触らないので、Reference Monitor と同時に使っても大丈夫です。

---

## インストール

1. Actions の実行結果ページの「Artifacts」から **MixTimeMachine-macOS** をダウンロード
   （または Releases の「latest」から `MixTimeMachine.zip`）
2. 解凍して出てきた `Mix Time Machine.app` を「アプリケーション」フォルダに入れる
3. ターミナルで次の1行を実行（ネットから落としたアプリのブロックを解除）
   ```
   xattr -dr com.apple.quarantine "/Applications/Mix Time Machine.app"
   ```
4. ダブルクリックで起動

初めて起動すると、**ミュージック › Logic** フォルダ（Logic の標準のバウンス先）を自動で見張り始めます。
そこにある `Bounces` フォルダと、各プロジェクトの `Bounces` フォルダも見ます。

## 使い方

### いつもの流れ
1. Mix Time Machine を起動したままにしておく
2. Logic でミックスを直して、いつも通りバウンス（ファイル → バウンス → プロジェクトまたはセクション）
3. 数秒で左の一覧に新しい版が出てきます。**B に新しい版、A に1つ前の版**が自動で入ります
4. **PLAY** → **スペース**で A / B を切り替えて聴き比べる
5. 迷ったら **BLIND TEST**

### 画面

| 場所 | 説明 |
|---|---|
| SONGS | 曲の一覧。新しく書き出した曲が上 |
| VERSIONS | その曲の版の一覧（新しい順）。左の **A** / **B** を押すと、その版が A / B に入る |
| 各版の2行目 | 書き出した日時、`saved copy`（コピーあり）、`blind 4/5`（ブラインドで選ばれた回数）、メモ |
| A / B の大きいボタン | 押した方が聴こえる（スペースでも切り替え） |
| PLAY | 再生・一時停止（P キーでも） |
| LOOP | 波形の上で**ドラッグした範囲**を繰り返す。ダブルクリックで解除 |
| MATCH LEVEL | 音量を自動でそろえる（**オン推奨**）。小さい方に合わせるので音割れしない |
| ALIGN | 書き出し範囲が違っても、曲の頭のずれを自動で見つけて合わせる。下に「B aligned 120 ms」などと出ます |
| BLIND TEST | ブラインドテスト（下で説明） |
| 波形 | 上が A、下が B。クリックでその位置へ |
| WHAT CHANGED | A → B で何が変わったかの文章 |
| TONE: B − A | 音色の差（音量の差は除いてある）。0 より上 = B の方がその帯域が多い |
| NOTE... | 選んでいる版にメモを付ける（「ボーカル +1dB」「リミッター変えた」など） |
| KEEPER | 気に入った版に ★ を付ける |
| FOLDERS... | 見張るフォルダの追加・解除、コピーの保存先を Finder で開く |
| KEEP COPIES | 新しいバウンスのコピーをとっておく（**オン推奨**） |
| OUTPUT | 鳴らす先（スピーカー・ヘッドホンなど） |

### 数値の意味
| 項目 | 意味 |
|---|---|
| LOUDNESS | 曲全体の音量（LUFS）。配信サービスが音量をそろえるときに使う値 |
| PEAK | いちばん大きい瞬間（dBFS） |
| DYNAMICS (PLR) | ピークと音量の差。**小さいほど潰れている**（迫力・パンチが減りやすい） |
| LOUDNESS RANGE | 静かな所と盛り上がる所の音量差 |
| WIDTH | 広がり（サイドの割合） |

### ブラインドテスト
1. 比べたい2つの版を A と B に入れる
2. **BLIND TEST** を押す → 名前が隠れて **X / Y** になり、音量は自動でそろいます
3. スペースで X と Y を好きなだけ切り替えて聴き、良い方の **I PREFER X** / **I PREFER Y** を押す
4. 押すたびに X と Y の中身がシャッフルされます。5回やると結果が出ます
   - 5回とも同じ方 → 本当に違いがわかっていて、その版が好き
   - 4回 → たぶん好み。もう一度やると確実
   - 3対2 → **ほぼ違いがわからない**。どっちでもいいので、別の所に時間を使いましょう

サビだけ比べたいときは、波形の上でサビをドラッグして LOOP してから始めると良いです。

### キーボード
| キー | 動作 |
|---|---|
| スペース | A ⇔ B（ブラインド中は X ⇔ Y） |
| A / B | A / B を選ぶ |
| P または return | 再生・一時停止 |
| ← / → | 5 秒戻る / 進む |
| L | ループ ON/OFF |
| home | 頭（ループ中はループの頭）へ |

### 右クリック
- **版**：A に入れる / B に入れる / メモ / KEEPER / 別の曲に移す / Finder で表示 / 一覧から外す / 一覧から外してコピーをゴミ箱へ
- **曲**：名前を変える（既にある曲名を入れると、2つの曲が1つにまとまる）/ 一覧から外す

## 知っておいてほしいこと

- **曲のまとめ方**：ファイル名の後ろの飾りを取ってまとめます。`_1`（Logic が自動で付ける番号）、`demo 3`、`mix2`、`v3`、`final`、`バウンス 3`、`ミックス2` など。
  例：`DNA 2 demo 7` → 「DNA 2」、`DNA 4_9` → 「DNA 4」、`DNA 2 さらにいじる用 3` → 「DNA 2 さらにいじる用」。
  `DNA 3` のような「名前 + 数字だけ」は、数字まで曲名として扱います。違う曲に入ってしまったら、右クリック →「Move to another song...」、
  2つの曲を1つにしたいときは、曲を右クリック →「Rename / merge...」で同じ名前にする
- **コピー**：KEEP COPIES がオンだと、新しいバウンスを `ミュージック › Mix Time Machine › 曲名` に FLAC（劣化なし・元の約半分の大きさ）で保存します。
  見張り始める前から既にあったファイルはコピーしません（一覧には出ます）。それを同じ名前で上書きすると、前の音は聴けなくなります（一覧に「audio gone」と出ます）
- **書き出し中のファイル**は、大きさが落ち着いてから（約3〜5秒後）取り込みます
- 一覧から外しても、元のバウンスファイルは消えません。同じ名前で書き出し直すと、また一覧に出ます
- 設定と一覧は `~/Library/Application Support/Mix Time Machine/library.json` にあります

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| バウンスが一覧に出ない | FOLDERS... で、バウンスの保存先が見張られているか確認。違う場所なら「Add folder...」 |
| 音が出ない | 右上の OUTPUT を確認 |
| アプリが開けない | インストール手順3の xattr の行を実行 |
| 違う曲同士がまとまってしまった | 版を右クリック →「Move to another song...」 |

# Balance Scope

ミックス・マスターの周波数バランスが「理想的な右肩下がり」の範囲に収まっているか、また**参考曲とどこが違うか**を確認する解析プラグイン（Logic 用 AU）。
曲全体の音量（LUFS）とピークも同じ画面で見られます。
音は一切変えずにそのまま通します。マスタートラックの最後に挿してください。

## 画面の見方
- 白い線（AVERAGE）… 再生している間だけ解析した平均。止めている間は加算されません
- 水色の細い線（LIVE）… 直近1.5秒くらいの状態
- 青い帯（TARGET）… 目標範囲。白い線がこの中に収まっていればバランス良好
- ピンクの線（REF A / B / C）… 覚えさせた参考曲のバランス（v1.1）
- 右の4本のメーター … LOW / LOW-MID / HIGH-MID / HIGH の大まかなズレ。緑なら範囲内、オレンジならはみ出し
  - 上に「vs TARGET」と出ているときは目標カーブとの差、「vs REF A」と出ているときは参考曲との差（±2 dB 以内で緑）
- 下の帯 … ラウドネス（下の「ラウドネス」）
- RESET … 平均とラウドネスをリセット（曲や区間を変えたときに）
- 右上のメニュー … 目標カーブのジャンル切り替え

## 使い方
1. マスターに挿す → RESET
2. 確認したい区間（サビなど）を再生
3. 白い線とメーターを見て、はみ出している帯域をEQで調整

## 参考曲と比べる（v1.1）
参考曲のバランスを一度「覚えさせて」おくと、自分のミックスに重ねて表示できます。覚えたカーブはプロジェクトに保存されます（3 曲ぶん：A / B / C）。
1. 参考曲を Logic のトラックに読み込み、マスターに Balance Scope を挿す
   （参考曲の音量はどうでもよい。全体の音量差は自動で取り除いて、形だけを比べます）
2. **RESET** を押して、参考曲のサビなど比べたい区間を再生（10〜30 秒くらい）
3. 止めて **CAPTURE**。左上のメニューが「REF A」になり、ピンクの線が出ます
   - メニューで REF B / C を選んでから CAPTURE すると、そのスロットに入ります（上書き）
4. 参考曲のトラックをミュートし、**RESET** → 自分のミックスの同じような区間を再生
5. 白い線（自分）とピンクの線（参考曲）を見比べる。右のメーターは「参考曲と比べて何 dB 多い／少ないか」
6. **DIFF** を押すと、差だけのグラフになります（上に出ている帯域は自分のほうが多い、下は少ない）

- **COMPARE: OFF** にすると、今までどおり目標カーブとだけ比べます
- **CLEAR** … 今選んでいるスロットの参照カーブを消す
- 曲調が違う曲と比べると、差が大きく出るのは当然です。同じジャンル・同じような編成の曲を選ぶのがコツ

## ラウドネス（v1.1、下の帯）
ITU-R BS.1770（EBU R128）の計算方法どおりに測ります（EBU の公式テストで ±0.1 LU 以内を確認）。
- **INTEGRATED** … 測り始めてから（RESET してから）の曲全体の音量（LUFS）。**再生している間だけ**測ります
- **SHORT-TERM** … 直近 3 秒の音量
- **MOMENTARY** … 直近 0.4 秒の音量
- **PEAK** … いちばん大きかったサンプルの値（dBFS）。0 を超えそうになるとオレンジ
- **PLR** … PEAK − INTEGRATED。大きいほど抑揚（ダイナミクス）が残っている
  - 目安：8 dB より小さいと潰しすぎ、10〜14 dB なら今どきのポップス、それより大きいとおとなしめ

配信サービスの目安（INTEGRATED）：Spotify / YouTube は -14 LUFS、Apple Music は -16 LUFS くらいに音量を合わせて再生されます。
それより大きく作っても、配信では下げられるだけです。

## 目標カーブについて
ピンクノイズが平らに見える表示（1/6オクターブ帯域のエネルギー）で、1kHzを基準に右肩下がりの傾きを設定しています。
- Modern (Pop / Rock) … -1.5 dB/oct
- Bass-Heavy (Hip-Hop / EDM) … -2.0 dB/oct ＋ 120Hz以下を +3dB
- Acoustic / Jazz … -1.2 dB/oct、低域控えめ
- Cinematic / Orchestral … -2.5 dB/oct
- **Custom**（v1.1）… 傾き（CUSTOM TILT、-3.5〜0 dB/oct）と 120 Hz 以下の持ち上げ（CUSTOM LOW、-4〜+6 dB）を自分で決める。
  Custom を選ぶと、下の帯の右につまみが出ます。許容幅は ±3 dB

数値は一般的な市販曲の傾向をもとにした目安です。
全体の音量差は自動で取り除くので、音量に関係なく形だけを比べられます。

# Resume Card（リジューム カード）

作業を中断したとき、**「どこで何をしていたか」を 1 枚のカードに残して、戻ってきたときに見せる** Mac アプリです。
メニューバー（画面右上）のしおりのアイコンで、いつも待っています。

## なにが残るか

| 項目 | 中身 |
|---|---|
| 使っていたアプリ | 前のアプリと、ウィンドウの名前・開いていた書類の場所 |
| 最後に書いていた所 | カーソルの前の 2 行ぶん（パスワード欄は取りません） |
| 画面の写真 | 前のウィンドウの写真（「画面収録」を許可したとき） |
| 開いていたページ | Chrome / Safari / Brave / Edge の、各ウィンドウの前のタブ |
| ほかに開いていたもの | ほかのアプリのウィンドウと書類、Finder のフォルダ |
| メモ | 次の自分へのひとこと（カードの下の欄に書く） |

カードは `~/Library/Application Support/Resume Card/cards` にだけ保存され、外には送りません（新しい 60 枚まで）。

## いつカードになるか

- **画面ロック・スリープ・スクリーンセーバー** になったとき
- **しばらく操作しなかった** とき（最初は 5 分）
- **⌃⌥P**（control + option + P）を押したとき … 今の状態をすぐカードにして、メモを書ける画面が開きます

使っている間は 90 秒ごとに今の状態を取っておくので、画面ロックの瞬間でも直前の状態が残ります。

## 戻ってきたら

3 分以上離れていたら、「おかえりなさい。42 分前、ここまでやっていました」とカードが出ます。

| ボタン | 動き |
|---|---|
| 全部開き直す | 書類はそのアプリで、ページはそのブラウザで開き直し、最後に使っていたアプリを前に（もう開いているページはそのタブへ移るだけ） |
| 前のアプリだけ | 使っていたアプリ（と書類）だけ前に |
| 青い文字 | クリックで、そこだけ開く。写真をクリックで大きく見る |
| 閉じる | カードを閉じる（あとからメニューバー →「最後のカードを見る」か **⌃⌥R** でまた見られる） |

## 最初にやること（1 回だけ）

1. 初めて開くと上に「アクセシビリティの許可」の帯が出るので「許可する」→ システム設定で Resume Card を ON → Resume Card を開き直す
   （ウィンドウの名前・書類・書いていた所を取るのに使います）
2. 画面の写真も残したいときは「設定」→「前のウィンドウの写真も残す」→「画面収録」で Resume Card を ON
3. 最初のカードを作るときに「Resume Card が Google Chrome を制御しようとしています」と出たら「許可」（開いていたページを覚えるため）
4. 「設定」→「ログインしたら起動」を ON にしておくと、いつも待っていてくれます

## 設定

| 項目 | 意味 |
|---|---|
| 離れたら自動でカードにする | OFF にすると、⌃⌥P で作ったときだけになる |
| 操作がないとき、離れたとみなすまで | 2〜30 分（最初は 5 分） |
| 戻ったときにカードを出すのは | これより短い中断では出さない（最初は 3 分以上） |
| 書いていた文も残す | OFF にすると、カーソルの前の文は取らない |
| キー | 「いま中断する」「最後のカードを見る」のキーを変える |
| 取らないアプリ | パスワード管理アプリ（1Password・Bitwarden・パスワード・キーチェーンアクセスなど）は最初から取りません。足すこともできます |

## 確認用

```
"Resume Card.app/Contents/MacOS/Resume Card" --snapshot <フォルダ>
```

見本のカードを PNG に書き出します。

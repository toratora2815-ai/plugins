# Lumen Rooms（ルーメン・ルームズ）

映画・ポップス向けの、広くてなめらかな部屋の響きを作るリバーブです。
市販のシネマティック系リバーブの「響き方」を、実際に音を通して測り、数値で合わせ込んで作りました（中身のプログラムは一から書いたオリジナルです）。

## 仕組み（ざっくり）

1. **初期反射（EARLY REFLECTIONS）** … 音が出た直後の「壁からの跳ね返り」。左右交互に 12 個の短い跳ね返りが並びます
2. **リバーブ（REVERB）** … その後に長く続く響き。左右で別々の響きを作り、反対側へ少しだけ流し込みます（CROSSFEED）
3. 2 つを **REFL / REVERB** で混ぜて、**DRY / WET** で元の音と混ぜます

## MAIN ページ

### EARLY REFLECTIONS（初期反射）
| つまみ | 説明 |
|---|---|
| PATTERN | 跳ね返りの並び方。Natural（自然な部屋）/ Even（等間隔）/ Even Tight（細かい等間隔）/ Spreading（だんだん間が空く）/ Gathering（だんだん詰まる）/ Cluster A・B（かたまり） |
| PROXIMITY | どの跳ね返りが一番大きいか。Touching＝最初が一番大きい（音源が壁の近く）→ Backward＝後ろほど大きい（逆再生っぽい） |
| SIZE | 部屋の大きさ。跳ね返りの間隔が伸び縮みします |
| REFLECTIVITY | 壁の硬さ。上げると後ろの跳ね返りが減りにくくなります |
| DIFFUSION | 跳ね返りのにじみ。0 でパチパチ、10 でなめらか |
| WIDTH | 跳ね返りの左右の広さ（100% が標準、150% まで） |
| ROLL-OFF / SLOPE | 跳ね返りの高音を削る周波数と、削り方の強さ |
| TRIM | 跳ね返りだけの音量（いちばん左で Off） |

### REVERB（残響）
| つまみ | 説明 |
|---|---|
| TIME | 残響の長さ（0.2〜42.5 秒）。音が 60 dB 小さくなるまでの時間（RT60） |
| BLOOM | 響きがふくらむまでの時間。上げるとふわっと遅れて広がります |
| PRE-DELAY | 響きが始まるまでの待ち時間（0〜500 ms） |
| WIDTH | 響きの左右の広さ（0% でモノラル） |
| BASS MULT / BASS FREQ | BASS FREQ より低い音の残響を何倍にするか（2.0 なら低音が倍長く残る） |
| TREBLE MULT / TREBLE FREQ | TREBLE FREQ より高い音の残響を何倍にするか（0.5 なら高音が半分の長さで消える＝暗い響き） |
| ROLL-OFF / SLOPE | 響きの高音を削る |
| LOW CUT | 響きの低音を削る（こもり・濁り対策） |
| TRIM | 響きだけの音量 |
| FREEZE | 今鳴っている響きをずっと止めて鳴らし続ける（新しい音は入りません） |

### OUTPUT
| つまみ | 説明 |
|---|---|
| DRY / WET | 元の音と響きの混ぜ具合。50% で両方 0 dB、100% で響きだけ（センド用の初期値） |
| REFL / REVERB | 初期反射と残響の混ぜ具合。50% で両方 0 dB |
| OUTPUT | 響きの音量 |

## プリセット（ブラウザ・保存）
- 画面上の **プリセット名** を押すとブラウザが開きます。上の欄に文字を入れると名前やフォルダで絞り込めます
- 一覧をクリックするとすぐ読み込まれます（開いたまま次々に聴き比べられます）。左の ☆ を押すとお気に入り、**★ ONLY** でお気に入りだけ表示
- 名前の左右の **< >** で前／次のプリセットへ（★ ONLY のときはお気に入りの中で）
- **SAVE** で今の設定に名前を付けて保存。ブラウザの「My Presets」に出ます（~/Library/Application Support/MyPlugins/LumenRooms/My Presets）
- どのプリセットを読み込んでも DRY / WET と OUTPUT は変わりません

## 画面の表示
- 左の **反射** の表示：左右にドラッグで SIZE、上下で DIFFUSION（Shift で細かく、ダブルクリックで初期値）
- 右の **SHAPE**：設定から計算した「時間 × 周波数」の響きの形。左右にドラッグで TIME、上下で BLOOM
- 右の **LIVE**：今流れている音を直近 6 秒ぶん表示（青緑 = 元の音、暖色 = 響き）。**ALL / REFL / REVERB** で響き全部・反射だけ・残響だけを切り替え。クリックで一時停止
- 右上の **IN / OUT** メーター：入力と出力の大きさ（右の数字は L/R の大きいほう、dB）
- つまみはダブルクリックで初期値に戻ります

## プリセットの読み込み（参考リバーブの形式）
画面右上の **LOAD** を押すと、この Mac に入っている参考リバーブの工場出荷プリセット（約 480 個、フォルダごと）がメニューに出ます。選ぶとその設定がそのまま Lumen Rooms のつまみに入ります。
- DRY / WET と OUTPUT は変わりません（今の混ぜ具合のまま音色だけ入れ替わる）
- プリセットはこの Mac の `~/Library/Application Support/MyPlugins/LumenRooms/Presets` に控えを取ってあり、LOAD はそこから読みます（参考リバーブを消しても使えます。リポジトリには入れていません）
- 参考リバーブの「User Presets」に自分で保存したプリセットがあれば、メニューの下にまとめて出ます
- 「Open file...」で、ほかの場所の `.crp_preset` も開けます
- 読み込んだプリセット名は画面上部に表示され、Logic のプロジェクトにも保存されます
- 古い形式の 9 個（Signature フォルダの一部）は読めません
- 参考リバーブの「ダッキング／ゲート」と「コーラス系の揺らぎモード」は Lumen Rooms にないので、それを使っているプリセット（約 40 個）は少し違って聞こえます

## DETAIL ページ
- **MODULATION** … 響きのゆらぎ。REVERB DEPTH / RATE（響きの揺れ）、UNDULATION / SHAPE（響きの量のうねり。SHAPE を上げると細かく震える）、REFL DEPTH / RATE（初期反射の揺れ）
- **ECHO** … 響きの中に 1 回だけはっきりしたこだまを足す（LEVEL がいちばん左で Off）。ECHO SYNC を押すとテンポに合わせた長さ（ECHO NOTE）になる
- **PRE SYNC / PRE-DELAY NOTE** … プリディレイをテンポに合わせる
- **LOW BOOST** … 音の出だしに低音のふくらみ（ブーン）を足す。WEIGHT はふくらみが続く長さ（Tight 約 50 ms → Heavy 約 0.5 秒）
- **COLOR（REVERB / REFL）** … 響きの音色の型（A1〜H10）。読み込んだプリセットが使う型が自動で入ります。
  型のデータは参考リバーブを測って作ったもので、この Mac の `~/Library/Application Support/MyPlugins/LumenRooms/profiles.txt` にだけ置いてあります（リポジトリには入れていません）。ファイルがない Mac では COLOR は効きません
- **CROSSFEED** … 左の音を右の響きへ（右を左へ）流し込む量・遅れ・高音の削り。響きの広がり方が変わります

## EQ ページ
響き全体（初期反射＋残響）にかける EQ。EQ ON で有効。LOW CUT / LOW シェルフ / MID / HIGH シェルフ / ROLL-OFF。元の音（ドライ）にはかかりません。

## 画面のいちばん下（LINK・取り消し）
### Plugin Link：歌っている間だけ響きを下げる
自作プラグイン同士が裏で情報をやりとりします。いちばん下の帯の **LINK**（LINK OFF / LINK 1〜4）を、つなげたいプラグイン同士で**同じ番号**にするだけです。最初は OFF。
番号を変えれば、別々の組を 4 つまで同時に作れます。帯の左の丸が光っているときは、相手とつながって効いています。
- 同じ LINK の **Fader Pilot**（ボーカルのトラック）が「歌っている」と送っている間、Lumen Rooms の響きを LINK 欄の右の **VOCAL DUCK**（0〜12 dB、最初は 4 dB）だけ下げます。
  下げるのは約 0.08 秒、歌の切れ目で約 0.3 秒で戻るので、言葉ははっきり、切れ目では響きがふわっと広がります（元の音は下げません）
- VOCAL DUCK を 0 にすると何もしません
- 帯の文の例：`voice singing: reverb -4.0 dB` / `voice resting: full reverb`。相手が見つからないときは `waiting for Fader Pilot`
- **FROM**（LINK の右）… 同じ LINK に Fader Pilot が 2 つ以上いるとき、どの声に合わせるか選べます（AUTO = いちばん新しく送ってきた相手。トラック名で覚えます）

### 取り消し・やり直し
- **UNDO / REDO** … つまみの操作を 1 手ずつ取り消し・やり直し（100 手まで。画面を閉じても残ります）
- プリセットの保存・読み込みは、上の「プリセット（ブラウザ・保存）」のほうを使います（いちばん下の帯は取り消し・やり直しだけ）

## おすすめの使い方
- **ボーカル**: プリセット「Vocal Hall」。センドで DRY / WET 100%、PRE-DELAY 20〜40 ms、LOW CUT 120 Hz 前後
- **映画っぽい大きい空間**: 「Cinematic Hall」。BLOOM を上げるとゆっくり広がる
- **ドラム**: 「Tight Drum Room」。REFL / REVERB を左寄せ（跳ね返り多め）にすると部屋鳴りっぽく
- **パッド・効果音**: 「Infinite Pad」で FREEZE。鳴らしてから FREEZE を押すと響きが止まって鳴り続けます
- 暗くしたいときは、ROLL-OFF より先に **TREBLE MULT** を下げると自然です

## 測定で合わせたところ（参考）
標準設定で、音量（左右とも 0.1 dB 以内）、残響の長さ（帯域ごとに 5% 以内）、立ち上がりの形（BLOOM 0〜10 で 2 dB 以内）、初期反射の位置と強さ（12 個とも 1 dB 以内）、左右の音量、揺れの量を合わせています。
プリセットを読み込んだ状態でも、7 個のプリセットで比べて、残響の長さ・立ち上がり・音量・音色がおおむね 1〜3 dB／1 割以内です。
細かいノイズの粒は自前なので、波形まで同じではありません。

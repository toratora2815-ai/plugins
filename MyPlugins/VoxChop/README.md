# Vox Chop

**自分の声を取り込んで、別の声に変えて、切り刻んで鍵盤で弾く**音源プラグイン（Logic 用 AU・音源）。
男性の声を女性・子ども・巨人に、女性の声を男性に、どちらでもない中性的な声に。ささやき声・かすれ声・ロボット声・声とわからない音まで、
声の向きを地図（VOICE MAP）の上で自由に動かせます。切った声は鍵盤に並ぶので、ボーカルチョップ（歌を細かく切って並べ直すやり方）がすぐできます。

声は取り込んだ後で**丸ごと計算し直す**ので、遅れはありません。元のファイル・トラックは変えません。

> 正直な注意: 「本物そっくりの別人の声」にはなりません（それは AI の声変換の仕事です）。できるのは「キャラクターとしての女性・男性・子どもの声」です。
> 変える量が小さいほど自然に聞こえます。中性的な声は、少し動かすくらいがいちばんきれいです。

## 使い方
1. Logic で **ソフトウェア音源のトラック**を作り、音源の欄で「AU 音源 → MyPlugins → Vox Chop」を選ぶ
2. 声を入れる（どちらか）
   - **ファイルを落とす**: 声のファイルを波形の所に落とす（クリックか OPEN で選んでも OK）
   - **CAPTURE**（おすすめ）: プラグインの画面のいちばん上にある **「Side Chain」で歌のトラックを選ぶ** → **CAPTURE** を押す → Logic で再生 → 止めると取り込み完了
     - 範囲を切ったり、Flex で直したりした後の音がそのまま入ります。鳴っていない所は自動で落とします
     - 取り込んだ声は「ミュージック → Vox Chop → Captures」に WAV で保存され、プロジェクトを開き直しても戻ります
3. **VOICE** ページで声を変える（下の「VOICE」）
4. **SOURCE** ページで切り方を決める（自動で切れています）→ 鍵盤で弾く、または箱をドラッグで Logic へ

## SOURCE（取り込みと切り分け）
- **CHOP / WHOLE**
  - **CHOP** … 声を切って鍵盤に並べる（1 片目 = C1、2 片目 = C#1 …、最大 64 片）
  - **WHOLE** … 切らずに、声全体を変えて Logic に戻す（歌 1 本を丸ごと「男性の声 → 女性の声」にしたいとき）。鍵盤では全体が鳴ります（C3 = そのまま）
- **AUTO / GRID** … 切り方
  - **AUTO** … 言葉の切れ目・音量のくぼみで切る。**SENS** を上げるほど細かく切る
  - **GRID** … 拍で切る（1/4・1/8・1/16・1/2・1 小節）。CAPTURE したときのテンポを使います（ファイルは Logic の今のテンポ）
- **RE-CHOP** … 今の設定で切り直す（手で直した切れ目は消えます）
- 波形の操作
  - 片を**クリック** = 鳴らす・選ぶ
  - 片の**端をドラッグ** = 切れ目を動かす
  - **ダブルクリック** = そこで 2 つに分ける
  - **右クリック** = 分ける・消す・次の片とつなぐ
  - 片を**つかんで外へドラッグ** = その片を Logic へ
- 下の箱（つかんで Logic へドラッグ。ファイルは「ミュージック → Vox Chop」にできます）
  - **⇦ SLICE** … 選んでいる片だけ
  - **⇦ ALL SLICES** … 全部の片（1 片 1 ファイル）
  - **⇦ MIDI（元の並び順）** … このトラックの、箱に書いてある小節に置くと、元のフレーズがそのまま鳴ります。そこからピアノロールで音符を並べ替えると、チョップのフレーズになります
  - **⇦ WHOLE VOICE** … 声全体（VOICE の設定込み）

## VOICE（声の変え方）
### VOICE MAP（地図）
- **横 = 声の高さ**（左が低い、右が高い。Hz で表示）、**縦 = 体の大きさ**（上ほど小さい体＝子どもや女性っぽい響き、下ほど大きい体）
- 青い帯 = 男性の声の高さ、ピンクの帯 = 女性の声の高さ
- **YOU**（水色の点）= 取り込んだ声。**オレンジの点**をつかんで動かすと、声が変わります（離すと計算し直して、選んでいる片が鳴ります）
- **MAN・WOMAN・NEUTRAL・CHILD・GIANT・TINY** の名前をクリックすると、その声へ飛びます。誰の声でも、同じ名前なら同じ所へ行きます
- ダブルクリック = YOU（元の声）へ戻る

### CHARACTER（つまみ）
- **BREATH** … 声を息の音に置き換える。少し = 息っぽい・やわらかい、100 % = ささやき声
- **GRIT** … かすれ・ボーカルフライ（「あ゛」のようなジリジリした低い揺れ）・うなり声。普通の歪みではなく、声の揺れを足します
- **ROBOT** … メロディーを 1 つの音に固定する（100 % で一本調子のロボット）
- **ALIEN** … 声から離していく（体の大きさを極端に・ロボット・息・金属っぽい響きを一度に）
- **LOW CUT / HIGH CUT** … 低い所・高い所を切る（ラジオ・電話の声）

### VOICES（プリセットのタイル）
ORIGINAL・MAN・WOMAN・NEUTRAL・CHILD・GIANT・TINY・CHIPMUNK（早回し）・SLOWED（遅回し）・HELIUM・WHISPER・BREATHY・FRY・GROWL・DEMON・GHOST・ROBOT・CYBORG・ALIEN・RADIO・PHONE・MEGAPHONE・WALKIE。
クリックすると設定が入って、選んでいる片が鳴ります。そこからつまみや地図で好きに直してください。

## KEYS（鍵盤で弾く）
- 左の 8×8 のパッド = 片（クリックで鳴らす・選ぶ）
- **SLICE**（選んだ片だけの設定）
  - **PITCH** … その片の高さ（±24 半音）
  - **GAIN** … その片の音量
  - **REVERSE** … 逆再生
  - **LOOP** … 鍵盤を押している間くり返す（母音を伸ばしてパッドのように）
  - **ONE SHOT** … 鍵盤を離しても最後まで鳴らす
  - **CHOKE** … CHOKE の片どうしは重ならない（次の片が鳴ると前の片が止まる）
- **KEYS**
  - **SLICES / MELODIC** … SLICES = 1 鍵盤に 1 片。MELODIC = 選んだ片がどの鍵盤でも鳴る（C3 = そのまま）。**和音で弾くとハモリ**になります
  - **FORMANT KEEP** … ON = 高い鍵盤でも同じ人の声のまま・長さもそのまま。OFF = テープの早回しのように、高いほど体が小さく短くなる
  - **VELOCITY** … 鍵盤の強さで音量が変わる量
  - **LEVEL** … 出口の音量
- **ENVELOPE** … ATTACK（鳴り始めのフェード）・DECAY・SUSTAIN・RELEASE（離した後のフェード）

## おすすめ
- **男性の声 → 女性の声**: VOICES の WOMAN → 少しかたいなら BREATH を 10〜20 %
- **中性的な声**: NEUTRAL。または地図で、YOU から WOMAN の方へ半分くらいまで動かす
- **K-POP・フューチャーベースのドロップ**: CHOP / AUTO（SENS 60 %）→ CHILD か WOMAN → KEYS の MELODIC で和音、または SLICES で並べ替え
- **ローファイ・ヒップホップの声ネタ**: GRID 1/8 → SLOWED → RADIO を少し（LOW CUT 300 Hz、HIGH CUT 5 kHz）
- **怪物・悪魔の声**: DEMON か GROWL
- **背景の声のかたまり（アンビエント）**: 母音の片に LOOP → MELODIC で和音 → BREATH 40 %・ALIEN 20 %

## 後ろに挿すとよいもの（このプラグインには入れていません）
リバーブ = Meld Verb・Lumen Rooms、ディレイ = Echo Drift、歪み = Fire Box、広がり = Horizon Spread、サ行の痛さ = Hush Field、
ボコーダー = Logic の EVOC 20、ケロケロ（音程補正を最速に）= Logic の Pitch Correction

## 設定の保存
声のファイルの場所・切れ目・片ごとの設定は、プロジェクトに保存されます。プリセット欄（いちばん下）は声の設定（VOICE・KEYS）を保存します。切り方は変えません。

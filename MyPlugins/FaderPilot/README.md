# Fader Pilot

ボーカルの音量のばらつきを、**フェーダーを自動で上げ下げして**揃えるプラグイン（Logic 用 AU）。
コンプのように音の頭を潰すのではなく、人がフェーダーを動かすのと同じように**音量だけ**を動かすので、声の表情や音色は変わりません。
動かした量は Logic のオートメーションに書き込めるので、あとから手で直せます。

## 何をしているか
1. 入ってきた声の大きさを測る（声の帯域 120 Hz〜8 kHz、約 40 ms の平均）
2. **TARGET** との差のぶんだけフェーダーを動かす（最大 **RANGE** まで、**SPEED** の速さで）
3. **FLOOR** より小さい音（息・無音・リップノイズ）のときは、フェーダーをその位置で止めておく（持ち上げない）

- 遅れ（レイテンシー）はゼロ。録音中に挿しておいても大丈夫です
- 入口の音を測って動かすので、行ったり来たりの発振はしません

## 画面の見方
- **LEVEL HISTORY**（左の大きいグラフ、6 秒分が右から左へ流れる）
  - 灰色の線 … 入ってきた声の大きさ
  - 白い線 … フェーダーを動かした後の声の大きさ（緑の線に沿っていれば揃っている）
  - 緑の線 … 目標（TARGET、FOLLOW MUSIC のときはオケ＋OFFSET）
  - 黄色の線 … フェーダーの動き（真ん中が 0 dB、右の目盛りが ±dB）
  - 暗くなっている所 … FLOOR より小さいので動かしていない所
- **RIDE**（右）… フェーダー。AUTO RIDE が ON のときは黄色の三角が今の位置

## ボタン（右上）
- **AUTO RIDE** … ON で自動。OFF にすると、RIDE のフェーダー（＝オートメーション）の値をそのまま使います
- **WRITE** … ON にして再生すると、自動で動かしたフェーダーの動きを「Ride」パラメーターに送ります（下の「オートメーションに書く」）
- **FOLLOW MUSIC** … オケの音量に合わせるモード（下の「オケに合わせる」）

## つまみ

### LEVEL
- **TARGET** … 揃えたい声の大きさ（-40〜-6 dB）。まずは、声がいちばんちょうどいい所を再生して、白い線がそのあたりになる値に
- **FLOOR** … これより小さい音は無視する（-80〜-20 dB）。息やノイズが持ち上がるときは上げる。小さく歌っている所が持ち上がらないときは下げる

### MOTION
- **RANGE** … フェーダーを動かす最大量（±0〜15 dB）。最初は ±6 dB くらい。0 にすると何もしません
- **SPEED** … 動きの速さ（20 ms〜2 s）。速いほど言葉ごと、遅いほどフレーズごとに揃う
  - 速すぎる（50 ms 以下）と、言葉の中で音量が揺れて不自然になることがあります

### MUSIC
- **OFFSET** … FOLLOW MUSIC のとき、オケより何 dB 大きく（小さく）するか（-12〜+12 dB）

### OUTPUT
- **OUTPUT** … 最後の音量（-12〜+12 dB）

## オケに合わせる：FOLLOW MUSIC
サビでオケが厚くなったら声も上げ、静かな所では下げる、という動きを自動でやります。
1. ボーカルのトラックに Fader Pilot を挿す
2. プラグインの画面のいちばん上にある **「サイドチェーン」メニュー**で、オケのバス（ボーカル以外をまとめたバス）を選ぶ
3. **FOLLOW MUSIC** を ON。目標が「オケの音量 ＋ OFFSET」になります
   - 右上に「MUSIC -21.3 dB → aim -19.3 dB」のように、今のオケの大きさと目標が出ます
   - オケが止まっている間（-60 dB より小さい）は、フェーダーをその位置で止めておきます
- 「MUSIC: no sidechain signal」と出ていたら、サイドチェーンメニューで音の来るトラックが選ばれていません
- オケのバスにボーカルが混ざっていると、正しく測れません

## オートメーションに書く（あとから手で直したいとき）
1. AUTO RIDE と **WRITE** を ON
2. Logic でボーカルトラックのオートメーションを表示（キーボードの **A**）し、モードを **Latch**（または Touch）にする
3. 曲の頭から再生すると、自動で動いたフェーダーが「Fader Pilot → Ride」のオートメーションとして記録されます
4. 終わったら停止し、オートメーションのモードを **Read** に戻す
5. Fader Pilot の **AUTO RIDE を OFF** にする。これで記録したオートメーションどおりに動きます
6. 気になる所は、Logic のオートメーションの線を直接直してください

- WRITE が ON でも、再生していないときは何も書きません
- AUTO RIDE が ON の間は、Logic のオートメーションの「Ride」の値は使いません（自動が優先）

## おすすめ設定（右上のプリセットメニュー）

| プリセット | TARGET | FLOOR | RANGE | SPEED | FOLLOW / OFFSET |
|---|---|---|---|---|---|
| Pop Vocal | -18 | -45 | ±6 | 250 ms | OFF |
| Rap / Fast Words（言葉が速い） | -16 | -42 | ±6 | 120 ms | OFF |
| Ballad (Gentle)（ゆったり、表情を残す） | -20 | -50 | ±4 | 600 ms | OFF |
| Narration（語り・セリフ） | -18 | -45 | ±9 | 200 ms | OFF |
| Bass Guitar（ベースの音量のばらつき） | -20 | -50 | ±4 | 400 ms | OFF |
| Follow Mix (+2 dB)（オケより少し前） | — | -45 | ±6 | 300 ms | ON / +2 dB |
| Follow Mix (Behind)（オケになじませる） | — | -45 | ±6 | 400 ms | ON / -2 dB |

使い方のコツ：
- **コンプの前**に挿すのがおすすめです。Fader Pilot でフレーズの大小を揃えてからコンプをかけると、コンプを浅くしても声が前に出ます
- TARGET は、いちばん大きいサビより少し小さい所に合わせると、上げる方向の動きが中心になって自然です
- RANGE を広げすぎると、静かに歌っている所まで同じ大きさになり、表情がなくなります。±3〜6 dB で十分なことが多いです

## メモ
- モノラル・ステレオどちらのトラックにも挿せます（左右は同じだけ動かします）
- PLUGIN_CODE: Fdpl

## Plugin Link：Horizon Spread と連動する（v1.1）
自作プラグイン同士が裏で情報をやりとりします。画面のいちばん下の帯の **LINK** を、つなげたいプラグイン同士で**同じ番号（1〜4）**にするだけです。
番号を変えれば、別々の組を 4 つまで同時に作れます（例：ボーカル用は LINK 1、ギター用は LINK 2）。最初は OFF（今までどおり）。
帯の左の丸が光っているときは、相手とつながって実際に効いています。トラック名も相手に伝わるので、帯の文に「どのトラックの誰か」が出ます。

- Fader Pilot は、今のフェーダー位置（RIDE、dB）と「声が鳴っているか（FLOOR より大きいか）」を、音の処理のたびに送ります
- 同じ LINK 番号の **Horizon Spread** は、ボーカルを**上げている間だけ**広がり（SPREAD）を少し抑えます。
  ボーカルが小さくて持ち上げているところで、まわりの広がりが一歩引いて、声が真ん中で聞き取りやすくなります
- 抑える量は Horizon Spread 側の VOCAL DUCK で決めます
- 遅延ゼロのままです

使い方の例:
1. ボーカルのトラックに Fader Pilot、ギターやシンセのバス（またはオケのバス）に Horizon Spread を挿す
2. 両方の LINK を **1** にする
3. 再生すると、Horizon Spread の帯に `SPREAD -12 %` のように今の抑え具合が出る

### FOLLOW MUSIC をサイドチェーンなしで（v1.2）
オケのバス（ボーカル以外をまとめたバス）に **Balance Scope** を挿して、Fader Pilot と同じ LINK 番号にすると、
Balance Scope が測ったオケの音量で FOLLOW MUSIC が動きます。Logic のサイドチェーンの設定はいりません。
1. ボーカル以外のトラックを 1 つのバス（Aux）にまとめ、そこに Balance Scope を挿す
2. ボーカルの Fader Pilot と Balance Scope の LINK を同じ番号にする
3. Fader Pilot の FOLLOW MUSIC を ON → グラフの右上に `MUSIC (LINK) -14.0 dB -> aim -12.0 dB` と出れば OK
- サイドチェーンにも音が来ているときは、サイドチェーンのほうを使います
- Balance Scope はボーカルが入っていないバスに挿してください（マスターだとボーカル自身の音も混ざります）
- **FROM**（LINK の右、v1.3〜）… 同じ LINK に同じ種類の相手が 2 つ以上いるとき、どの Balance Scope のオケの音量を使うか選べます。
  **AUTO** は「いちばん新しく送ってきた相手」。選んだ相手はトラック名で覚えるので、プロジェクトを開き直しても同じ相手につながります
  （その相手がいないときは `(not here)` と出て、AUTO と同じ動きになります）

### ほかに Fader Pilot の情報を使うもの
- **Lumen Rooms / Elder Verb / Meld Verb** … 同じ LINK にすると、歌っている間だけ響きを下げます（各リバーブの LINK 欄の **VOCAL DUCK**、最初は 4 dB）
- **Mod Host** … MOD の種類を **LINK** にすると、フェーダー位置（-12〜+12 dB）で中のプラグインのつまみを動かせます

## プリセットの保存・取り消し（画面のいちばん下）
右上のプリセットメニュー（上の表の 8 個）とは別に、自分の設定を保存できます。
- **UNDO / REDO** … つまみの操作を 1 手ずつ取り消し・やり直し（100 手まで。画面を閉じても残ります。オートメーションの動きは入りません）
- **< >** … 前／次の自分のプリセット。真ん中の名前を押すと一覧（Save as... / Delete / Show preset folder in Finder）
- **SAVE** … 今のつまみに名前を付けて保存（~/Library/Audio/Presets/MyPlugins/Fader Pilot。Logic のプリセットと同じ場所）。呼び出した後につまみを変えると、名前の後ろに * が付きます
- LINK の番号はプリセットで変わりません

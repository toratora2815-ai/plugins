# 書記（Shoki）… 会議の書記をするアプリ

**オンライン会議（Teams・Zoom など）の自分の声と相手の声を、Mac の中だけで文字にして、Markdown（.md）に 1 行ずつ書いていく** Mac アプリです。
会議のあとに、相手の声をグループごとに聞いて名前を選ぶと、「（緑川）〜」「（釧路）〜」のような名前つきの議事録ができます。

- 声は **Mac の中だけ** で文字にします（macOS の音声認識。外のサーバーには送りません）
- 自分の声 = マイク、相手の声 = Mac から出ている音（会議アプリの音）。**ヘッドホンを使ってください**（スピーカーだと、相手の声がマイクにも入って「自分」としても書かれます）
- 書いた文字は 1 行ずつすぐ保存するので、途中でアプリが落ちても、それまでの分は残ります
- 録音・文字起こしすることは、**会議の最初に一言伝えてください**
- macOS 26 以降（Apple シリコンの Mac）

## 使い方

1. 会議に入る前に「書記」を開く（Spotlight で `Shoki`、または ~/Applications の Shoki）
2. 上の **参加者（相手）** に名前を入れる（例: `緑川、釧路`）。**自分の名前** も入れておくと、議事録の自分の行がその名前になります
3. **記録を始める** を押す
   - 初めてのときは「マイク」と「システムオーディオ録音」の許可を聞かれるので、**許可** を押す
4. 会議中は、そのままにしておくだけ。左が時刻、（自分）は青、（相手）はオレンジで出ていきます
   - 会議でミュートしている間のひとりごとを残したくないときは **自分のマイクを一時停止**
5. 終わったら **終える** → 自動で **名前を付ける** の画面が出ます
   1. 相手の声が、似ている声どうしでグループ（A、B、C…）に分かれています
   2. グループごとに **聞く** を押して（押すたびに別の発言）、**だれ？** で名前を選ぶ
   3. **名前を付けて保存** → 「議事録（名前つき）.md」ができます
6. できた議事録を Claude に渡して「**清書して**」と頼むと、いつもの議事録の書き方（手本）にそろえて、言いよどみを除き、聞き間違いを直します

## 保存されるもの

ホームの **議事録** フォルダ（`~/議事録/2026-11-18 2200 会議/` のように、会議ごとに 1 つ）。iCloud には上がりません。

| ファイル | 中身 |
|---|---|
| 記録（時刻つき）.md | 会議中に 1 行ずつ書いた記録。`[22:03:15]（相手）〜` の形 |
| 議事録（名前つき）.md | 名前を付けたあとの議事録。`（緑川）〜` の形。同じ人が続けて話した分は 1 つにまとめる |
| 自分.m4a / 相手.m4a | 音声（1 時間でそれぞれ約 15 MB）。会議中は音が欠けないよう大きい形式で録って、終わったら小さくします |
| data.jsonl / meeting.json | 名前付けをやり直すためのデータ（声の特徴など） |

- 名前の後ろの **?**（例: `（緑川?）`）は、声だけでは自信がない行です。**（?）** はだれか分からない行（名前を選ばなかったグループ）
- 名前付けはあとからやり直せます: **保存した会議…** → その会議の **名前を付ける…**

## 音声を消す

- **この会議の音声を消す…** … いま開いている会議の音声をゴミ箱へ
- **保存した会議…** … 会議ごとの音声の大きさを見て、**音声を消す**（1 つずつ）か **音声を全部消す…**
- どれも **音声ファイルだけ** をゴミ箱に入れます。文字（記録・議事録）は残ります。ゴミ箱を空にするまでは戻せます
- 音声を消したあとも名前付けはできます（「聞く」の代わりに、例の文を読んで選ぶ）

## うまくいかないとき

- **相手（Mac の音）のメーターが動かない** … システム設定 → プライバシーとセキュリティ → **画面とシステムオーディオ録音** → 下の「システムオーディオ録音のみ」で **書記** を ON。そのあと **終える** → **記録を始める** をやり直す
- **自分（マイク）のメーターが動かない** … 上の **マイク** で会議に使っているマイクを選ぶ。システム設定 → プライバシーとセキュリティ → **マイク** で **書記** が ON か
- **イヤホンを抜き差しした・AirPods に切り替わった** … 自動でつなぎ直します（数秒抜けることがあります）
- **赤い字で「文字起こしをつなぎ直しています」** … Mac の音声認識が止まったので作り直しています。数秒で戻り、その間の発言も取り戻します。「止まりました」と出たら「終える」→「記録を始める」
- **名前のグループ分けがおかしい** … **グループの数** を変えて **分け直す**。1 人の声が 2 つに分かれたら、両方に同じ名前を選んでも大丈夫です

## 精度の目安

- 文字起こし: はっきり話していればほぼ正確。人の名前・専門用語は間違えやすい（**参加者** と **言葉のヒント** に入れておくと少し良くなります）。最後に Claude の清書で直すのがおすすめ
- 名前: オンライン会議の相手は、人ごとにマイクや部屋の音が違うので、声のグループ分けはわりと当たります。1 人が短く「はい」と言っただけの行などは外れやすいので、? が付きます

## 作り方（Claude 用）

Xcode なしで、Command Line Tools の swiftc だけで作ります（GitHub Actions ではビルドしません）。

```
bash MyPlugins/Shoki/build.sh install   # 作って、この Mac 専用の署名をして ~/Applications に入れる
bash MyPlugins/Shoki/build.sh test      # 数値テスト（build/Shoki/shoki-test）
```

# Reference Monitor（リファレンス・モニター）

自分の曲（Logic Pro）と参照曲（Apple Music やファイル）を、ボタン1つ・キー1つで聴き比べる Mac 用の常駐アプリです。
プラグインではなく **単体のアプリ** なので、Logic を止めていても参照曲が鳴り、書き出し（バウンス）にも一切影響しません。

- **BlackHole 不要**：Logic とミュージックの音をアプリが直接受け取ります（macOS 14.2 以降の機能）
- 受け取った元の音は消すので、二重には鳴りません。**アプリを終了すれば、元の鳴り方に戻ります**
- Logic の出力先は今のまま（オーディオインターフェイスなど）で OK

---

## インストール

1. Actions の実行結果ページの「Artifacts」から **ReferenceMonitor-macOS** をダウンロード
2. 解凍すると `ReferenceMonitor.zip` が出てくるので、それもダブルクリックして解凍 → `Reference Monitor.app`
3. `Reference Monitor.app` を「アプリケーション」フォルダに入れる
4. ターミナルで次の1行を実行（ネットから落としたアプリのブロックを解除）
   ```
   xattr -dr com.apple.quarantine "/Applications/Reference Monitor.app"
   ```
5. ダブルクリックで起動

### 初回に出る許可（どちらも「許可」）
- **「システム オーディオ録音」**：Logic とミュージックの音を受け取るため
  - 出なかったとき・拒否してしまったとき：「システム設定」→「プライバシーとセキュリティ」→「画面とシステムオーディオ録音」→ 下の「システムオーディオ録音のみ」に **Reference Monitor** を追加してオン
- **「"ミュージック"を操作しようとしています」**：キューの位置に飛ぶため
  - あとから変えるとき：「プライバシーとセキュリティ」→「オートメーション」→ Reference Monitor →「ミュージック」をオン

※ アプリを新しい版に入れ替えたら、許可をもう一度出す必要があることがあります。

## 画面

### 上
| 表示・ボタン | 説明 |
|---|---|
| MIX / REF の文字 | 緑＝受信中。うまくいかないときの理由もここに出ます |
| **RESET METERS** | メーターを今から計り直す |
| **PIN** | ウィンドウを常に手前に表示（Logic の上に置いておける） |
| **BYPASS** | 一時的にアプリを素通しにする。Logic もミュージックも直接鳴ります。**録音するときに押す** |

### 参照曲（REF の行）
画面の幅は MacBook の画面の半分（約 740）まで細くできます。Logic を大きい画面に、Reference Monitor を MacBook の画面の半分に置く使い方ができます。
- **REF** のメニューで参照曲を選ぶ。いちばん上の **Apple Music (LIVE)** を選ぶと、ミュージックで再生中の曲が参照曲になります
- **+ ADD** か、ファイルを窓にドラッグ＆ドロップで WAV / AIFF / MP3 / M4A / FLAC を追加。何曲でも並べられます。**REMOVE** で今選んでいるファイルを外す
- 右の **LIVE APP** で、Apple Music 以外のアプリ（Safari など）を参照元にすることもできます
- その下の段に、注意やヒントがオレンジの文字で出ます

### 真ん中
| ボタン | 説明 |
|---|---|
| **MY MIX / REFERENCE** | 聴く方を切り替え（キーボードの **スペース** でも切替） |
| **PLAY / STOP** | **今聴いている側**を再生・停止（MY MIX のときは Logic、REFERENCE のときは参照曲）。表示が「PLAY (Logic)」「PLAY (Ref)」に変わります |
| **+ CUE** | 参照曲の今の位置にキュー（目印）を付ける。名前は聞かずに、すぐ **CUE 1**・**CUE 2**…と番号で付きます（v1.4.2） |
| **SET MIX** | 選んでいるキューに、**自分の曲（Logic）の今の位置**を登録する（S キーでも可）。登録するとボタンに「+MIX」が付きます |
| キューのボタン | 押すと、**参照曲も自分の曲も、それぞれのキューの位置から再生**。**ダブルクリック**で名前を付ける（「Aメロ」「サビ」など。空にすると番号だけに戻る）。**右クリック**で位置の付け直し・削除など |
| **LOOP** | 選んだキューから次のキューまでを繰り返す。2つのキューの両方に MIX 位置があれば、**Logic も同じ区間を繰り返します** |
| **CUE ON SWITCH** | 切り替えたとき、**切り替えた側だけ**選んだキューの頭に戻して鳴らす。もう片方は止めずに流れ続けます |
| 波形／バー | クリックでその位置へ移動。Apple Music の曲は波形を読めないので、**流れた所から音量の形を描いていきます**（v1.5.0。大きい所ほど高い。サビがどこか見えるので、キューを打ちやすくなります。アプリを閉じると消えます） |
| キューの線（上に三角の付いた縦線） | **つかんで左右にドラッグすると、キューの位置を動かせます** |

キューは曲ごとに保存されます（Apple Music の曲も、曲ごとに覚えます）。
自分の曲（Logic）側の位置を直したいときは、Logic をその位置に合わせて、キューを選んで SET MIX を押し直してください。

Logic のループは、Logic の位置を見ながら「区間の終わりに来たら頭に戻す」方式です。戻るときに一瞬（0.1〜0.2 秒ほど）間が空くことがあります。

### スペクトラム・メーター
プラグイン版 Reference と同じです。紫＝自分の曲、オレンジ＝参照曲、下の白い線＝音色の差（0 より上＝自分の曲の方が多い）。

グラフの左上の **TONE / WIDTH / PUNCH / LOW** で表示を切り替えます（W キーで順番に切り替え）。

**WIDTH（帯域ごとの広がり、v1.4.0）**
低（〜200Hz）・中（200Hz〜4kHz）・高（4kHz〜）それぞれで、音がどれだけ左右に広がっているか（サイドの割合）を、MIX と REF の横棒で並べます。
- 0% ＝真ん中だけ（モノラル）、50% ＝左右がバラバラ。棒の右端が 50% です
- 右に「REF is wider（参照曲の方が広い）」「Yours is wider（自分の方が広い）」「About the same（ほぼ同じ）」と出ます
- 低域が 12% を超えると「Wide lows: thinner in mono」と黄色で出ます。低音が広がりすぎていて、スマホやクラブのモノラルで鳴らすと低音が痩せます
- ほとんど音が出ていない帯域は「--」になります

**PUNCH（帯域ごとの迫力、v1.5.0）**
低・中・高それぞれで、直近 3 秒の「いちばん大きい瞬間」と「平均の音量」の差（dB）を、MIX と REF の横棒で並べます。
キックやスネアのアタックが立っているほど大きく、コンプやリミッターで潰すほど小さくなります。
「音量は同じなのに、リファレンスの方がパンチがある」ときに、どの帯域で負けているかが分かります。
- 棒の右端が 24 dB。ずっと鳴っている音（ベースの持続音など）は小さく、太鼓のように「ドン」と来て消える音は大きく出ます
- 右に「REF hits harder（参照曲の方がパンチがある）」「Yours hits harder（自分の方がある）」「About the same（ほぼ同じ）」と出ます。
  参照曲より 3 dB 以上小さいと「REF hits much harder (yours is squashed)」と黄色で出ます。潰しすぎのサインです
- 曲の同じ場所（例: サビ同士）で比べてください。静かな所と盛り上がる所では、そもそも値が違います

**LOW（低域を拡大、v1.6.0）**
20〜250 Hz だけを、TONE よりずっと細かく（約 1.5 Hz きざみ）見ます。キックとベースの重なりや、超低域（サブ）の出すぎをチェックできます。
家のスピーカーやヘッドホンでは、低音が出ているかどうかを耳で判断しにくいので、目で確かめるための表示です。
- 上のグラフ: 紫＝自分の曲、オレンジ＝参照曲。自分の曲は「全体（100 Hz〜8 kHz）の音量」を参照曲にそろえてから描くので、線の高さの差が、そのまま「全体に対して低音が多いか少ないか」です
- **点と周波数**（例「52 Hz」）: 30〜150 Hz の中でいちばん大きい所。だいたいキックかベースの一番太い音です。自分と参照曲で数字が大きくずれていたら、低音の「芯」の高さが違います
- 下の白い線: 低域の差（0 より上＝自分の曲の方が多い）
- 下の 4 つの札:
  - **SUB 20-60 Hz** … 体で感じる超低域。スマホでは聞こえないので、出すぎると音量の無駄になります
  - **BASS 60-120 Hz** … キックとベースの太さ
  - **LOW-MID 120-250 Hz** … 多いと「こもる」、少ないと「細い」
  - それぞれ参照曲との差を dB で出し、1.5 dB 以内なら緑の「same as REF」、3 dB 以上ずれると黄色の「too much / too little」
  - **MONO < 120 Hz** … 120 Hz より下が左右にどれだけ広がっているか。15% を超えると黄色で「wide bass!」（クラブやスマホのモノラルで低音が痩せます）
- SNAP したときは、点線が「SNAP したときの自分」です
- AVG が ON でも、LOW は今選んでいる参照曲と比べます

**AVG（何曲かの平均と比べる、v1.5.0）**
1 曲だけと比べると、その曲のクセに引っぱられます。2〜3 曲の「平均の音色」と比べられます（TONE 表示のとき）。
1. 参照曲を選んで、グラフの右上の **AVG** を右クリック →「Add current reference to AVG」
   - ファイルの参照曲は、曲全体をその場で解析します
   - Apple Music の曲は、**15 秒以上流してから**足してください（流した所の平均を使います。長く流すほど正確）
2. ほかの参照曲でも同じようにする（2〜3 曲がおすすめ）
3. **AVG** を押すと ON / OFF。ON のときは、オレンジの線が「AVG OF 3」（3 曲の平均）、紫の線が自分の曲の直近 20 秒の平均になり、下の白い線はその差です
4. 外したいときは、AVG を右クリック → 曲名を押す（「Remove all」で全部）

AVG の曲は保存されるので、次に開いたときも使えます。WIDTH・PUNCH・LOW は、今選んでいる参照曲と比べます。

**SNAP（さっきの自分と比べる、v1.4.0）**
グラフの右上の **SNAP**（N キーでも）を押すと、その時点の自分のミックスの音色と広がりを覚えます。
1. 自分の曲を数秒流してから SNAP を押す（直近 3 秒くらいの平均を覚えます）
2. EQ やコンプを変える
3. TONE では、**点線**が「SNAP したときの自分」です（上のグラフは音色、下は参照曲との差）。白い実線が今の差なので、点線より 0 に近づいていれば、参照曲に近づいています
4. WIDTH と PUNCH では、MIX の棒の上の**白い縦線**が SNAP したときの値です

もう一度押すと覚え直し、**右クリック**で消せます。アプリを閉じると消えます。
| メーターの行 | 意味 |
|---|---|
| **HEARD LUFS (10s)** | **実際に耳に届いている音量**（LEVEL でそろえた後）。MATCH のときは DIFF がほぼ 0 になる＝そろっている |
| 3s LUFS | それぞれの曲そのものの、直近 3 秒の音量 |
| 10s LUFS | それぞれの曲そのものの、直近 10 秒の音量。MATCH はこの差を GAIN APPLIED で埋めます |
| SECTION LUFS | 区間全体の平均。キューに飛んだとき、または 1.5 秒以上止まってから再生し直したときに計り直します |

3s / 10s / SECTION は「そろえる前の元の音量」なので、MATCH 中でも DIFF は 0 になりません（DIFF ≒ GAIN APPLIED）。

### 下
| つまみ | 説明 |
|---|---|
| LEVEL | OFF／MATCH（参照曲を自分の曲の音量に自動で合わせる・おすすめ）。MATCH の基準は**直近 10 秒の音量**なので、リミッターを足すなどして自分の曲が変わっても、10 秒以内に追いつきます |
| BAND SOLO | 全体／低（〜200Hz）／中（200Hz〜3kHz）／高（3kHz〜） |
| MORE | **LISTEN AS**（スマホ・ノートPC・イヤホン・Bluetooth スピーカー・車・クラブでの聞こえ方）と、**配信サービスの音量**（SPOTIFY・APPLE MUSIC・YOUTUBE）を選ぶメニュー（v1.5.0 で、あまり使わないのでここにまとめました）。どれかが入っているときは、ボタンが黄色になって「PHONE」などと出ます。元に戻すには、メニューで「Off (normal)」「Back to MATCH」を選びます |
| OUTPUT (A / B) | 出力先を2つ登録して A / B で切替（例：A＝スピーカー、B＝ヘッドホン） |
| STEREO | ステレオ／モノ／サイド |
| REF TRIM | 参照曲の音量を手で ±12dB（MATCH で合わせたあとの微調整用） |
| VOLUME / DIM / MUTE | 全体の音量、一時的に -20dB、消音 |

REF TRIM と VOLUME は、数字の箱を**上下にドラッグ**するか、**マウスのホイール**で変えます。**ダブルクリックで 0 dB** に戻ります（v1.4.0。前はスライダーでした）。
OUTPUT・STEREO・REF TRIM・VOLUME・DIM / MUTE は一番下の1行にまとめてあります。
ウィンドウを横に広げても、下の行のボタンや REF のメニューは伸びすぎないようにしてあります（v1.5.0）。
メーターの SPOTIFY / APPLE MUSIC / YOUTUBE の行は、MORE で配信サービスの音量を選んでいるときだけ出ます。

## Logic を操作するための設定（曲ごとに1回）

アプリから Logic を再生・停止・位置移動したり、Logic の位置を受け取ったりするための設定です。**曲（プロジェクト）ごとに保存される**ので、使う曲で1回ずつやります（いつものテンプレートに入れておけば、新しい曲では不要）。

1. Reference Monitor を起動しておく
2. Logic で曲を開き、「ファイル」→「プロジェクト設定」→「同期…」
3. 真ん中の「**MIDI**」をクリック
4. 表のいちばん上の「オフ」をクリック →「**Reference Monitor**」を選ぶ
5. 同じ行の「**MTC**」の列にチェック
6. 表の下の「**MIDI マシンコントロール（MMC）の入力を自動認識**」にチェック
7. 閉じて command + S で保存

できていれば、アプリの上の段に「Logic 0:42 playing」のように Logic の位置が出ます。

## Aメロ同士を比べる手順（おすすめ）

1. ミュージック（または左の参照曲ファイル）で、参照曲の Aメロの頭で **C**（キュー追加）→ 名前を付けたければ、そのボタンをダブルクリックして「Aメロ」に
2. Logic を自分の曲の Aメロの頭に合わせて、**S**（SET MIX）→ ボタンが「1. Aメロ +MIX」になる
3. 「1. Aメロ」を押す → 両方の曲がそれぞれの Aメロの頭から鳴る
4. **CUE ON SWITCH** をオンにしておくと、**スペース**で切り替えるたびに、切り替えた側が Aメロの頭から鳴ります
5. メーターの SECTION LUFS・DYNAMICS と、スペクトラム下の白い線で、Aメロ同士の差を確認
6. BAND SOLO で LOW / MID / HIGH ごとにも比べる

## LISTEN AS（いろんな所で鳴らしたときのチェック）

ミックスが「スマホで聴いたらベースが消えた」「車だとボーカルが埋もれた」とならないかを、その場で確かめる機能です。
**マスターにプラグインを挿さないので、外し忘れたまま書き出す心配がありません。**
参照曲にも同じ聞こえ方がかかるので、「スマホで聴いた参照曲」と「スマホで聴いた自分の曲」をスペースで聴き比べられます。

| ボタン | 再現しているもの | 聴くポイント |
|---|---|---|
| PHONE | スマホのスピーカー。300Hz より下が出ない・ほぼモノ・小さいスピーカーのリミッター | キックやベースが（倍音で）まだ感じられるか。ボーカルが前に出ているか |
| LAPTOP | ノートPC のスピーカー。低音が薄く、中域が箱っぽい | 薄くなりすぎないか。ボーカルとスネアのバランス |
| EARBUDS | 耳にゆるく入れたイヤホン。超低域が抜けて、5〜7kHz が刺さりやすい | 「サ行」やシンバルが痛くないか |
| BT SPEAKER | Bluetooth スピーカー。モノラルで、110Hz あたりがボワつく | 低音がこもらないか。モノで消える音がないか |
| CAR | 車。低音が大きく響き、ロードノイズがあり、運転席（右）側のスピーカーが近い | ノイズの中でもボーカルが聴こえるか。低音が重すぎないか |
| CLUB | クラブ。モノラル、超低域が大きく、高域は控えめ | キックとベースがぶつからずに鳴るか。モノでもノリが残るか |

- どの環境も、**音量が素の状態と同じになるように自動で補正**しています（大きい方が良く聞こえる錯覚を防ぐため）
- 本物のスピーカーそのものではなく「よくある傾向」の再現です。最後は実機でも確認してください

## 配信サービスの音量（SPOTIFY / APPLE / YOUTUBE）

配信サービスは、曲ごとの音量を自動でそろえます。**大きく作りすぎた曲は下げられる**ので、音圧を上げても得をしません。

- **MORE** から **SPOTIFY / APPLE MUSIC / YOUTUBE** を選ぶと、そのサービスと同じように、自分の曲も参照曲も上げ下げして鳴らします
  - SPOTIFY：-14 LUFS に合わせる（小さい曲は、ピークが -1dB を超えない分だけ上げる）
  - APPLE（サウンドチェック）：-16 LUFS に合わせる
  - YOUTUBE：-14 LUFS より大きい曲を下げるだけ（上げない）
- メーターの **SPOTIFY dB / APPLE MUSIC dB / YOUTUBE dB** の行に、それぞれ何 dB 下げられる（−）・上げられる（＋）かが出ます
  - 例：自分の曲 −5.0、参照曲 −3.0 なら、自分の曲は参照曲より 2dB 余分に潰しているだけで、聴く人には大きく聴こえません
- 参照曲ファイルは**曲全体**の音量で計算します。自分の曲（Logic）とライブの参照曲は、計り始めてからの平均（SECTION と同じ）で計算するので、**曲を頭から最後まで流す**と正確になります

## 知っておいてほしいこと

- **ウィンドウの位置と大きさを覚えます**（v1.3.3）。一度 MacBook の画面などに置けば、次からはそこに開きます。その画面をつないでいないときは、今ある画面の中に出ます
- Logic の音はアプリを通るので、**ほんの少し遅れます**（10〜20 ミリ秒くらい）。ミックス中は気になりませんが、**録音するときは BYPASS** を押してください
- Apple Music のループは、0.25 秒ごとに位置を見て戻すので、ファイルほどぴったりではありません
- Apple Music のライブラリの曲（コピー防止付き）も、再生中の音を受け取るので使えます
- 不具合があったら、`~/Library/Application Support/Reference Monitor/log.txt` に動作記録が残っています

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| Logic の音が聴こえない | 「画面とシステムオーディオ録音」の許可を確認。急ぐときは BYPASS |
| 「Apple Music: control not allowed」 | 「オートメーション」でミュージックの操作を許可 |
| 「Logic Pro: not running」 | Logic を起動すると数秒で自動でつながります |
| アプリが開けない | インストール手順4の xattr の行を実行 |
| 波形やメーターに何も出ない・上に「OUTPUT A is not connected」 | 選んでいた出力先（オーディオインターフェイスなど）がつながっていません。そのあいだは Mac の今の出力先で鳴らし、つなぎ直すと数秒で元に戻ります |
| PLAY (Logic) で Logic が動かない・上に「sync off」 | **今開いている Logic のプロジェクトで、同期の設定がまだ**です。「Logic を操作するための設定（曲ごとに1回）」をやってください。いつものテンプレートに入れておくと、新しい曲では不要になります |
| 音が二重に聴こえる | 起動直後の1〜2秒だけ起こることがあります。続くときはアプリを再起動 |

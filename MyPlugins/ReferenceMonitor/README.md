# Reference Monitor（リファレンス・モニター）

自分の曲（Logic Pro）と参照曲（Apple Music やファイル）を、ボタン1つ・キー1つで聴き比べる Mac 用の常駐アプリです。
プラグインではなく **単体のアプリ** なので、Logic を止めていても参照曲が鳴り、書き出し（バウンス）にも一切影響しません。

- **BlackHole 不要**：Logic とミュージックの音をアプリが直接受け取ります（macOS 14.2 以降の機能）
- 受け取った元の音は消すので、二重には鳴りません。**アプリを終了すれば、元の鳴り方に戻ります**
- Logic の出力先は今のまま（オーディオインターフェイスなど）で OK

---

## インストール

1. Actions の実行結果ページの「Artifacts」から **ReferenceMonitor-macOS** をダウンロード
2. 解凍すると `ReferenceMonitor.zip` が出てくるので、それもダブルクリックして解凍 → `Reference Monitor.app`
3. `Reference Monitor.app` を「アプリケーション」フォルダに入れる
4. ターミナルで次の1行を実行（ネットから落としたアプリのブロックを解除）
   ```
   xattr -dr com.apple.quarantine "/Applications/Reference Monitor.app"
   ```
5. ダブルクリックで起動

### 初回に出る許可（どちらも「許可」）
- **「システム オーディオ録音」**：Logic とミュージックの音を受け取るため
  - 出なかったとき・拒否してしまったとき：「システム設定」→「プライバシーとセキュリティ」→「画面とシステムオーディオ録音」→ 下の「システムオーディオ録音のみ」に **Reference Monitor** を追加してオン
- **「"ミュージック"を操作しようとしています」**：キューの位置に飛ぶため
  - あとから変えるとき：「プライバシーとセキュリティ」→「オートメーション」→ Reference Monitor →「ミュージック」をオン

※ アプリを新しい版に入れ替えたら、許可をもう一度出す必要があることがあります。

## 画面

### 上
| 表示・ボタン | 説明 |
|---|---|
| MIX / REF の文字 | 緑＝受信中。うまくいかないときの理由もここに出ます |
| **RESET METERS** | メーターを今から計り直す |
| **PIN** | ウィンドウを常に手前に表示（Logic の上に置いておける） |
| **BYPASS** | 一時的にアプリを素通しにする。Logic もミュージックも直接鳴ります。**録音するときに押す** |

### 左：参照曲リスト
- いちばん上の **Apple Music (LIVE)** を選ぶと、ミュージックで再生中の曲が参照曲になります
- **+ ADD** か、ファイルをドラッグ＆ドロップで WAV / AIFF / MP3 / M4A / FLAC を追加。何曲でも並べられます
- 下の **LIVE APP** で、Apple Music 以外のアプリ（Safari など）を参照元にすることもできます

### 真ん中
| ボタン | 説明 |
|---|---|
| **MY MIX / REFERENCE** | 聴く方を切り替え（キーボードの **スペース** でも切替） |
| **PLAY / STOP** | **今聴いている側**を再生・停止（MY MIX のときは Logic、REFERENCE のときは参照曲）。表示が「PLAY (Logic)」「PLAY (Ref)」に変わります |
| **+ CUE** | 参照曲の今の位置にキュー（目印）を付ける。付けたらすぐ名前を入れられます（「Aメロ」「サビ」など） |
| **SET MIX** | 選んでいるキューに、**自分の曲（Logic）の今の位置**を登録する（S キーでも可）。登録するとボタンに「+MIX」が付きます |
| キューのボタン | 押すと、**参照曲も自分の曲も、それぞれのキューの位置から再生**。**右クリック**で名前変更・位置の付け直し・削除 |
| **LOOP** | 選んだキューから次のキューまでを繰り返す。2つのキューの両方に MIX 位置があれば、**Logic も同じ区間を繰り返します** |
| **CUE ON SWITCH** | 切り替えたとき、**切り替えた側だけ**選んだキューの頭に戻して鳴らす。もう片方は止めずに流れ続けます |
| 波形／バー | クリックでその位置へ移動 |
| キューの線（上に三角の付いた縦線） | **つかんで左右にドラッグすると、キューの位置を動かせます** |

キューは曲ごとに保存されます（Apple Music の曲も、曲ごとに覚えます）。
自分の曲（Logic）側の位置を直したいときは、Logic をその位置に合わせて、キューを選んで SET MIX を押し直してください。

Logic のループは、Logic の位置を見ながら「区間の終わりに来たら頭に戻す」方式です。戻るときに一瞬（0.1〜0.2 秒ほど）間が空くことがあります。

### スペクトラム・メーター
プラグイン版 Reference と同じです。紫＝自分の曲、オレンジ＝参照曲、下の白い線＝音色の差（0 より上＝自分の曲の方が多い）。
**SECTION LUFS** は「区間の平均音量」です。キューに飛んだとき、または 1.5 秒以上止まってから再生し直したときに、自動で計り直します。

### 下
| つまみ | 説明 |
|---|---|
| LEVEL | OFF／MATCH（参照曲を自分の曲の音量に自動で合わせる・おすすめ）／-14 LUFS（ストリーミング基準） |
| BAND SOLO | 全体／低（〜200Hz）／中（200Hz〜3kHz）／高（3kHz〜） |
| STEREO | ステレオ／モノ／サイド |
| REF TRIM | 参照曲の音量を手で ±12dB |
| OUTPUT (A / B) | 出力先を2つ登録して A / B で切替（例：A＝スピーカー、B＝ヘッドホン） |
| VOLUME / DIM / MUTE | 全体の音量、一時的に -20dB、消音 |

### キーボード
| キー | 動作 |
|---|---|
| スペース | MY MIX ⇔ REFERENCE（Reference Monitor の画面が前にあるとき。Logic が前だと Logic の再生／停止になります） |
| 1〜9 | その番号のキューへ飛んで再生 |
| P | 参照曲の再生・一時停止 |
| C | 今の位置にキューを追加 |
| S | 選んでいるキューに Logic の今の位置を登録（SET MIX） |
| L | ループ ON/OFF |
| M | モノ ON/OFF |
| D | DIM ON/OFF |

## Logic を操作するための設定（曲ごとに1回）

アプリから Logic を再生・停止・位置移動したり、Logic の位置を受け取ったりするための設定です。**曲（プロジェクト）ごとに保存される**ので、使う曲で1回ずつやります（いつものテンプレートに入れておけば、新しい曲では不要）。

1. Reference Monitor を起動しておく
2. Logic で曲を開き、「ファイル」→「プロジェクト設定」→「同期…」
3. 真ん中の「**MIDI**」をクリック
4. 表のいちばん上の「オフ」をクリック →「**Reference Monitor**」を選ぶ
5. 同じ行の「**MTC**」の列にチェック
6. 表の下の「**MIDI マシンコントロール（MMC）の入力を自動認識**」にチェック
7. 閉じて command + S で保存

できていれば、アプリの上の段に「Logic 0:42 playing」のように Logic の位置が出ます。

## Aメロ同士を比べる手順（おすすめ）

1. ミュージック（または左の参照曲ファイル）で、参照曲の Aメロの頭で **C**（キュー追加）→ 名前を「Aメロ」に
2. Logic を自分の曲の Aメロの頭に合わせて、**S**（SET MIX）→ ボタンが「1. Aメロ +MIX」になる
3. 「1. Aメロ」を押す → 両方の曲がそれぞれの Aメロの頭から鳴る
4. **CUE ON SWITCH** をオンにしておくと、**スペース**で切り替えるたびに、切り替えた側が Aメロの頭から鳴ります
5. メーターの SECTION LUFS・DYNAMICS と、スペクトラム下の白い線で、Aメロ同士の差を確認
6. BAND SOLO で LOW / MID / HIGH ごとにも比べる

## 知っておいてほしいこと

- Logic の音はアプリを通るので、**ほんの少し遅れます**（10〜20 ミリ秒くらい）。ミックス中は気になりませんが、**録音するときは BYPASS** を押してください
- Apple Music のループは、0.25 秒ごとに位置を見て戻すので、ファイルほどぴったりではありません
- Apple Music のライブラリの曲（コピー防止付き）も、再生中の音を受け取るので使えます
- 不具合があったら、`~/Library/Application Support/Reference Monitor/log.txt` に動作記録が残っています

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| Logic の音が聴こえない | 「画面とシステムオーディオ録音」の許可を確認。急ぐときは BYPASS |
| 「Apple Music: control not allowed」 | 「オートメーション」でミュージックの操作を許可 |
| 「Logic Pro: not running」 | Logic を起動すると数秒で自動でつながります |
| アプリが開けない | インストール手順4の xattr の行を実行 |
| 音が二重に聴こえる | 起動直後の1〜2秒だけ起こることがあります。続くときはアプリを再起動 |

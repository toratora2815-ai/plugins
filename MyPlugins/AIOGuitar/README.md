# AIO Guitar（エーアイオー ギター）

**自分のエレキギターを録った音で鳴らす、全部入りのギター音源**です（AU 音源＋単体アプリ）。
ギターをライン録り（アンプやエフェクトを通さず、オーディオインターフェイスに直接つないで録ること）した数十音を読み込むと、
音程と音量を自動でそろえて、全部の音を弾けるようにします。打ち込みは Logic のピアノロールでします。

画面は 4 ページです。

1. **MY GUITAR** … 録音の読み込み、弦とフレットの表、弾き方の設定、奏法
2. **SCORE** … タブ譜を見ながら 1 音ずつ奏法・弦を付ける。Logic と同期
3. **EFFECTS** … ペダルボード。Cotton Comp（コンプ）・Porch Drive（ドライブ）・Wool Fuzz（ファズ）・AMP・TREM（トレモロ）を、好きな順番に並べる。ドライブとファズは単体のプラグインと同じ音、TREM は My Tremolo の小型版
4. **AMP** … アンプ 5 種類のつまみ、キャビネット 5 種類（または読み込んだ IR）、マイクの種類・位置・距離

## Logic での出し方
1. ソフトウェア音源トラックを作る
2. 音源の欄 → AU 音源 → MyPlugins → **AIO Guitar**
3. 単体アプリは ~/Applications の「AIO Guitar」。MIDI キーボードをつなげばそのまま弾けます

## 録り方（いちばん大事）
全部の音は録りません。**カポを使って、開放弦を 1 本ずつ**録ります。

1. ギターをオーディオインターフェイスの Hi-Z（INST）入力に直接つなぐ。エフェクトはすべて外す
2. いつも使うピックアップを選ぶ
3. **MEDIUM PICKING（いつもコードやリフを弾くときの強さ）** を 1 本のファイルに続けて録る
   - カポなし（開放）→ 3 フレット → 6 → 9 → 12 の順。最後に 15 フレットで 1〜3 弦だけ
   - 各位置で **6 弦 → 5 弦 → … → 1 弦**の順（15 フレットは 3 弦 → 1 弦）
   - 各弦は **ダウンで 1 回、アップで 1 回**
   - 1 音ずつ鳴り終わるまで伸ばす（低い弦は 6〜8 秒、高い弦は 3〜4 秒）。手でミュートして、1 秒ほど無音を空けて次へ
4. **PALM MUTE（ブリッジミュート）** … 6・5・4 弦だけを、開放・3・6・9 で。6 弦 → 4 弦、各弦ダウン → アップ
5. **BRUSHING（全弦ミュートのストローク）** … ダウン、アップ、ダウン…と交互に 8 回ほど。1 回ずつ少し間を空ける
6. 強弱を付けたくなったら **SOFT PICKING（そっと）** と **HARD PICKING（アクセントで思い切り）** … あとからで大丈夫。録り方は MEDIUM と同じ。
   3 つの強さで、ピック・弾く位置・ピックアップ・トーンつまみ・インターフェイスの入力ゲインを変えないこと
7. Logic でそれぞれのリージョンを WAV で書き出す
8. AIO Guitar の各欄にドラッグ（または「Load...」）

順番を守ると、「何弦の何フレットか」を自動で割り出します。表（STRINGS & FRETS）の ● が録れた場所です。
「弦が分からず」と出たら、録る順番がずれているところがあります。

## RECORD GUIDE（録音ガイド・単体アプリだけ）
Logic で録って書き出す代わりに、アプリが 1 音ずつ案内しながら録ります。ギターを持ったまま進められます。

1. ギターをオーディオインターフェイスの Hi-Z（INST）入力につなぐ（エフェクトは外す）
2. ~/Applications の **AIO Guitar** を開く。初めてのときは「マイクへのアクセス」を聞かれるので「許可」
3. MY GUITAR の右上「GUITAR」欄の **RECORD GUIDE** を押す
4. **入力の設定** で、Input にオーディオインターフェイスを選ぶ。その横の「入力: 自動」は、ギターが鳴っているほうの入力を自動で使います（入力 1 / 入力 2 に固定もできる）
5. 上の **MEDIUM** を押すと始まる。最初に**チューニング確認**: カポを外して、開放弦を 6 弦から 1 本ずつ弾く。±20 セント以内なら次の弦へ、ずれていれば「6 弦が +35 セント高い」のように出るので直してもう一回（「飛ばす →」で確認ごと飛ばせる）
6. 画面の大きな文字（例「カポなし 6 (E) 弦 ↓ ダウン」）のとおりに 1 回弾き、鳴り終わるまで待つ（手でミュートしても OK）
   - OK なら自動で次へ。だめなら理由が 1 つ出るので、同じ音をもう一回
   - カポを付け替えるところで止まります。付け替えて、表示の音を弾けばそのまま再開
   - 入力のメーターのピークが −12〜−6 dB くらいになるよう、インターフェイスの入力つまみを合わせる
7. 終わると自動で保存（~/Music/AIO Guitar/<ギターの名前>.aioguitar）。録った生の音も ~/Music/AIO Guitar/Recordings に WAV で残ります
8. 続けて **BRUSH**（全弦ミュートのストローク 8 回）、**MUTE**（ブリッジミュート 24 音）。強弱を付けたくなったら **SOFT**（そっと）と **HARD**（アクセントで思い切り）も 66 音ずつ。
   画面に強さの目安が出ます。SOFT と MEDIUM、MEDIUM と HARD があまり変わらないと「気になる点」で知らせます

- だめになるのは: 半音以上ずれた（弦かカポ違い）／音が割れた／小さすぎ／前の弦がミュートされずに鳴っている／2 回鳴った／短すぎ。
  セントのずれ、ほかの弦の共鳴、ハム（ブーンという電源の雑音）などは、最後に「気になる点」として出るだけで、そのまま使えます
- 「← 1 つ戻る」「飛ばす →」、スペースキーで一時停止
- 1 音だけ録り直したいときは、STRINGS & FRETS の表のマスを**右クリック** → SOFT / MEDIUM / HARD / MUTE を選ぶ（ダウンとアップを録ります。録っていないフレットも足せます）
- Logic の AU 版にはガイドはありません。アプリで録ったギターは、Logic 側で「Open Guitar...」から .aioguitar を開けば同じ音になります

## MY GUITAR の画面

### 録音の欄（SOFT / MEDIUM / HARD PICKING、PALM MUTE、BRUSHING）
- ファイルをドラッグ、または「Load...」で読み込む。「Clear」で消す
- 読み込むと、1 音ずつ切り分けて、音程を 1 セント（半音の 100 分の 1）単位で測り直し、音量をそろえます
- どの強さが鳴るか（打ち込みのベロシティ）: 3 つとも録ったら 1〜60 = SOFT、61〜100 = MEDIUM、101〜127 = HARD。
  SOFT と HARD だけなら 80 から HARD。録っていない強さは、となりの強さが受け持ちます
- 3 つの強さは音量をそろえてあり、音の大きさはベロシティ（PLAYING の Velocity つまみ）だけで決まります。強さを変えると音色（アタックの鋭さ・明るさ）が変わります

### GUITAR
- 名前を付けて「Save Guitar...」で、録音一式を 1 つのファイル（.aioguitar、~/Music/AIO Guitar）に保存。「Open Guitar...」で読み込み
- Logic のプロジェクトにも録音ごと自動で保存されます

### STRINGS & FRETS（弦とフレットの表）
- ● が録った場所（橙 = soft、緑 = medium、赤 = hard、青 = mute）
- マウスを乗せると「5弦 7F ← 5弦 9F の録音を −2 半音」のように、どの録音から作っているかが出ます
- **クリックでその弦・そのフレットの音を試聴**できます
- 録っていない音は、同じ弦の近い録音から作ります。**音程を下げる方向を優先**します（上げるより自然なため）。開放弦の録音は開放の音にしか使いません

### PLAYING（弾き方）
| つまみ | 意味 |
|---|---|
| String choice | どの弦で弾くか。Auto = 手の位置から自動（和音は 1 音ずつ別の弦に）。MIDI Ch 1-6 = MIDI チャンネル 1〜6 を 1〜6 弦として使う |
| Pitch Correct | 録音の音程のずれを直す（普通は ON） |
| Level Match | 録音ごとの音量差をそろえる（普通は ON） |
| Velocity | 打ち込みの強さで音量がどれだけ変わるか |
| Humanize | 弾くたびに音量・明るさ・鳴り始めをほんの少し変える（同じ音の連打が機械っぽくならないように） |
| Palm Mute | 全部の音にミュートをかける量（モジュレーションホイールでも同じ） |
| Release | 鍵盤を離してから音が消えるまでの時間 |
| Volume | ギターの音量 |
| STRUM | 和音（同時に弾いた 2 音以上）を、ピックで弦をなでるように 1 本ずつずらして鳴らす（標準は ON） |
| Strum Speed | 1 本ごとのずれ（標準 7 ms。6 本で約 35 ms）。強く弾くほど少し速くなります |
| Up-stroke strings | アップストロークで鳴らす弦の数（上から 3 本 / 4 本 / 全部）。鳴らさない低い弦は前の音が鳴ったまま |

- 同じ音を続けて弾くと、ダウンとアップの録音を交互に使います
- STRUM の向きは自動で決まります: 表拍 = ダウン（低い弦から）、裏 = アップ（高い弦から）。その小節に 16 分の裏の和音があれば 16 分の振りになります。ダウンはダウンの録音、アップはアップの録音で鳴らします
- ずらすのは鳴る音だけで、Logic の MIDI のタイミングは変えません（クオンタイズしても大丈夫）
- 鍵盤で弾いて録った和音（音が少しずつずれている）も、25 ms 以内ならストロークになります（並びは弾いた順。アップでも全部の弦が鳴ります）
- ブラッシング（C1 / C#1）を鳴らすと、鳴っている和音が止まります（ジャーン・チャッ）
- 1 本の弦は同時に 1 音だけ。同じ弦で次の音を弾くと、前の音は止まります（本物のギターと同じ）

### ARTICULATIONS（奏法）
Logic のピアノロールで 1 音ずつ指定します。
- 音を選んで、左の「アーティキュレーション」欄から AIO Guitar の奏法を選ぶ（下の「アーティキュレーションセット」を入れたとき）
- または、キースイッチ（その音の直前に置く、鳴らない音）を書く

| 鍵盤 | 奏法 |
|---|---|
| C0 | 普通 |
| C#0 | ブリッジミュート（PALM MUTE の録音を使う。なければフィルターでまねる） |
| D0 / D#0 / E0 | チョーキング 半音 / 全音 / 1 音半 |
| F0 | チョーキング＆戻し |
| F#0 | 先に曲げてから戻す |
| G0 / G#0 | ビブラート / 深いビブラート |
| A0 / A#0 | スライドイン / スライドアウト |
| B0 | デッドノート（ミュートでチャッと鳴らす） |
| C1 / C#1 | ブラッシング（ダウン / アップ） |
| D1 / D#1 | 次の和音のストロークをダウン / アップにする（その和音だけ。STRUM が ON のとき） |

- 奏法の右のつまみ: チョーキングが始まるまで・曲げる速さ・曲げたまま保つ時間、スライドの幅、ビブラートの速さと揺れ始め
- PITCH WHEEL: ピッチベンドで上げ下げできる幅（半音）
- アフタータッチ（鍵盤を押し込む）でビブラート

### アーティキュレーションセットの入れ方
1. ターミナルで:
   ```
   mkdir -p ~/Music/Audio\ Music\ Apps/Articulation\ Settings
   cp "MyPlugins/AIOGuitar/Logic/AIO Guitar.plist" ~/Music/Audio\ Music\ Apps/Articulation\ Settings/
   ```
2. Logic のトラックのインスペクタ →「アーティキュレーションセット」→「AIO Guitar」

## SCORE（タブ譜で奏法を付ける）
左上で 2 つのやり方を切り替えます。

### FOLLOW LOGIC（いつもはこちら）
1. Logic のピアノロールで、ふつうに音を打ち込む
2. Logic を再生すると、流れてきた音がタブ譜（6 本線、数字 = フレット）に出る。再生するたびに Logic に合わせて更新されます
3. 音をクリックして選ぶ（Shift で追加、空いた所をドラッグで範囲）
4. 上のボタン（Bend Full、Vibrato など）で奏法を付ける。**次の再生からすぐ効きます**
5. 上下にドラッグすると、別の弦で弾かせられます（フレットは自動で変わる）
6. プラグインで付けた奏法は**オレンジ**＝まだ Logic の MIDI には入っていない、という印
7. 仕上がったら右上の「DRAG TO LOGIC」をつかんで、Logic のトラックの「表示されている小節」の頭にドロップ → 元のリージョンと差し替える。奏法がキースイッチとして Logic の MIDI に入り、次の再生でオレンジが消えます

- Logic で音を動かして、付けた奏法が当たらなくなったら「外れた奏法 ○ 個を消す」が出ます（勝手には消えません。音を戻せばまた効きます）
- 「Logic」ボタン（または Delete）で、選んだ音のプラグインでの指定を消して Logic のままに戻す
- 和音の上の **↓ / ↑** がストロークの向き。灰色 = 自動、オレンジ = ここで変えた、金色 = Logic の D1 / D#1。クリックで 自動 → ↓ → ↑ → 自動
  - DRAG TO LOGIC で戻すと、変えた向きは D1（ダウン）/ D#1（アップ）として和音の直前に入ります（その和音だけに効く）
- 「CH = STRING」を ON にすると、弦を MIDI チャンネル 1〜6 で書き出し・受け取ります（Logic に戻した後も弦の指定が残る）
- ダブルクリックでその音を試聴、「PREVIEW」で譜面をプラグインの中だけで試聴、⌘＋ホイールで拡大、⌘Z で取り消し

### PLAY IN SYNC（Ample Guitar 型）
- 「Open MIDI...」か、.mid ファイルをドロップすると、その譜面をプラグインが持ちます
- Logic を再生すると、その譜面を Logic の再生位置に合わせて鳴らします（Logic 側に MIDI はいりません。拍子は Logic とそろえる）
- 奏法の付け方・DRAG TO LOGIC は同じ

## EFFECTS（ペダルボード）
音は左から右へ流れます: IN → 5 つの箱（COMP・DRIVE・FUZZ・AMP・TREM、好きな順番）→ CAB（スピーカー、いつも最後）→ OUT

- **順番の入れ替え** … 箱をつかんで左右にドラッグするか、箱の下の ◀ ▶ で 1 つずつずらす（AMP の箱も動かせます）
  - AMP の箱は小さいヘッドで、機種とつまみの値を表示します。箱を押すか「AMP 画面で調整 ▸」で AMP ページへ。つまみはそちらで回します
  - CAB の箱は動きません（本物のギターと同じで、スピーカーはいつも最後）。押すと AMP ページ
  - AMP より後ろに置いたペダルには「AMP の後」と出ます。アンプを通った音（スピーカーの前）にかかります
  - AMP の後ろのペダルにも、ギターから直接入れたときと同じくらいの大きさで音が入るように、中で自動でそろえています（アンプの機種・GAIN・MASTER で決まる決まった量。弾いた音を追いかけて変えたりはしません）
  - 鳴らしながら入れ替えると、一瞬（約 10 ms）音を下げてからつなぎます。順番によって音量は変わります（AMP の後ろのドライブは音量がそのまま足されるので大きくなりやすい）。LEVEL・VOLUME で合わせてください
  - 順番は曲の途中で自動で変えるもの（オートメーション）にはしていません
- **おすすめの順番**
  | 順番 | どんな音 |
  |---|---|
  | COMP → DRIVE → FUZZ → AMP（標準） | いちばん普通。コンプで伸ばしてから歪ませる |
  | DRIVE → COMP → AMP | 歪みの音量のばらつきをコンプでそろえる。リードが前に出て、刻みが均一になる |
  | AMP → COMP | アンプの音をそのままコンプでまとめる（スタジオでマイクの音にコンプをかける感じに近い） |
  | FUZZ → DRIVE → AMP | ファズをドライブで押し出す（内蔵プリセット「Fuzz into Drive」） |
  | AMP → DRIVE / FUZZ | アンプの後で歪ませる、荒い音。クリーンのアンプで試すと分かりやすい |
- **COTTON COMP**（コンプ）… 音の頭をつぶして、伸び（サステイン）を出すギター用のコンプ
  | つまみ | 何をする |
  |---|---|
  | COMP | つぶす量。上げるほど音がそろい、長く伸びる（持ち上げは最大 +20 dB） |
  | LEVEL | 出る音量。0 dB で ON / OFF がだいたい同じ大きさになるよう自動で補っています |
  | BLEND | コンプの音と元の音の混ぜ具合。下げるとピックのアタックが戻って自然になる |
  - アタックは固定（ピックの頭が少し抜ける 6 ms）、戻りは COMP に合わせて自動
  - とても小さい音（録音の終わりのハムやサーッという雑音くらい）は持ち上げません
  - おすすめ: クリーンのカッティング・アルペジオに COMP 4〜6・BLEND 70〜100 %。ドライブの前に置くと伸びるリードに、
    ドライブの後ろに置くと歪みの音量がそろう。ファズはそれ自体が音をつぶすので、ファズの前ではほとんど効きません
  - ディレイ・リバーブは入れていません。自作の Echo Drift・Lumen Rooms などを AIO Guitar の後ろに挿してください
- **PORCH DRIVE**（LEVEL / TONE / GAIN）と **WOOL FUZZ**（SUSTAIN / TONE / VOLUME）。中身は単体の Porch Drive・Wool Fuzz とまったく同じ音です
- **TREM**（トレモロ。DEPTH / RATE / SHAPE ＋ SYNC）… 音量を周期的に揺らす。中身は My Tremolo と同じ揺れ方（色付けなし、遅れ 0）
  | つまみ | 何をする |
  |---|---|
  | DEPTH | 揺れの深さ。100 % で波の底では音が消える |
  | RATE | SYNC ON: 1 回の揺れの長さを音符で（1/2〜1/32、T = 3 連）。Logic のテンポと拍に合わせる / SYNC OFF: 速さを Hz で（1〜12 Hz） |
  | SHAPE | 揺れの形。Sine・Triangle・Vintage（昔のアンプのトレモロふう）・Soft Square・Square（刻み） |
  - 置き場所で音が変わります: **AMP の後ろ**（標準）= 本物のアンプのトレモロ。歪ませても揺れは深いまま
    / **AMP の前** = トレモロペダル。アンプへ入る量が揺れるので、歪みの量も一緒に揺れる（荒れた刻みになる）
  - COMP をトレモロの後ろに置くと、コンプが揺れを打ち消して浅くなります
  - 単体アプリでは SYNC が使えません（Logic のテンポがないため）。RATE は Hz です
  - リズムを描く・スウィング・左右に揺らす（オートパン）など細かく作るときは、AIO Guitar の後ろに My Tremolo を挿してください
  - 前の版で作ったプロジェクトを開くと、TREM は AMP の直後に OFF で入っています。内蔵プリセット「Vintage Amp Trem」で試せます
- 下の「ON / OFF」で踏む。OFF のペダルは計算しないので軽くなります
- 何も鳴っていない間は、EFFECTS と AMP を自動で休ませます（右上に「休止中」）。弾けばすぐ戻ります
- AMP と CAB を両方 OFF にしたときは、出口で音の頭をやわらかく押さえます（ペダルだけだと大きな音が出るため）

## AMP
- いちばん上の帯に今の順番が出ます（AMP が光っているところがアンプの位置）。「順番を変える（EFFECTS）▸」で EFFECTS ページへ
- **アンプ**（上のヘッド）… 右上で種類を選ぶ。「AMP ON」で ON / OFF（OFF だとアンプを通らず素通り）
  | 種類 | どんな音 |
  |---|---|
  | American Clean | 大きなクリーン。低音と高音がきれいに出て、中域が少しへこむ。カッティング・アルペジオに |
  | Tweed | 早めにくずれる太い音。弾く強さで歪みが変わる。ブルース・ルーツロックに |
  | British Chime | きらびやかな高域と、軽いくずれ。60 年代のブリティッシュ・ポップに |
  | British Crunch | 中域の押し出しが強いクランチ。ロックのリフ・コードに |
  | Modern High Gain | 締まった低音の強い歪み。メタル・ハードロックの刻みに |

  | つまみ | 何をする |
  |---|---|
  | GAIN | 歪みの量（プリアンプ） |
  | BASS / MIDDLE / TREBLE | 低域・中域・高域。真ん中（5）が標準。下げるほうがよく効きます |
  | PRESENCE | いちばん上の高域（耳に近い、抜けの部分） |
  | MASTER | パワー管の押し込み。上げると音が太く、押しつぶされ、弾き方に反応するようになります |
- **キャビネットとマイク**（左下）… 箱の種類（1x12 Open / 2x12 Open / 4x12 Closed / 4x12 Modern / 4x10 Open）と、マイク
  | 項目 | 何をする |
  |---|---|
  | Dynamic / Condenser / Ribbon | マイクの種類。Dynamic = 中高域が前に出る定番、Condenser = 素直で上まで伸びる、Ribbon = やわらかく太い |
  | POSITION | スピーカーのどこを狙うか。0 = 真ん中（明るい）→ 10 = 端（暗く、やわらかい） |
  | DISTANCE | スピーカーからの距離。0 = 近い（低音が増える）→ 10 = 離す（部屋の響きが少し混ざる） |
  - 「Load IR...」でキャビネットの IR（WAV / AIFF、0.5 秒まで）を読み込むと、箱の種類が「Loaded IR」になって、その IR で鳴ります。IR はプロジェクトにも保存されます
  - IR はそのままの音で使います（マイクの種類・POSITION・DISTANCE は IR には効きません）。IR がないまま「Loaded IR」を選ぶと、4x12 Closed で鳴ります
  - 箱やマイクの種類を切り替えると、一瞬（約 16 ms）音を下げてからつなぎます（プチッと鳴らないように）
  - 画面の白い丸がマイクの位置（右へ行くほど端、小さいほど離れている）
- **OUTPUT** … 最後の音量
  - 内蔵のリバーブは 0.3.0 で外しました（自作の Lumen Rooms・Meld Verb・Elder Verb などを後ろに挿す前提）。
    0.2.0 で REVERB を上げて保存したプロジェクトは、開くとリバーブなしの音になります

## いちばん下の欄
- **LINK** … 自作プラグイン同士の連携（Plugin Link）。今は番号を選べるだけで、送り合う数値はまだありません
- **プリセット・UNDO / REDO** … つまみの設定を保存・読み込み、取り消し・やり直し。録音は変わりません
- 右上の「Init」などの内蔵プリセットは、EFFECTS と AMP の音作りだけが変わります

## おすすめの使い方
- まず MEDIUM PICKING と BRUSHING だけ録って、表で ● を確認 → いくつかクリックで試聴（1 つの強さだけのときは、ベロシティで明るさが変わります）
- 刻み（ロックのリフ）を打ち込むなら PALM MUTE も録る。キースイッチ C#0 でミュート、C0 で普通に戻す
- 強弱を付けたくなったら SOFT PICKING と HARD PICKING を足す（ベロシティ 1〜60 と 101〜127 で鳴ります）

# Num Deck（ナム・デック）

テンキーの **1〜9** に、よく使う操作を割り当てて、ゲーム機のメニューのような大きなタイル画面で確認できる単体 Mac アプリです。
数字を打ちたいときは **OFF** にすれば、テンキーは普通の数字キーに戻ります。

## 2 つのモード（v1.1.0）

左上の **Logic Pro ／ 業務** をクリックして切り替えます（テンキーでは切り替わらないので、うっかり変わりません）。
モードごとに、割り当てとページ（4 ページずつ）を別々に覚えています。

| モード | 動く場所 | 最初の割り当て |
|---|---|---|
| Logic Pro | Logic が前面のときだけ（下のボタンで変えられる） | 再生・録音 / 編集 / ウィンドウ / 自由 |
| 業務 | どのアプリでも | 編集（コピー・貼り付けなど） / ブラウザ（タブ操作） / アプリ / リンク |

### 業務モードの割り当て

| ページ | 7 | 8 | 9 | 4 | 5 | 6 | 1 | 2 | 3 | 0 | . |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 編集 | 元に戻す ⌘Z | やり直す | すべて選択 ⌘A | 切り取り ⌘X | コピー ⌘C | 貼り付け ⌘V | 検索 ⌘F | 保存 ⌘S | 範囲スクショ |
| ブラウザ | 新しいタブ | タブを閉じる | 閉じたタブを開く | 前のタブ | 再読み込み | 次のタブ | 戻る | アドレスバー | 進む |
| アプリ | Slack | Chrome | Finder | Excel | Word | Zoom | メモ など（入っているものだけ） |||
| リンク | （空き。自分で登録） |||||||||

### アプリやページを登録する

タイルをクリック →

- **アプリを開く** … 一覧から選ぶ／「ほかのアプリを選ぶ…」でアプリケーションフォルダから選ぶ
- **ページを開く** →
  - **Chrome で今開いているページを登録** … 先に Chrome で登録したいページ（ICE、評価など）を開いておき、これを選ぶだけ。
    名前を聞かれるので、短い名前（例: ICE）にすると見やすい。
    初めてのときに「Num Deck が Google Chrome を制御しようとしています」と出たら **許可** を押す
  - **アドレス（URL）を入力…** … アドレスを貼り付けて登録
- ページは Chrome で開きます（Chrome がないときはいつものブラウザ）
- ページの名前は **設定 → このページの名前を変える…** で変えられます

## 画面

- 3×3 のタイル … テンキーと同じ並び（上が 7 8 9、下が 1 2 3）。押すとタイルが光ります
- 上のタブ … ページ（再生・録音 / 編集 / ウィンドウ）。1 ページに 9 個 × 3 ページ = 27 個まで
- 右上の **ON / OFF** … クリックで切り替え
- 下の左 … Logic の状態（緑 = 前面、橙 = 背面、灰 = 起動していない）

## テンキーの使い方（ON のとき）

| キー | 動き |
|---|---|
| 1〜9 | タイルの操作を Logic に送る |
| / と * | 前 / 次のページ（v1.8.0 から。前は − / +） |
| Clear（PC キーボードなら NumLock） | ON ⇔ OFF |
| − + Enter など | 何もしない（普通のキーのまま） |

- ⌘ や ⇧ を押しながらのテンキーは横取りしません
- 「なし」にしたキーは普通の数字キーのまま

## 割り当てを変える

タイルをクリック → メニューから選ぶだけ。

- 分類（再生・録音 / 編集 / トラック / ウィンドウ / ファイル）から選ぶ
- **ショートカットを覚えさせる…** → Logic で使いたいキー（例: ⌘T）を押すと、そのキーが入ります（Esc でやめる）
- **名前を変える…** … 覚えさせたキーのタイルの名前
- **なし** … そのキーは普通の数字キーとして使う

## Reference Monitor を操作する（v1.3.0）

Logic Pro モードの 4 ページ目 **リファレンス** は、聴き比べアプリ Reference Monitor の操作です。
Reference Monitor が後ろにあっても届くので、Logic を前に出したまま使えます（Reference Monitor 1.3.0 以降）。

| 7 | 8 | 9 |
|---|---|---|
| A/B 切替 | 自分の曲（A） | 参照曲（B） |
| **4** | **5** | **6** |
| キュー 1 | キュー 2 | キュー 3 |
| **1** | **2** | **3** |
| 再生 / 一時停止 | モノラル | 聞こえ方（LISTEN AS）を切替 |

1 ページ目の 3 は **出力 A/B 切替**（v1.3.1）。Reference Monitor の OUTPUT A と B（例: AirPods Pro とオーディオインターフェイスのヘッドホン）をすぐ切り替えます。

タイルのメニュー → **Reference Monitor** から、ループ・DIM・ミュート・出力 A / 出力 B・キュー追加・SET MIX・メーターのリセットなども選べます。
Reference Monitor を前に出しているときも「Logic が前面のときだけ」と同じに動きます。

**Logic の操作は Logic にだけ届きます（v1.3.3）**：1〜3 ページ目の再生・録音・巻き戻しなど（Logic のキーを送るタイル）は、
Reference Monitor などほかのアプリが前面にあっても、**Logic に届けます**（一瞬だけ Logic を前に出して送り、すぐ元のアプリに戻します）。
前は Reference Monitor が前面だと、再生 / 停止のスペースキーが Reference Monitor に届いて **MIX と REF が入れ替わる**ことがありました。
Reference Monitor を操作したいときは、4 ページ目「リファレンス」を使ってください。

## トラックをフリーズ（v1.3.2、最初に 1 回だけ設定）

Logic には「フリーズ」のキーが最初から決まっていないので、Num Deck は **⌃⌥⇧⌘F**（control + option + shift + command + F）を送ります。
Logic にこのキーを 1 回だけ覚えさせてください。

1. Logic で「Logic Pro」→「キーコマンド」→「割り当てを編集」
2. 左上の検索欄に「フリーズ」と入れる
3. 「トラックのフリーズを切り替え」をクリック
4. 「キーラベルで記憶」を押す
5. テンキーの **1**（Num Deck が ON、1 ページ目のとき）を押す → ⌃⌥⇧⌘F が入る
6. 「キーラベルで記憶」をもう一度押して止め、ウィンドウを閉じる

あとは、トラックを選んでテンキーの 1 を押すと、フリーズ／解除が切り替わります。

## モードの切り替えをキーで（v1.7.0）

テンキーのいちばん上の **Home** キーで、Logic Pro モードと業務モードが切り替わります（画面のクリックでも今までどおり切り替えられます）。

- Home キーを押しても切り替わらないときは、「設定」→「切り替えのキーを覚えさせる…」→ 使いたいキーを押す
- そのキーは切り替え専用になります（ほかのアプリには届きません）。やめるときは「設定」→「キーで切り替えない」

## 業務モード: アプリはもう一度押すと隠れる（v1.5.0）

アプリを開くタイル（例: 7 = Slack）は、**そのアプリが前に出ているときにもう一度押すと隠れて**、開く前の画面に戻ります。
全画面で開いているアプリでも同じです（もう一度押すと、開く前のアプリの画面に移る。v1.7.0 で直しました）。アプリは終了しないので、通知などはそのまま届きます。

## リンクを 2 画面で開く（v1.9.0）

リンクのタイルは、画面を左右に分けて開けます。左半分にそのページ、右半分に次のどれかが並びます。

- **Chrome の新しいウィンドウ**（例: 研修のページを見ながら、右で答案を開く）
- **Claude**（例: 評価のページを見ながら、右で Claude を使う）
- ほかのアプリ（自分で選ぶ）

設定のしかた: リンクのタイルをクリック →「2 画面で開く」→ 右に置くものを選ぶ。
マウスのある画面を使います。ページは毎回新しいウィンドウで開きます。

## リンクを開く Chrome のアカウント（v1.5.0）

Chrome にアカウント（プロフィール）がいくつかあるとき、リンクのタイルをどのアカウントで開くか決められます。

1. Num Deck の右下「設定」→「リンクを開く Chrome のアカウント」
2. 使いたいアカウント（例: 仕事用）を選ぶ
   - 初めてのときだけ、macOS が「“Num Deck”がほかのアプリのデータにアクセスしようとしています」と聞いてきます。「許可」を押してください（Chrome のアカウントの一覧を読むためです）
3. 以後、リンクのタイルはそのアカウントの Chrome で開きます（「指定しない」に戻すと、今使っている Chrome で開く）

## テンキーの .（Del）（v1.6.0）

0 の右に **.** のタイルが増えました（キーボードによっては「Del」と書いてあるキー）。0 と同じく、何でも割り当てられます。
1 ページ目（再生・録音）の . は **低レイテンシモード**（時計のマーク、録音中の遅れを減らす）です。
Num Deck は ⌃⌥⇧⌘L を送るので、Logic に 1 回だけ覚えさせてください（手順は下の 0 と同じ。検索欄に「低レイテンシ」と入れ、「低レイテンシモード」の行を選ぶ）。

## テンキーの 0（v1.4.0）

画面のいちばん下に、横長の **0** のタイルが増えました。ほかのタイルと同じく、クリックで何でも割り当てられます。
「なし」にしておくと、0 は普通の数字キーのままです。

1 ページ目（再生・録音）の 0 は **入力モニタリング**（トラックの「I」ボタン）です。ギター録音で、弾きながら自分の音を聞くときに使います。
フリーズと同じく、Logic に 1 回だけキーを覚えさせてください（Num Deck は ⌃⌥⇧⌘I を送ります）。

1. Logic で「Logic Pro」→「キーコマンド」→「割り当てを編集」
2. 左上の検索欄に「入力モニタリング」と入れる
3. 「入力モニタリングを切り替え」の行をクリック（「自動入力モニタリング」ではない方）
4. 「キーラベルで記憶」を押す → テンキーの **0** を押す → ⌃⌥⇧⌘I が入る
5. 「キーラベルで記憶」をもう一度押して止め、閉じる

## 最初の割り当て（Logic Pro モード）

| ページ | 7 | 8 | 9 | 4 | 5 | 6 | 1 | 2 | 3 | 0 | . |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 再生・録音 | 元に戻す | サイクル | メトロノーム | 巻き戻し | 再生/停止 | 早送り | トラックをフリーズ | 録音 | 出力 A/B 切替（Reference Monitor） | 入力モニタリング | 低レイテンシモード |
| 編集 | やり直す | リピート | 削除 | 結合 | 分割 | ズーム | ミュート | ソロ | オートメーション | なし | なし |
| ウィンドウ | ミキサー | エディタ | ライブラリ | ピアノロール | 保存 | ループ | 新規オーディオ | 新規ソフト音源 | バウンス | なし | なし |

Logic の**初期設定のキーコマンド**を送っています。Logic でキーコマンドを変えている場合は「ショートカットを覚えさせる…」で合わせてください。

## 下のボタン

- **Logic が前面のときだけ**（標準 ON）… Logic 以外のアプリを使っているときは、テンキーは普通の数字キー。
  ブラウザや Excel で数字を打つときに、いちいち OFF にしなくて済みます
- **いつも手前** … ウィンドウを常に一番手前に（小さくして画面の隅に置くと便利）
- Num Deck の画面でボタンやページを押したあとは、さっきまで使っていたアプリ（Logic など）に自動で戻ります。
  そのまま続けてテンキーを使えます
- **設定** … ON/OFF のキー（Clear / = / なし）、ページの名前、割り当てを最初に戻す、画面の大きさ（大きい／小さい）

## 小さい画面（v1.2.0）

下の **小さく／大きく** ボタン（または **設定 → 小さい画面にする**）で 430×300 と 860×600 を切り替えます（ウィンドウの端をドラッグして自由な大きさにもできます）。
小さいときは、タイルに番号・名前・アイコンだけを出し、ショートカットの表示や下のヒントを省きます。
「いつも手前」と組み合わせて、画面の隅に置いておくのがおすすめです。ウィンドウの位置と大きさは次に開いたときも同じです。

## はじめて使うとき（許可）

テンキーを受け取るために「アクセシビリティ」の許可が要ります。

1. アプリを開くと上にオレンジの帯が出る → **許可する…** をクリック
2. システム設定 → プライバシーとセキュリティ → アクセシビリティ で **Num Deck** を ON
3. 帯が消えたら使えます

一覧で Num Deck が ON に見えているのに帯が消えないときは、前の版の許可が残っています。
オレンジの帯の **許可する…** を押すと古い許可を消して出し直すので、一覧の Num Deck をもう一度 ON にしてください。

## インストール

Releases の `latest` から `NumDeck.zip` をダウンロードして解凍 → `Num Deck.app` を「アプリケーション」に入れる。
開けないときはターミナルで:

```
xattr -dr com.apple.quarantine ~/Applications/"Num Deck.app"
```

# Num Deck（ナム・デック）

テンキーの **1〜9** に Logic Pro のよく使う操作を割り当てて、ゲーム機のメニューのような大きなタイル画面で確認できる単体 Mac アプリです。
数字を打ちたいときは **OFF** にすれば、テンキーは普通の数字キーに戻ります。

## 画面

- 3×3 のタイル … テンキーと同じ並び（上が 7 8 9、下が 1 2 3）。押すとタイルが光ります
- 上のタブ … ページ（再生・録音 / 編集 / ウィンドウ）。1 ページに 9 個 × 3 ページ = 27 個まで
- 右上の **ON / OFF** … クリックで切り替え
- 下の左 … Logic の状態（緑 = 前面、橙 = 背面、灰 = 起動していない）

## テンキーの使い方（ON のとき）

| キー | 動き |
|---|---|
| 1〜9 | タイルの操作を Logic に送る |
| − / + | 前 / 次のページ |
| Clear（PC キーボードなら NumLock） | ON ⇔ OFF |
| 0 . Enter * / など | 何もしない（普通のキーのまま） |

- ⌘ や ⇧ を押しながらのテンキーは横取りしません
- 「なし」にしたキーは普通の数字キーのまま

## 割り当てを変える

タイルをクリック → メニューから選ぶだけ。

- 分類（再生・録音 / 編集 / トラック / ウィンドウ / ファイル）から選ぶ
- **ショートカットを覚えさせる…** → Logic で使いたいキー（例: ⌘T）を押すと、そのキーが入ります（Esc でやめる）
- **名前を変える…** … 覚えさせたキーのタイルの名前
- **なし** … そのキーは普通の数字キーとして使う

## 最初の割り当て

| ページ | 7 | 8 | 9 | 4 | 5 | 6 | 1 | 2 | 3 |
|---|---|---|---|---|---|---|---|---|---|
| 再生・録音 | 元に戻す | サイクル | メトロノーム | 巻き戻し | 再生/停止 | 早送り | 先頭へ | 録音 | キャプチャ録音 |
| 編集 | やり直す | リピート | 削除 | 結合 | 分割 | ズーム | ミュート | ソロ | オートメーション |
| ウィンドウ | ミキサー | エディタ | ライブラリ | ピアノロール | 保存 | ループ | 新規オーディオ | 新規ソフト音源 | バウンス |

Logic の**初期設定のキーコマンド**を送っています。Logic でキーコマンドを変えている場合は「ショートカットを覚えさせる…」で合わせてください。

## 下のボタン

- **Logic が前面のときだけ**（標準 ON）… Logic 以外のアプリを使っているときは、テンキーは普通の数字キー。
  ブラウザや Excel で数字を打つときに、いちいち OFF にしなくて済みます
- **いつも手前** … ウィンドウを常に一番手前に（小さくして画面の隅に置くと便利）
- **設定** … ON/OFF のキー（Clear / = / なし）、割り当てを最初に戻す

## はじめて使うとき（許可）

テンキーを受け取るために「アクセシビリティ」の許可が要ります。

1. アプリを開くと上にオレンジの帯が出る → **許可する…** をクリック
2. システム設定 → プライバシーとセキュリティ → アクセシビリティ で **Num Deck** を ON
3. 帯が消えたら使えます

**アプリを新しい版に入れ替えたとき**は、許可が外れることがあります。
帯が出たら、アクセシビリティの一覧から Num Deck を「−」で消して、もう一度 ON にしてください。

## インストール

Releases の `latest` から `NumDeck.zip` をダウンロードして解凍 → `Num Deck.app` を「アプリケーション」に入れる。
開けないときはターミナルで:

```
xattr -dr com.apple.quarantine ~/Applications/"Num Deck.app"
```

# My Filter（マイ・フィルター）

音に合わせて動く「フィルター」の全部入りです（オートワウ、スイープ、刻み、サンプル＆ホールド、シンセのフィルターなど）。
本人の Mac にある市販のフィルター・プラグイン（フィルター 1 つ版と 2 つ版）に実際に音を通して測り、
フィルターの形・レゾナンスの効き方・周波数・MIX の混ぜ方・音量で開く動き・音の色付け（7 種類）を、同じ動きになるように合わせ込んだオリジナルです
（名前・見た目・プリセット名は別物）。1 つ版と 2 つ版を、このプラグイン 1 つで切り替えられます。

- 種類: エフェクト（AU）。Logic では「Audio Units → MyPlugins → My Filter」
- 遅れ: 29 サンプル（Logic が自動で補正します）
- モノのトラックでは「モノ → ステレオ」でも挿せます（下の「左右」を参照）

## 画面の上の帯

| 場所 | 何をする |
|---|---|
| **1 Filter / 2 Filters** | フィルターを 1 つか 2 つか |
| **Serial / Parallel** | 2 つのとき: Serial（直列）= 1 を通した音を 2 に通す。Parallel（並列）= 1 と 2 に別々に通して足す |
| **LINK** | 2 つのとき: FREQ・RES・GAIN を 1 と 2 で一緒に動かす（同じ向きに同じだけ） |
| **ANALOG** | ON = 色付け（下の STYLE）あり。OFF = DIGITAL（何も足さない。出口で −0.1 dB に硬く頭打ち） |
| **STYLE** | 色付けの種類（ANALOG が ON のとき） |
| **FACTORY PRESETS** | 内蔵プリセット 16 個 |

STYLE（音の色付け）:
- Clean … 柔らかい頭打ち。歪みの少ない標準
- Fat … 低い音が温かく歪む
- Squash … Fat に近く、軽く潰れる（コンプ）
- Dirt … 全体に柔らかく歪む
- Crunch … 高い音ほど早く潰れて荒れる
- Shred … 非対称に強く歪む（音量は −6 dB ほど下がる）
- Pump … 極端なコンプ。とても小さくなるので OUTPUT か GAIN MATCH で戻す

## 1 段目: つまみ

| つまみ | 何をする | 目安 |
|---|---|---|
| INPUT | フィルターに入る音量。上げると STYLE の歪みが強くなる | 0 dB |
| FILTER 1 / 2 の **FREQ** | フィルターの周波数（ローパスなら「ここより上を削る」所） | 曲による |
| **RES** | レゾナンス。FREQ の所を持ち上げて「クセ」を付ける。**95 % くらいから上は自分で鳴り出します（発振）。スピーカーに注意** | 0〜70 % |
| **GAIN** | そのフィルターの音量（±24 dB） | 0 dB |
| 形（Lowpass など） | Lowpass = 高い音を削る / Bandpass = FREQ の辺りだけ残す / Highpass = 低い音を削る / Notch = FREQ の辺りだけ削る | |
| POLES | 削り方の急さ。2 Pole = 12 dB/oct（ゆるい）… 8 Pole = 48 dB/oct（とても急） | 2〜4 Pole |
| **MOD** | 下の「動かし方」でフィルターを動かす量（0 % = 動かない） | 30〜90 % |
| 動かし方 | LFO / RHYTHM / ENVELOPE / RANDOM / STEP / ADSR（下の 2 段目） | |
| MIX | フィルターを通した音と元の音の割合（100 % = 通した音だけ） | 100 %（センドなら 100 %） |
| OUTPUT | フィルターの後の音量（STYLE の出口側の歪みに入る量） | 0 dB |

**動く幅** = MOD × FREQ MOD（TWEAK タブ、最初は +8 オクターブ）。MOD 50 % なら FREQ から最大 4 オクターブ上まで動きます。
FREQ MOD をマイナスにすると下向きに動きます。動いても 20 Hz〜19.6 kHz で止まります。

## 2 段目: 動かし方（モードごとにつまみが変わります）

- **LFO** … 一定の速さでくり返し動かす（オートワウ、スイープ）
  - RATE … 速さ 0.01〜100 Hz（とても速くすると金属的な「リングモジュレーター」のような音）
  - SHAPE … 動きの形（Sine・Triangle・Square・Ramp など 15 種類＋Custom = 自分で描く）
- **RHYTHM** … 曲のテンポに合わせて動かす（刻み・ワウのリズム）
  - RHYTHM … 1 回の長さ（4 Bars〜1/32、付点・3 連、Pattern = RHYTHM タブで描いたリズム）
  - SHAPE … 1 回の動きの形
  - GROOVE … 左 = シャッフル、右 = スウィング
  - TEMPO・SYNC・TAP … SYNC が ON なら Logic のテンポと小節にぴったり。OFF なら TEMPO（TAP で叩いて決められる）
- **ENVELOPE** … 入ってくる音の大きさで開く（ギター・ベース・ドラムのオートワウ）
  - THRESHOLD … この大きさを超えたら開き始める（まわりの輪 = 入力の大きさ。赤 = 超えている）
  - GAIN … 感度。上げるほど少し超えただけで全開になる（スイッチのような動き）
  - ATTACK / RELEASE … 開く速さ・閉じる速さ
- **RANDOM** … テンポに合わせて、1 回ごとにでたらめな高さへ（サンプル＆ホールド、ピコピコ音）
  - RHYTHM・GROOVE・TEMPO は RHYTHM と同じ。SMOOTH（TWEAK タブ）0 = 階段状に跳ぶ、上げるほどなめらかに移る
- **STEP** … 音が鳴る（TRIGGER の大きさを超える）たびに、でたらめな高さへ（ドラム向け。叩くたびに音色が変わる）
  - TRIGGER … きっかけの大きさ（輪 = 入力）。いちばん上にすると TRIGGER ボタンだけで動く
  - TRIGGER ボタン … 押すとその場で 1 回
- **ADSR** … 音が鳴るたびに、決まった形で開いて閉じる（シンセのフィルター・エンベロープ）
  - TRIGGER（大きさ）、A（開く時間）・D（S まで下がる時間）・S（鳴っている間の高さ）・R（止まってから閉じる時間）、TRIGGER ボタン

## 左下: フィルターの形

今の周波数での形（オレンジ）と、動かす前の形（薄い線）。右の細い棒が「今どれだけ動かしているか」。

## 右下のタブ

### TWEAK（細かい設定）
- **FREQ MOD 1 / 2** … MOD 100 % で何オクターブ動かすか（±10。最初は +8）。2 つのフィルターを逆向き（片方をマイナス）にすると「しゃべるような」ワウになります
- **RES MOD 1 / 2** … 動きに合わせてレゾナンスを足す（+）／減らす（−）
- **LEVEL MOD 1 / 2** … 動きに合わせて音量も変える。+ = 動きが小さい所で小さく、− = 動きが大きい所で小さく（フィルター付きトレモロ）
- **L/R OFFSET / L/R MODE**（**モノ → ステレオで挿したときだけ**効きます）… 右の周波数を上（+）／下（−）にずらす、Flipped = 右を左と逆向きに動かす（ぐるぐる回るステレオ感）
- **SMOOTH**（と曲線の種類）… Custom の形・RANDOM・STEP のなめらかさ

### SHAPE（形を描く）
- SHAPE を **Custom** にすると点を動かせます: クリック = 足す、ドラッグ = 動かす、option を押しながらクリック = 消す
- **EDIT** = 今の形を Custom に写して描き直す、**SAVE / LOAD** = ファイルに保存（`~/Library/Audio/Presets/MyPlugins/My Filter/Shapes`）

### RHYTHM（リズムを描く）
- 小節数・拍子・升目を選んで、升目をクリック = 動かす／休み。shift（右クリック）= 前の 1 回を伸ばす
- 使うときは RHYTHM を **Pattern** に（升目を触ると自動で切り替わります）

## 2 つのフィルターのとき

- **Serial**: 1 → 2 の順に通す。例: Highpass 400 Hz → Lowpass 3 kHz で「電話の声」
- **Parallel**: 1 と 2 を足す。例: Bandpass 2 つで母音のような響き
- モノ → ステレオで挿すと、**1 が左・2 が右** になります（Serial / Parallel は関係なし）

## 画面のいちばん下

- **LINK 欄**: Fader Pilot（ボーカルに挿したもの）と同じ LINK 番号にすると、歌っている間だけ動き（MOD）を小さくできます（VOCAL DUCK の % だけ）
- **GAIN MATCH**（プリセット欄の左端）: ON にすると、挿しても・つまみを回しても音量が変わらないように自動でそろえます（既定 OFF）
- **プリセット欄**: 自分のプリセットの保存・読み込み、UNDO / REDO（描いた形・パターンはそれぞれのタブの SAVE で。Logic のプロジェクトにはどちらも保存されます）

## おすすめ設定

1. **ギターのオートワウ（ファンク）**: FACTORY → Auto-Wah Funk。THRESHOLD を、弾いた時だけ輪が赤くなる所に。RELEASE で戻りの速さ
2. **ベースの太いワウ**: Envelope Low Funk 24dB、FREQ 120〜200 Hz、RES 40〜60 %
3. **盛り上げのスイープ（サビ前）**: Lowpass 4 Pole、MOD 0 %、FREQ を Logic のオートメーションで 200 Hz → 20 kHz へ。RES 30〜50 %
4. **シンセ・ループを刻む**: 1/16 Ramp Gate、MIX 70〜100 %
5. **ドラムに変化**: Drum Step Filter（叩くたびに音色が変わる）、MIX 30〜50 %
6. **電話・ラジオの声**: Telephone（2 Filters・Serial・Dirt）
7. **シンセのフィルター**: Synth Pluck ADSR、A を短く・D で減衰の長さ

## 注意

- RES を上げて ENVELOPE や ADSR で開くと、FREQ の辺りが急に大きくなることがあります。最初は OUTPUT を下げて試してください
- RES 95 % くらいから上は、音が止まってもフィルター自身が鳴り続けます（本物と同じ）
- 2 Filters の Parallel は 1 と 2 を足すので、同じ帯域が重なると 0 dBFS を超えることがあります（本物も足すだけ）。STYLE の Fat・Squash・Dirt・Pump で RES を上げた時も同じ。GAIN か OUTPUT で下げてください
- 形・POLES・フィルターの数・Serial / Parallel を替えた瞬間は、通った音を 12 ms ほど小さくしてつなぎます（プチッと鳴らないように）

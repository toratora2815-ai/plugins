# Elder Verb（エルダー・バーブ）

70〜80 年代のデジタルリバーブ機材っぽい響きを作るリバーブです。
この Mac に入っている市販のビンテージ系リバーブに、インパルス（パチッという一瞬の音）や正弦波を通して測り、
**残響の長さ・帯域ごとの減り方・最初の跳ね返りの時間と形・左右の広がり・揺れ・音色**を数値で合わせ込みました。
中身のプログラムは一から書いたオリジナルです（名前・見た目・プリセットはまねしていません）。

## 仕組み（ざっくり）

1. **入口の拡散** … 入ってきた音を 4 段のオールパス（音を細かくにじませる部品）でぼかします（EARLY DIFFUSION）
2. **初期の粒のかたまり** … 最初の 0.1 秒くらいに並ぶ跳ね返り。ATTACK で形が変わります
3. **ループ** … 4 つの枝が輪になって、音がぐるぐる回りながら減っていきます。ここで DECAY・BASS MULT・HIGH SHELF が効きます
4. 最後に HIGH CUT / LOW CUT（響きだけにかかる、なだらかなフィルター）を通して、MIX で原音と混ぜます

## 上の段

| 部分 | 説明 |
|---|---|
| モード | 響きの種類（22 種類）。下の表を見てください |
| 70s / 80s / NOW | 色づけ。**70s** は高音が 11 kHz あたりでスパッと切れる昔の機材の音、**80s** は高音まで出て揺れがランダム、**NOW** は高音まで出て揺れがなめらか |
| プリセット | 押すと一覧。上が Elder Verb の自作プリセット、その下に「この Mac に入っている VintageVerb のプリセット」がそのまま並びます（値の意味が同じなので、そのまま読み込めます） |
| ＜ ＞ | 前／次のプリセット |
| SAVE | 今の設定を自分のプリセットとして保存（~/Library/Application Support/MyPlugins/Elder Verb/Presets） |

## SPACE（空間）

| つまみ | 説明 |
|---|---|
| MIX | 原音と響きの割合。0% = 原音だけ、100% = 響きだけ（AUX に挿すときは 100%） |
| PRE-DELAY | 響きが始まるまでの待ち時間（0〜500 ms） |
| DECAY | 響きの長さ（0.2〜70 秒）。音が 60 dB 小さくなるまでの時間の目安。モードによって実際の長さは少し違います |
| SIZE | 部屋の大きさ。小さくすると跳ね返りの間隔が詰まり、早く濃い響きになります（短い DECAY は SIZE を小さくしないと出ません） |
| ATTACK | 響きの立ち上がり。0% = 最初にドンと出てすぐ引く、50% = 自然、100% = ふわっと遅れてふくらむ（始まりが約 50 ms 遅れる） |

## DECAY EQ（ループの中の音色＝減り方）

| つまみ | 説明 |
|---|---|
| BASS MULT | BASS XOVER より低い音の響きを何倍の長さにするか（×0.25〜×4） |
| BASS XOVER | 低音とみなす境目（約 100 Hz〜18 kHz） |
| HIGH SHELF | 高音が 1 周ごとにどれだけ減るか（0〜−12.8 dB）。下げるほど高音が早く消える＝暗く自然な響き |
| HIGH FREQ | 高音とみなす境目（約 100 Hz〜13.7 kHz） |

右のグラフは「周波数ごとの響きの長さ」です。つまみを回すと形が変わります。

## TEXTURE / OUTPUT

| つまみ | 説明 |
|---|---|
| EARLY DIFF | 最初の跳ね返りのにじみ。0% でパラパラした粒、100% でなめらか |
| LATE DIFF | 後ろの響きのにじみ。下げると金属っぽい響きが残ります |
| MOD RATE / MOD DEPTH | 響きの揺れの速さと深さ。上げるとコーラスっぽく広がり、金属っぽさが消えます（DEPTH は最後の 1/4 で急に深くなります） |
| HIGH CUT | 響きの高音を削る（約 100 Hz〜、右いっぱいで Off） |
| LOW CUT | 響きの低音を削る（左いっぱいで Off〜約 1.3 kHz） |

## 画面のいちばん下

| 部分 | 説明 |
|---|---|
| LINK | Plugin Link（自作プラグイン同士の連携）。OFF / 1〜4 |
| VOCAL DUCK | 同じ LINK の Fader Pilot（ボーカルのトラック）が「歌っている」と言っている間、響きをこの dB だけ下げる。歌の切れ目でリバーブがふわっと戻ります |
| UNDO / REDO | つまみの操作の取り消し・やり直し |

| Plate | 鉄板リバーブ。立ち上がりが速く、明るい |
| Room | 部屋。すぐに響き始める |
| Chamber | 残響室（石やタイルの部屋） |
| Random Space | 跳ね返りの位置がゆらゆら動く、広い空間 |
| Chorus Space | コーラスがかかったように広がる空間 |
| Ambience | ごく初期の響きだけ。音を前に出したまま空気感を足す |
| Bright Hall | 明るいホール |
| Sanctum | 古い鉄板機材っぽい、密度の高い響き |
| Grainy Hall / Grainy Plate | 少しざらっとした（昔のデジタル機材の）ホール／プレート |

## おすすめ設定

- **ボーカル（バラード）** … Vintage Hall / 80s、MIX 25〜35%、PRE-DELAY 0.25（約 30 ms）、DECAY 0.40（約 3 秒）、HIGH CUT 0.5、LOW CUT 0.12
- **スネア** … Plate / NOW、DECAY 0.25〜0.3、SIZE 40〜60%、ATTACK 30%
- **ドラム全体の空気感** … Ambience、DECAY 0.15、SIZE 30%、MIX 15〜20%
- **80 年代のゲートスネア** … Gated、SIZE 30%（約 0.3 秒）、MIX 35%
- **シンセパッドを果てしなく** … Grand Hall / NOW、DECAY 0.75 以上、MOD DEPTH 50%、LOW CUT 0.15

## 測って合わせたこと（開発メモ）

- DECAY: 0.2 + 69.8 × 値^3.33 秒、PRE-DELAY: 500 × 値² ms、BASS MULT: 4^(2×値−1) 倍、MIX: 等パワー（sin / cos）
- HIGH SHELF: ループ 1 周あたり 20·log10(0.229 + 0.771 × 値⁴) dB、HIGH FREQ・BASS XOVER・HIGH CUT は 5〜21 点の表
- HIGH CUT / LOW CUT はループの外の 1 次（6 dB/オクターブ）フィルター
- COLOR: 0〜0.66 = 70s、0.67〜0.99 = 80s、1.0 = NOW（本物のプリセットの値の読み方）
- 70s: 出口に 12 kHz の 12 次楕円ローパス（VintageFilter.h）＋ループの中の 1 枝ごとに 12.7 kHz の 1 次ローパス（本物は 70s のときだけ 5〜12 kHz が 1 周ごとに余分に減る）
- 揺れ: 本物の「1 kHz の正弦を入れたときの音程のにじみ」に合わせて、モードごとに揺れ幅を決めた（tools/measure/fitmod.py）
- モードごとの性格（ループの長さ、初期の粒の時刻・形・量、反対側へ回る量、残響の長さの倍率、音色など）は、
  本物とこのエンジンを同じ方法で測り、差（包絡・密度・減り方・音色・左右）が小さくなるよう自動で探しました
  （`tools/render.cpp` で書き出し、`tools/measure/` の fit.py → genprof.py で Source/Profiles.h を作る。作業データは build/ElderVerbFit）
- 本物の初期値の設定で 22 モードを比べた結果（エンジン単体）: 残響の長さはほぼ ±10%（Grand Hall は長め）、最初の音の時刻はほぼ一致、
  10 ms ごとの音量の形の差は平均 4 dB、聞こえる帯域の音色の差は平均 2 dB

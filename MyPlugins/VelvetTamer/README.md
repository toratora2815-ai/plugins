# Velvet Tamer

レゾナンス（耳に痛い響き・キンキン・ボワつき）を、**鳴った瞬間だけ自動で**下げるプラグイン（Logic 用 AU）。
「動的なレゾナンス抑制」と呼ばれるタイプの考え方を参考にした、オリジナル設計です。

## 何をしているか
音を細かい周波数に分けて、**まわりの周波数より飛び出ている所だけ**を、その瞬間だけ下げます。
- EQ と違って、ずっと削りっぱなしにはならない（響きが鳴っていないときは何もしない）
- まわりとの比べっこなので、音量の大小には左右されない
- ノイズのような平らな音はほとんど触らない（テストで音量変化 0.0 dB）

画面の上半分に、入ってきた音（紫）と、今どこを何 dB 下げているか（ピンク、上から垂れ下がる）が出ます。
右上の **MAX** は、いちばん深く下げている量です。

## グラフをマウスで動かす（v1.1）
- **FOCUS の境目（紫の縦線）** … 左右にドラッグすると LOW / HIGH が動く
- **FOCUS の帯域の中（明るい所）** … つかんで左右にドラッグすると、幅はそのままで帯域ごと動く
- **WEIGHT の点（黄色の丸、7 個）** … 上下にドラッグすると、その帯域だけ効きが強く／弱くなる
  - 真ん中の線が 0%（ふつう）。上に +100% で 2 倍効く、下に -100% でその帯域は効かない
  - 点の周波数は 100 / 250 / 600 / 1.5k / 3.5k / 7k / 14k Hz で固定。点と点の間はなめらかにつながる
- **ダブルクリック** … その点・境目を初期値に戻す
- どれも Logic のオートメーションで動かせます（「Weight 3.5 kHz」など）

## プリセット（右上のメニュー）
Default / Vocal Harshness / Sibilance / Distorted Guitar / Boxy Low-Mids / Mix Bus Polish。
選ぶと、つまみと WEIGHT がまとめて下の「おすすめ設定」の値になります（MIX・OUTPUT・DELTA・LINK はそのまま）。

## つまみ

### AMOUNT
- **DEPTH** … 下げる強さ（0〜100%）。0% で何もしない。まずは 30〜60% くらいから

### DETECT（どんな響きを狙うか）
- **SHARPNESS** … 高いほど**細く鋭いピーク**だけを狙う。低いほど**広めのこもり・盛り上がり**も拾う
- **SELECTIVITY** … 高いほど**目立つピーク**だけを狙う。低いほど小さな飛び出しにも反応する（やりすぎるとこもる）

### TIME（反応の速さ）
- **ATTACK** … 響きを見つけてから下げ始めるまでの速さ（0.5〜50 ms）
- **RELEASE** … 響きが消えてから元に戻るまでの速さ（5〜500 ms）

### FOCUS（効かせる帯域）
- **LOW / HIGH** … この間だけ効きます。外側は半オクターブかけて自然に効かなくなる
  画面の暗い所は「効かない帯域」です

### OUTPUT
- **MIX** … 処理した音と元の音を混ぜる割合
- **OUTPUT** … 出力音量（-12〜+12 dB）

### ボタン（右上）
- **DELTA** … **削っている音だけ**を聴く。どこを削っているか耳で確かめる用（書き出し前に OFF に）
- **LINK** … ON で左右を同じだけ下げる（定位がブレない。普段は ON）

## おすすめ設定

プリセットに入っている値です（WEIGHT もそれぞれ用途に合わせて入っています）。

| 用途 | DEPTH | SHARPNESS | SELECTIVITY | ATTACK / RELEASE | LOW〜HIGH |
|---|---|---|---|---|---|
| ボーカルの耳に痛い所（2〜6 kHz） | 40% | 60% | 40% | 5 ms / 80 ms | 1.5 k〜10 k |
| 歯擦音（サ行）をやわらげる | 60% | 40% | 30% | 1 ms / 40 ms | 4 k〜16 k |
| 歪みギターのキンキン | 50% | 50% | 40% | 5 ms / 100 ms | 1 k〜12 k |
| ボワつく低中域（箱鳴り） | 40% | 30% | 50% | 10 ms / 150 ms | 150〜800 |
| 2mix の仕上げ（うっすら） | 20% | 50% | 60% | 10 ms / 150 ms | 300〜16 k |

使い方のコツ：
1. DEPTH を一度 80% くらいまで上げて、**DELTA** を押して何が削られているか聴く
2. 狙いたい音だけが聞こえるように SHARPNESS / SELECTIVITY / FOCUS を合わせる
3. DELTA を戻して、DEPTH をちょうどいい所まで下げる

## メモ
- 処理のために少し音が遅れます（44.1 / 48 kHz で 2048 サンプル ≒ 43 ms）。Logic が自動で補正するので、普通に使うぶんには気になりません
  （録音しながらモニターするのには向きません）
- モノラル・ステレオどちらのトラックにも挿せます

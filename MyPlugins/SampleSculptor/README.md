# Sample Sculptor

**サンプル（オーディオファイル）を落として、いじって、できた音を Logic にドラッグで戻す**編集プラグイン（Logic 用 AU・音源）。
キック・スネアの形を変える（頭を硬く、短く／長く、響きを消す／足す）のも、声やループを逆再生するのも、これ 1 台でできます。

ファイルを丸ごと計算し直すので、遅れや、鳴り始めの見逃しはありません。元のファイルは変えません。

## 使い方
1. Logic で **ソフトウェア音源のトラック**を作り、音源の欄で「AU 音源 → MyPlugins → Sample Sculptor」を選ぶ
2. **Splice** か Finder から、サンプルを**波形の所に落とす**（Logic のトラックに落とすのと同じ感覚で。クリックか OPEN で選んでも OK。WAV / AIFF / FLAC / MP3 / M4A / CAF）
3. つまみを回す → 自動で作り直して、**すぐ鳴ります**（下の波形 = できた音。クリックかPLAY でもう一度）
   - Logic が止まっていても鳴ります。鍵盤でも鳴らせます（C3 = そのままの高さ、上下で音程が変わる）
4. できたら、**オレンジの波形（RESULT）をつかんで、そのまま Logic のトラックへドラッグ**（下の **⇦ ○○ sculpted.wav** の箱からでも同じ）
   - 先に **EXPORT** を押しておくと書き出して「READY」になります（押さなくても、ドラッグした瞬間に書き出します）
   - ファイルは「ミュージック → Sample Sculptor」にできます。つまみを変えていなければ同じファイルを使い回し、変えたら新しいファイルになります（前に Logic へ入れたものは上書きしません）
   - 箱をクリック = Finder で表示

- 上の波形（ORIGINAL）の**オレンジの線をドラッグ**すると、頭と終わりを切れます
- **A/B ボタン**で聴き比べ: **A: ORIGINAL** = 元の音（START〜END の所だけ）、**B: RESULT** = できた音。押すたびに切り替わってすぐ鳴ります。
  A は**音量を B にそろえて**鳴らすので、「大きくなったから良く聞こえる」にだまされません
- つまみはダブルクリックで最初の値、**RESET** で全部最初に戻ります（サンプルはそのまま）
- 設定とサンプルの場所はプロジェクトに保存されます

## つまみ

### EDIT（編集）
- **REVERSE** … 逆再生
  - **◀ SOUND** … 音を逆向きに（響きを足すときは、逆にした音の後ろに響きがつく）
  - **◀ SOUND + ROOM** … 響きごと逆に ＝ **吸い込まれるような「逆再生リバーブ」**（ROOM を右に回すと効く）
- **FADE IN / FADE OUT** … 頭・終わりのフェード（0〜0.5 秒 / 0〜3 秒）
- **PITCH**（±24 半音）… 音程。サンプラーと同じで**速さと長さも一緒に変わります**（+12 で半分の長さ）
- **STRETCH**（25〜400 %）… **音程を変えずに長さだけ**変える（200 % = 2 倍の長さ）
  - 声・ループ・パッドに向いています。キックやスネアを長くしたいときは LENGTH（余韻を持ち上げる）の方が自然です
  - PITCH と組み合わせると「長さはそのまま音程だけ」もできます（PITCH +12 と STRETCH 200 %）

### SHAPE（形）
- **ATTACK**（左 = やわらかい頭、右 = 硬い頭。最大 ±18 dB くらい）
- **SNAP**（1〜50 ms）… どこまでを「頭」とみなすか。短い = クリックだけ、長い = 胴鳴りまで
- **LENGTH**（左 = 短く切る、右 = 余韻を持ち上げて長く）
  - ループや声のように何回も鳴る音では、鳴り始めごとに効きます

### ROOM（響き）
- **ROOM**（左 = **DRY**: 元の部屋の響きを消してカラカラに、右 = **WET**: 部屋の響きを足す。足すとファイルが響きの分だけ長くなる）
- **SIZE** … 足す部屋の大きさ（響き 約 0.1〜1.8 秒）
- **TONE** … 足す響きの明るさ
  （SIZE / TONE は ROOM を右にしたときだけ効きます）

### TONE（音色）
- **LOW CUT**（OFF〜1 kHz）… これより低い所を切る（24 dB/oct）。こもり・余計な低音を取る
- **HIGH CUT**（1 kHz〜OFF）… これより高い所を切る。耳に痛い高音・ノイズを取る、昔っぽく
- **WIDTH**（0〜200 %）… ステレオの広さ。0 % = モノラル、100 % = そのまま、200 % = 広く（ステレオのファイルだけ）

### OUT
- **DRIVE** … ソフトクリップで太く（4 倍オーバーサンプリング）
- **GAIN** … 音量
- **NORMALIZE**（標準 ON）… 一番大きい所を -0.3 dB にそろえ、そこから GAIN をかける

## おすすめ
| やりたいこと | 設定 |
|---|---|
| キックをタイトに | ATTACK +30, LENGTH -55, ROOM -40 |
| キックを 808 っぽく長く | LENGTH +70, PITCH -2, DRIVE 10 |
| 響きを全部消す | ROOM -100, LENGTH -30 |
| スネアをスナッピーに | ATTACK +70, SNAP 8 ms, LENGTH -30 |
| スネアに大きい部屋 | ROOM +70, SIZE 75, TONE 60 |
| 逆再生シンバル風（吸い込み） | REVERSE ◀ SOUND + ROOM, ROOM +60, SIZE 70 |
| 声を逆再生 | REVERSE ◀ SOUND, FADE IN 30 ms |
| ループをテンポ半分の長さに | STRETCH 200 % |
| キックの余計な低音・高音を取る | LOW CUT 30 Hz, HIGH CUT 12 kHz |
| ステレオのサンプルを真ん中に | WIDTH 0 % |
| 声の前に吸い込む響き | 声の一言を START/END で切り出し → REVERSE ◀ SOUND + ROOM, ROOM +80, SIZE 80 → 声の手前に置く |

## 画面のいちばん下（LINK・プリセット・取り消し）
- **LINK**（LINK OFF / LINK 1〜4）… 自作プラグイン同士の連携の欄。Sample Sculptor には今のところ連携する相手がないので、OFF のままで大丈夫です
- **UNDO / REDO** … つまみの操作を 1 手ずつ取り消し・やり直し（100 手まで。画面を閉じても残ります）
- **< >** … 前／次の自分のプリセット。真ん中の名前を押すと一覧（Save as... / Delete / Show preset folder in Finder）
- **SAVE** … 今のつまみに名前を付けて保存（~/Library/Audio/Presets/MyPlugins/Sample Sculptor。Logic のプリセットと同じ場所）
- プリセットで変わるのはつまみだけ。読み込んだサンプルはそのままです

## Logic の音を入れるには
- Logic のリージョンは直接は落とせないことがあります。そのときは
  1. リージョンを選んで「ファイル → 書き出す → 選択範囲をオーディオファイルとして」（または「リージョンをオーディオファイルとして書き出す」）
  2. できたファイルを Finder から落とす
- Logic の右上「ブラウザ」→「プロジェクト」の一覧からドラッグできる場合もあります

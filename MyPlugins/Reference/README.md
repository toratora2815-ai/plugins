# Reference（リファレンス）

自分の曲と参照曲（好きなプロの曲）を、ボタン1つで聴き比べるプラグインです。
参照曲は **音声ファイル** か、**Spotify / Apple Music / YouTube で流している音そのもの（ライブ入力）** から選べます。
音量を自動でそろえるので、「大きいほうが良く聴こえる」錯覚なしで比べられます。

> 有名な参照プラグインの機能を参考にしたオリジナルのプラグインです。

---

## 挿す場所

Logic の **Stereo Out（マスター）のいちばん下のスロット** に挿してください。
（ほかのプラグインより後ろにすることで、完成形の音と比べられます）

**書き出し（バウンス）の前に、必ず「MY MIX」に戻すか、プラグインをオフにしてください。**
REFERENCE のまま書き出すと、参照曲が書き出されてしまいます。

---

## 画面とつまみ

### 上の段：参照曲の入れ方
| ボタン | 説明 |
|---|---|
| **FILE / LIVE** | 参照曲をファイルから読むか、Mac で流している音（ライブ入力）を使うか |
| **RESET METERS** | メーター（音量の計測）をゼロからやり直す。曲や区間を変えたら押す |

**FILE のとき**
| ボタン | 説明 |
|---|---|
| **LOAD** | 参照曲を選ぶ（WAV / AIFF / MP3 / M4A / FLAC）。画面にドラッグ＆ドロップでも OK |
| **PLAY / PAUSE** | 参照曲の再生・一時停止 |
| **LOOP** | 最後まで行ったら頭に戻る |
| **FOLLOW DAW** | Logic の再生／停止に合わせて参照曲も再生／停止する |
| 波形 | クリック・ドラッグで好きな場所に移動 |

**LIVE のとき**
| 項目 | 説明 |
|---|---|
| デバイス選択 | 「BlackHole 2ch」を選ぶ（入っていれば自動で選ばれます） |
| **REFRESH** | デバイス一覧の読み直し・つなぎ直し |
| 状態表示 | 緑＝受信中／オレンジ＝音が来ていない／赤＝開けなかった |

### 真ん中：A/B 切り替え
| ボタン | 説明 |
|---|---|
| **MY MIX** | 自分の曲を聴く（ふだんはこちら） |
| **REFERENCE** | 参照曲を聴く |

切り替えは 0.02 秒でなめらかにつなぐので「プチッ」となりません。

### スペクトラム（左）
- 紫＝自分の曲、オレンジ＝参照曲の周波数バランス。**いま聴いている音量に合わせて** 表示します
- 下の白い線は **「自分の曲 − 参照曲」の音色の差**（全体の音量差は除いてあります）
  - 0 より上 → その帯域が参照曲より **多い**
  - 0 より下 → その帯域が参照曲より **少ない**
- 両方の曲を一度ずつ鳴らすと表示されます（片方を止めても最後の形が残ります）

### メーター（右）
左から MIX（自分の曲）、REF（参照曲）、DIFF（自分 − 参照）

| 項目 | 意味 |
|---|---|
| SHORT-TERM LUFS | 直近3秒の音量 |
| INTEGRATED LUFS | 計り始めてからの平均音量（ストリーミングの基準と同じ測り方） |
| PEAK (3s) dBFS | 直近3秒の最大レベル |
| MAX PEAK dBFS | 計り始めてからの最大レベル |
| DYNAMICS (PSR) | ピークと音量の差。**小さいほど潰れている**（目安：ポップス 7〜10、EDM 5〜8） |
| CORRELATION | 左右の似ている度合い。1＝モノ、0付近＝広い、マイナス＝位相の問題あり |
| SIDE % | 横（ステレオ成分）の量。0%＝完全モノ |
| GAIN APPLIED dB | 音量合わせのためにいま掛けている増減 |

メーターは聴いていない側も **ずっと測り続けます**。

### 下の段
| つまみ | 説明 |
|---|---|
| **LEVEL: OFF** | 音量合わせなし（そのままの音量） |
| **LEVEL: MATCH** | 参照曲の音量を **自分の曲に自動で合わせる**（おすすめ・初期設定） |
| **LEVEL: -14 LUFS** | 両方を Spotify 基準（−14 LUFS）にそろえる。**アップロード後に実際どう聴こえるか** が分かる。小さい曲は、ピークが −1dB を超えない範囲でだけ上げます |
| **BAND SOLO** | FULL＝全部／LOW＝200Hz 以下／MID＝200Hz〜3kHz／HIGH＝3kHz 以上 だけを聴く |
| **STEREO** | STEREO＝そのまま／MONO＝モノラル（スマホのスピーカーっぽく）／SIDE＝横の成分だけ |
| **REF TRIM** | 参照曲の音量を手で ±12dB 微調整（ダブルクリックで 0 に戻る） |

BAND SOLO と STEREO は **両方の曲に同じようにかかる** ので、帯域ごとに聴き比べられます。

## 準備①：ファイルだけで使う場合

準備はいりません。LOAD で参照曲を選ぶだけです。
（iTunes Store で買った曲、自分で持っている WAV など。Apple Music のライブラリの曲はコピー防止があるので、ライブ入力を使ってください）

## 準備②：Spotify などをそのまま使う場合（ライブ入力）

**最初に1回だけ** の準備です。

### 1. BlackHole（無料の仮想オーディオ）を入れる
1. Safari で https://existential.audio/blackhole/ を開く
2. メールアドレスを入れて「BlackHole 2ch」をダウンロード（無料。メールで届くリンクから）
3. ダウンロードした .pkg を開いてインストール → Mac を再起動

（Homebrew を使っている人は、ターミナルで `brew install blackhole-2ch` でも入ります）

### 2. Logic の出力先を固定する（大事）
1. Logic を開く → メニュー「Logic Pro」→「設定」→「オーディオ」
2. 「出力デバイス」を **いつも使っているもの**（オーディオインターフェイス名、または「MacBook Pro のスピーカー」など）にする
   - 「システム設定」のままだと、次の手順で Logic の音まで BlackHole に行って聴こえなくなります

### 3. Logic にマイクの許可があるか確認
「システム設定」→「プライバシーとセキュリティ」→「マイク」→ **Logic Pro がオン**
（BlackHole は「入力デバイス」として扱われるので、この許可が必要です）

### 使うとき
1. Mac 画面右上のコントロールセンター →「サウンド」→ 出力を **BlackHole 2ch** にする
2. Spotify / Apple Music / YouTube で参照曲を再生
3. Reference で **LIVE** を選ぶ → 緑の「Receiving from BlackHole 2ch」が出れば OK
4. REFERENCE を押すと、その曲が聴こえます
5. 使い終わったら、Mac の出力をいつものスピーカーに戻す

**Spotify の設定**：「設定」→「音量の自動調整」は **オンのまま** でOK（ストリーミングで実際に鳴る音と比べられます）。Spotify の音量スライダーは **最大** にしてください。

**曲を変えたとき**：ライブ入力で3秒以上の無音のあとに音が来ると、新しい曲とみなして参照曲側のメーターを自動でやり直します。無音がない切り替えのときは RESET METERS を押してください。

## おすすめの使い方

1. **LEVEL を MATCH** にして、自分の曲のサビと参照曲のサビを鳴らす
2. RESET METERS を押して、10秒くらい両方を鳴らす（メーターが安定する）
3. MY MIX ⇔ REFERENCE を何度か切り替えて、まず全体の印象を比べる
4. スペクトラム下の白い線で「多すぎる／少なすぎる帯域」を見る
5. BAND SOLO で **LOW だけ** 比べる → キックとベースの量・まとまり
6. **MID だけ** → ボーカルの前に出かた、こもり
7. **HIGH だけ** → シンバル・歯擦音・空気感
8. STEREO を **MONO** にして、モノで聴いても埋もれないか確認
9. 最後に **-14 LUFS** にして、ストリーミングで並んだときの印象を確認
   - DYNAMICS（PSR）が参照曲より大きく下回っていたら、潰しすぎのサイン

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| Logic を止めている間、参照曲が鳴らない | Logic を再生しながら比べてください（Logic が停止中に処理を止めることがあるため） |
| LIVE で「BlackHole not found」 | BlackHole を入れて Mac を再起動 → REFRESH |
| LIVE でオレンジの「No sound」 | Mac のサウンド出力が BlackHole になっているか、Spotify が再生中か、Logic のマイク許可を確認 |
| Logic の音が聴こえなくなった | 準備②-2（Logic の出力先を固定）をやり直す |
| 赤い「Couldn't open device」 | ほかのアプリが BlackHole を独占していないか確認して REFRESH |
| 音量合わせがおかしい | RESET METERS を押して、両方を10秒ほど鳴らし直す |
| 参照曲がモノラルっぽい | 曲がモノラル音源か、STEREO が MONO / SIDE になっていないか確認 |

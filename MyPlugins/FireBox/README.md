# Fire Box（ファイアボックス）

ドラム・ベース・シンセ・ボーカルを「太く・前に・大きく」する、多機能の音作りプラグインです。
手持ちの市販プラグインに実際に音を通して測り、**音の処理を同じ動きになるように作りました**（名前と見た目はオリジナル）。

## 音の流れ
IN → BASS → THICK → BODY → COMP（または OTT）→ SOFT CLIP → CRUNCH → MIX → LOUD → UNITY → OUT

各つまみの上の **ON** で、その部分だけを外せます（音の比較に便利）。

## つまみ
| つまみ | 何をする | 範囲 |
|---|---|---|
| IN | 入口の音量。上げるほど後ろの歪み・圧縮・クリップが強くかかる | -12〜+12 dB |
| BASS | 低音（約 210 Hz 以下）だけを歪ませて太くする。22% を超えると 54 Hz 付近も持ち上がる（その半分の 27 Hz は少し下げる） | 0〜100%（初期 15%） |
| THICK | 中域を強調しながら全体をなめらかに歪ませる。左右の差（サイド）を多めに持ち上げるので広がりも出る | 0〜100%（初期 13%） |
| BODY | 小さい音をゆっくり（約 1 秒かけて）持ち上げる「上向きの圧縮」。上げすぎると少しポンピングする | 0〜100% |
| COMP | とても速いコンプ（3.5:1、自動で音量を戻す）。波形の山ごとに動くので、音の高さが低いほどゆったり動く | 0〜48 dB |
| OTT（COMP の横のボタン） | COMP のつまみを 3 帯域（88 Hz・2.5 kHz で分ける）の上げ下げ圧縮に切り替える。小さい成分を大きく持ち上げ、大きい成分を下げる | 0〜48 dB |
| SOFT CLIP | 大きいところをなめらかに頭打ちにする | 0〜100% |
| CRUNCH | 信号をつぶすファズ。SOFT CLIP と一緒に使うと、2 つがまざった独特の形になる | 0〜100% |
| MIX | 元の音とのまぜ具合（パラレル処理） | 0〜100% |
| LOUD | 最後のリミッターに入れる量。0 dBFS を超えないように、波形の山ごとに音量を下げる | 0〜24 dB |
| OUT | 出口の音量（リミッターの後） | -12〜+12 dB |

## 上のボタン
- **UNITY** … 出口の音量を入口と同じにそろえる（4 秒の平均で比べる。IN と OUT は対象外）。設定を変えても音量が変わらないので、「大きいほうが良く聞こえる」錯覚なしで比べられる
- **LIVE** … 遅れを小さくする（2464 → 576 サンプル、48 kHz のとき）。COMP / OTT と LOUD の先読みが短くなる
- **192k** … 約 192 kHz で処理する（44.1 / 48 kHz なら 4 倍）。歪みの折り返しノイズが減るぶん、少し重くなる
- **BYPASS** … 遅れをそろえたままの素通し

## おすすめ設定
- **ドラムバスを太く**: BASS 15%、THICK 25%、COMP 12 dB、SOFT CLIP 35%、LOUD 4 dB
- **パラレルで潰す**: COMP 30 dB、MIX 40%
- **シンセを大きく**: THICK 45%、OTT にして 8〜12 dB
- **ボーカルの粒をそろえる**: COMP 8 dB、BODY 20%
- **ボーカルに荒さ**: CRUNCH 15〜25%、MIX 50%
- **思い切り歪ませる**: IN を +6〜+12 dB まで上げる（LOUD が 0 dBFS を超えないようにしてくれるので、OUT で音量を戻す）

## Plugin Link
画面いちばん下の LINK を Gain Stage と同じ番号にして MATCH を ON にすると、出口の音量を Gain Stage の TARGET にそろえます。

## 遅れ（レイテンシー）
48 kHz で 2464 サンプル（約 51 ms）。Logic が自動で補正します。LIVE なら 576 サンプル。

## どれくらい同じか（もとのプラグインとの差）
同じ音を通したときの差です（−60 dB より小さければ、まず聞き分けられません）。
- 初期設定のまま: −75 dB
- BASS / SOFT CLIP / CRUNCH / LOUD: −140 dB 以下（計算の誤差だけ）
- THICK −93 dB、COMP −86 dB、SOFT CLIP と CRUNCH の同時使用 −57 dB、UNITY −62 dB
- BODY −44 dB（ゆっくり持ち上げる動きの細部が少し違う）
- **OTT −23 dB**（ここだけまだ細かい動きが合いきっていない。音の方向性は同じ）

測定と当てはめの道具は `build/fuellab/`（リポジトリには入れていない）、表のデータは `Source/Tables.h` と `Data/clip2d.bin`。

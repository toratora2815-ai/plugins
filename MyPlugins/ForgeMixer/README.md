# Forge Mixer 1.0.0

Forge Strip を入れたトラックを 1 つの画面に並べて、音の置き場所を見ながら動かすミキサーです（音は素通し）。

## 使い方
1. 各トラックに Forge Strip を入れ、画面いちばん下の **LINK** を同じ番号（例 1）にする
2. どこか 1 つのトラック（バスなど）に Forge Mixer を入れ、**LINK** を同じ番号にする
3. 画面にトラックが点で並びます
   - 左右 = パン、上下 = 音量（Forge Strip の OUTPUT）、点の大きさ = 幅（WIDTH）、明るさ = 今の音量
4. 点をドラッグ = 音量とパン（Shift を押しながら = 音量だけ）
5. 点の上でホイール = 幅、ダブルクリック = 0 dB・真ん中・幅 0 に戻す
6. 右の一覧で、各トラックの数値と「低 / 中 / 高」の音量（200 Hz 以下 / 全体 / 4 kHz 以上）を見比べられます

動かした値は各 Forge Strip のつまみに入るので、プロジェクトに保存され、Logic のオートメーションにも記録できます。

画面のいちばん下の右に **UNDO / REDO** の欄がありますが、Forge Mixer 自身には LINK 以外のつまみがないので、今は取り消すものがありません（点を動かした結果は各 Forge Strip のつまみに入ります）。プリセットの保存もありません。

## おすすめ
- まず全部の点を真ん中の 0 dB に置き、ボーカルを少し上、ベースとキックを真ん中、ギターやシンセを左右に開く
- 低の棒が長いトラックどうしは、片方を下げるか、SCULPTOR / UNMASK で場所を分ける

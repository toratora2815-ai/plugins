# Meld Verb（メルド・ヴァーブ）

3 種類の響き（EARLY＝初期反射 / PLATE＝プレート / HALL＝ホール）を三角形のパッドで混ぜて作るリバーブです。
市販の「3 つの響きを混ぜる」タイプのリバーブに実際に音を通して、残響の長さ・高音と低音の減り方・立ち上がり・左右の広がり・音量・
自動で響きを抑える動き（SMOOTHING）を数値で測り、それに合わせて一から作りました（プログラムはオリジナルです）。

測って合わせた結果（参考プラグインとの差、インパルスで測定）:
- 残響の長さ（8 帯域の平均）… PLATE 約 5%、HALL 約 8%、全部を混ぜた標準の設定で約 7%
- 全体の音量 … 標準の設定で 0.1 dB
- SMOOTHING の動き（響きへ送る量の上げ下げ）… 平均 1 dB 以内

## 画面

### BLEND（左）
三角形の中の白い点をドラッグすると、3 つの響きの量が変わります。
- 上 = EARLY、左下 = PLATE、右下 = HALL。角に近づけるほどその響きが大きくなります
- 真ん中で 3 つとも -3 dB。辺の上に置くと、反対の角の響きは消えます（OFF）
- 下の 3 本のスライダーでも 1 つずつ決められます（いちばん左で OFF）

### EARLY / PLATE / HALL（真ん中）
上のタブで選んだ響きのつまみが出ます。グラフは「時間と音量」で、EARLY は跳ね返りの棒、PLATE と HALL は減っていく形です。

**EARLY（初期反射）**
| つまみ | 説明 |
|---|---|
| TIME | 跳ね返りが続く長さ（0〜250 ms）。12 個の跳ね返りがこの中に並びます |
| SIZE | 1 つ 1 つの跳ね返りの「にじむ長さ」。小さいとパチッと、大きいと長く尾を引いてつながります |
| DIFFUSION | 0 で 1 本ずつの鋭い跳ね返り、100 でにじんだなめらかな跳ね返り |
| ANGLE | 0 = 音源と同じ側から、最初が大きく後ろほど小さい／40 = 平ら／100 = 反対側から、後ろほど大きい（遠くから回り込む感じ） |
| LOWPASS | 反対側に届く跳ね返りの高音を少し丸める（頭の陰） |

**PLATE / HALL（残響）**
| つまみ | 説明 |
|---|---|
| TIME | 残響の長さ（0.02〜24 秒）。SYNC を押すと曲のテンポに合わせた音符の長さ（下のメニュー）になります |
| SIZE | 部屋の大きさ。大きいほど響きの粒が粗く、立ち上がりがゆっくり、高音が長く残ります |
| DIFFUSION | 出だしのにじみ。上げるとすぐに密な響きになります |
| ATTACK | 響きがふくらむまでの時間（0〜250 ms）。HALL で上げると「ふわっ」と遅れて広がります |
| LOWPASS | これより上の高音が早く消えます（暗い響き） |
| DAMPING | LOWPASS の効きの深さ。0 で高音がよく消え、10 で高音が残ります |
| BALANCE | 0.5 で低音も高音も同じ長さ。0.5 より小さいと CROSSOVER より上が、大きいと下が短くなります |
| CROSSOVER | BALANCE の境目の周波数 |

### 右の列
| つまみ | 説明 |
|---|---|
| PRE-DELAY | 響きが始まるまでの待ち時間（0〜1000 ms）。SYNC でテンポに合わせた音符の長さに |
| MODULATION RATE / DEPTH | 響きの揺れの速さと深さ。Random（ゆっくり不規則）と Pitch（音程が揺れるコーラス風）から選べます |
| SMOOTHING | 響きを自動で抑える機能（下で詳しく） |
| DRY/WET | 元の音と響きの割合（50% でちょうど半分ずつ） |
| OUTPUT | 最後の音量 |

### SMOOTHING（自動で響きを抑える）
ON にすると、響きへ送る音の量を自動で上げ下げします。音の大きさには関係なく、「今の音」と「ここ数秒の音」を比べて決めます。
- 新しく鳴り始めた音（スネアの 1 発、歌の出だし）… 少し多め（最大 +1.9 dB）
- 同じ大きさで続く音（伸ばした声、パッド）… 少なめ（約 -3 dB）。響きがもやもや溜まりません
- 前より静かになった所（サビの後の静かな部分）… さらに少なく。大きい音の響きの後ろで小さい音がにごりません
- AMOUNT で効き具合（0〜100%）。下のバーに今の量（send ○ dB）が出ます

### EQ（下）
- **PRE EQ** … 響きに入る前の音を整えます（元の音そのものは変わりません）
- **REVERB EQ** … できた響きの音色を整えます
- LOW（Low Shelf / High Pass）、BELL、HIGH（High Shelf / Low Pass）の 3 つ。シェルフの GAIN は「その周波数での量」（平らな所はその 2 倍）、
  High Pass / Low Pass の SLOPE は 0.7 で 6 dB/oct、3 で 12 dB/oct、6 で 24 dB/oct
- グラフの灰色が入力（元の音）、青が響きのスペクトル

**LEARN（PRE EQ を自動で）** … 押して曲を 5 秒流すと、入力の中の「まわりより飛び出た耳に痛い響き」を探して、BELL で下げます。
低いゴロゴロが多いときは 70 Hz のローカットも入れます。響きが「キーン」「ボワン」と鳴るのを防ぎます。

**UNMASK（REVERB EQ を自動で）** … 押して曲を 5 秒流すと、元の音と響きを比べて、響きが元の音を隠している帯域だけ響きを下げます
（低域・中域のベル・高域）。右の AMOUNT で効き具合を後から変えられます（つまみを離したときに入れ直します）。

## おすすめの使い方
- **ボーカル** … プリセット「Vocal Plate」→ SMOOTHING ON。UNMASK を 1 回かけると歌詞がにごりにくくなります
- **スネア** … 「Snare Plate」。BLEND の点を PLATE と HALL の間に動かすと広がりが増えます
- **ドラム全体** … 「Drum Room」。EARLY 多めで部屋っぽく
- **ピアノ・アコギ** … 「Piano Hall」。HALL の ATTACK を上げるとやわらかく
- **ストリングス・パッド** … 「Big Hall」「Ambient Wash」。MOD を Pitch にすると揺れが増えます
- 響きが曲の中で邪魔なとき … SMOOTHING ON → それでも濁るなら UNMASK

## メモ
- 遅延（レイテンシー）は 0 です
- SMOOTHING を ON にすると、響きへ送る音だけ 1 ms 遅れます（PRE-DELAY から自動で差し引きます）
- 測定と合わせ込みに使ったテスト: `tools/render_meld.cpp`（参考と同じ番号でつまみを指定して音を書き出す）、`tools/test_meld.cpp`（発振・減衰・つまみを乱暴に動かす・LEARN の計算）

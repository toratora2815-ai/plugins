# 提案 2026-11-06 11:53（日本時間）

### 1. Plugin Link：ボーカルの「居場所」を、サイドチェーンの配線なしでギターやシンセから空ける
- 種類: 改善（Fader Pilot と Velvet Tamer。Plugin Link の新しいつなぎ方）
- できるようになること: ボーカルの Fader Pilot と、ギターやシンセの Velvet Tamer を同じ LINK 番号にするだけで、声が鳴っている帯域だけをギター側で一瞬下げられる。Logic のサイドチェーンメニューで毎回トラックを選ぶ必要がなく、何本のトラックにも同時に効かせられる。
- なぜ今: Velvet Tamer 1.2 のサイドチェーンは 1 本ずつ Logic で配線が必要。Plugin Link の掲示板ができたので、声の帯域の情報を流せば配線なしで同じことができる。
- 中身:
  - Fader Pilot が、声の大まかな帯域の強さ（8 帯域）と「今歌っているか」を Link に出す
  - Velvet Tamer に MODE「VOCAL SPACE（Link）」を足し、その 8 帯域の強い所だけ、自分のトラックから下げる（DEPTH・FOCUS・WEIGHT はいつもどおり効く）
  - 画面に、受け取っている声の帯域を重ねて表示
  - 何本のギター／シンセでも同じボーカルを参照できる
- 大きさ: 中
- 気をつける点: Link の 1 席の数値は 24 個までなので、帯域は 8 個程度にまとめる（細かい倍音までは追えない。細かくやりたいときは今のサイドチェーンを使う、と README に書く）。遅延の違う 2 つのプラグインのタイミングのずれを数値テストで確認する。

### 2. Project Shelf（ProjectShelf）：Logic のプロジェクトの「棚」アプリ
- 種類: 新規（単体 Mac アプリ）
- できるようになること: ~/Music/Logic のプロジェクトを、最後に触った日・キーとテンポ・バウンスの回数・メモ付きで一覧にして、「最近止まっている曲」「あと少しの曲」がひと目で分かる。押せばそのプロジェクトが開く。
- なぜ今: Idea Catcher で思いつきのプロジェクトが増え、Mix Time Machine でバウンスの履歴も残るようになった。曲が増えるほど「どれをやりかけだったか」が分からなくなる。
- 中身:
  - プロジェクトの一覧（名前・最後に保存した日・テンポ・キー・長さ）
  - Mix Time Machine のバウンスの数と最新の日付、Idea Catcher から来た曲かどうか
  - 状態のラベル（アイデア / 作業中 / ミックス中 / 完成）と一言メモ、並べ替え・絞り込み
  - 「2 週間触っていない作業中の曲」をそっと知らせる
  - Num Deck から「次にやる曲を開く」を押せるようにする
- 大きさ: 中
- 気をつける点: Logic のプロジェクトの中身は読むだけにして、絶対に書き換えない（テンポ・キーは Idea Catcher の記録や、プロジェクトの中の情報が読める範囲だけ）。メモやラベルは別のファイルに保存する。

### 3. Lumen Rooms：歌っている間は控えめ、歌の切れ目で広がるリバーブ（Plugin Link とテンポ同期）
- 種類: 改善（LumenRooms）
- できるようになること: ボーカルのリバーブが、歌っている間は小さく、フレーズの切れ目でふわっと広がる。言葉がにごらずに、余韻だけ豊かになる。プリディレイもテンポに合わせられる。
- なぜ今: Lumen Rooms はプリセットやメーターまでそろったが、まだ Plugin Link につながっていない。Fader Pilot はもう「声が鳴っているか」を Link に出しているので、受け取るだけで実現できる。
- 中身:
  - DUCK（歌っている間に下げる量）と RELEASE（切れ目で戻る速さ）。声の情報は同じ LINK 番号の Fader Pilot から（配線不要）
  - Link がないときは、入ってくる音そのもので下げる（センドの中でも使える）
  - PRE-DELAY のテンポ同期（1/64〜1/8、付点・3 連）
  - LinkBar（画面いちばん下）を他のプラグインと同じ形で付ける
- 大きさ: 小〜中
- 気をつける点: 既存のパラメーター ID と音（DUCK 0 のとき）は変えない。下げ始め・戻りでポンプ感が出すぎないよう、数値テストと試聴用のプリセットで確認する。

### 1. 全プラグイン共通：自分の設定を名前を付けて保存・呼び出し（マイプリセット）
- 種類: 改善（Velvet Tamer / Fader Pilot / Horizon Spread / Balance Scope / Gain Stage / Nebula / Wool Fuzz / Porch Drive）
- できるようになること: 「いつものボーカル用」「自分の歪みギター」のように、作った設定を名前を付けて保存し、別の曲でもメニューから一発で呼び出せる。どのプラグインでも同じ操作。
- なぜ今: 今あるのは最初から入っているプリセットだけで、自分で詰めた設定は曲ごとに作り直しになる。プラグインが増えてきて、同じ手間があちこちで起きている。
- 中身:
  - 各プラグインのプリセットメニューに「今の設定を保存…」「名前を変える」「消す」と、自分のプリセットの一覧
  - 保存先は ~/Music/MyPlugins Presets/<プラグイン名>/（ファイルなので、Mac を替えても持っていける）
  - 共通の部品（1 つのファイル）を作って、全プラグインで同じものを使う
  - プリセットがないプラグイン（Wool Fuzz / Porch Drive / Nebula）にも、このメニューだけ付ける
- 大きさ: 中（プラグインの数が多いので、2 回に分けるかも）
- 気をつける点: 保存するのは音に関わるつまみだけにする（DELTA や SIDE SOLO のような「確認用のボタン」や、Balance Scope の参照カーブは入れない）。既存のパラメーター ID は変えない。

### 2. Breath Hush（BreathHush）：ボーカルの息継ぎだけを自動で小さくする
- 種類: 新規
- できるようになること: 歌と歌の間の「スッ」「ハッ」という息だけを見つけて、決めた量だけ下げる。リージョンを切ってフェードを書く手間がなくなる。消しすぎず「少し下げる」ので自然。
- なぜ今: Fader Pilot や Gain Stage で音量を上げると、息も一緒に大きくなる。コンプをかけるとさらに目立つ。仕上げで毎回手で直している所。
- 中身:
  - 息の見つけ方：声の高さ（音程）がなく、高めの帯域にエネルギーが集まっている所を「息」と判定
  - REDUCE（-3〜-30 dB）/ SENSITIVITY / ATTACK・RELEASE
  - LISTEN（息だけを聴いて、正しく見つけているか確かめる）
  - 波形の上に、息と判定した所を色で表示
  - 少しだけ先読みする（10 ms 程度。Logic が自動で補正）
- 大きさ: 中
- 気をつける点: サ行（歯擦音）を息と間違えないように、続く長さと帯域で見分ける。数値テストで、声の部分は 0.1 dB も変わらないこと、息の部分が設定どおり下がることを確認する。PLUGIN_CODE は未使用の4文字（例: Brhs）。

### 3. Mix Time Machine：バウンスごとのメモと「次にやること」リスト
- 種類: 改善（MixTimeMachine）
- できるようになること: バウンスを聴き比べながら「v3 はボーカルが前に出すぎ」「キックの低域を足す」のようにメモでき、次のバウンスのときに「前回やると決めたこと」がチェックリストで出る。どの版で何を直したかが後から分かる。
- なぜ今: 聴き比べの仕組み（A/B・ブラインドテスト・何が変わったか）はそろったが、気づいたことを書き留める場所がない。数日空けると、何を直すつもりだったか忘れる。
- 中身:
  - 各バウンスにメモ欄（曲の何秒目のことか、再生位置を押すと付く）
  - 「次にやること」リスト。次のバウンスが取り込まれたら、チェックを付けられる形で出す
  - メモの位置を押すと、そこから再生
  - Num Deck の Logic Pro モードから「今の位置にメモ」を押せるようにする（文字はあとで入れる）
- 大きさ: 中
- 気をつける点: メモは ~/Music/Mix Time Machine の中に保存し、公開リポジトリには入れない。曲名ごとのまとまり（今のファイル名のルール）に合わせる。

### 1. Nebula 1.1.0：プリセット＋「リバーブ専用」の整え機能
- 種類: 改善（Nebula）
- できるようになること: センドに挿したまま、残響の濁りや耳に痛い高域を抑え、ドラムやボーカルの後ろで邪魔しない残響に整える。プリセットで一発で目的の空間を呼び出せる。
- なぜ今: Horizon Spread・Velvet Tamer にはプリセットがあるが Nebula にはない。UI も他と比べて素っ気なく、README に VST3 の記述が残っている。
- 中身:
  - 内蔵プリセット10個前後（パッド / 映画 / ピアノ / 短いプレート風 など）とプリセットメニュー
  - DUCK（原音が鳴っている間だけ残響を下げ、止まると戻る）
  - 残響の HIGH CUT / 低域のかぶり抑え（LOW CUT の対になるもの）
  - 残響の減衰カーブとスペクトルを表示するグラフ
  - README を AU 専用に整理
- 大きさ: 中
- 気をつける点: DUCK の効き方とシマーの組み合わせで音が揺れすぎないか数値テストで確認する。既存のパラメーター ID は変えない。

### 2. Tape Pocket（TapePocket）：テープ風の温かさとまとまりを足す
- 種類: 新規
- できるようになること: ドラムバスやミックス全体に挿すだけで、角が丸くなり、高域がなめらかになって音がまとまる。ワウ・フラッター（ゆらぎ）も量を決めて足せる。
- なぜ今: 歪み系（ファズ・ドライブ）と空間系はあるが、「かけ録り感」を出す微妙な飽和系がない。ミックスの仕上げに使う頻度が高い。
- 中身:
  - DRIVE（テープ飽和。4倍オーバーサンプリング）
  - TONE（高域の丸め）と HEAD BUMP（低域の膨らみ）
  - WOW / FLUTTER（ピッチのゆらぎ）
  - NOISE（テープヒス。オフにもできる）
  - INPUT / OUTPUT と自動音量合わせ
- 大きさ: 中
- 気をつける点: 実在のテープ機の名前や見た目は使わない。ゆらぎは小さい値からにして、ずれた音程に聞こえないか確認する。PLUGIN_CODE は未使用の4文字（例: Tppk）。

### 3. Wool Fuzz / Porch Drive：プリセット・ゲインを合わせるつまみ・入出力メーター
- 種類: 改善（WoolFuzz と PorchDrive）
- できるようになること: かけたときの音量差を気にせず音色だけ比べられる。好みの設定を保存、呼び出せる。音が割れたかどうかも目で分かる。
- なぜ今: 歪み2つはつまみが3つだけで、ほかの新しいプラグインにある使いやすさ（プリセット・音量合わせ・メーター）が付いていない。
- 中身:
  - 内蔵プリセット各5個前後とプリセットメニュー
  - OUTPUT つまみ（WoolFuzz は VOLUME とは別に自動音量合わせの ON/OFF）
  - 入力と出力のレベルメーター
  - DRY/WET の MIX（パラレルで歪ませる用）
  - 既存の音色（DSP）は変えない
- 大きさ: 小〜中（2つ同時でも1回で終わる見込み）
- 気をつける点: MIX を足すとオーバーサンプリングの遅延と原音のタイミングを揃える必要がある。既存のパラメーター ID は変えない。

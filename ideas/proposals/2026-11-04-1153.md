### 1. Num Deck：1 つのキーで「いくつもの操作を順番に」送るマクロ → GO 済み（2026-11-04）
- 種類: 改善（NumDeck）
- できるようになること: たとえば「選んだトラックをソロ → サイクルを先頭へ → 再生」や「書き出しの前の準備一式」を、テンキー 1 回で実行できる。いつも同じ順番で押しているキー操作をまとめられる。
- なぜ今: Num Deck はページ・タイル・分割表示まで育ってきて、毎日使う道具になっている。1 キー 1 操作のままだと、よく使う手順はやっぱり何回も押すことになる。
- 中身:
  - タイルの割り当てに「マクロ」を追加：キー操作・待ち時間（ms）・アプリを開く・リンクを開く を並べる
  - 設定画面で順番をドラッグで入れ替え、1 つずつ試し押しできる
  - 「ショートカットを覚えさせる」を続けて押すと、そのまま 1 行ずつ足していける
  - 実行中はタイルが光り、途中で Clear を押すと止まる
- 大きさ: 中
- 気をつける点: Logic が後ろにいるときの送り方（今の「一瞬前に出して戻す」）を、マクロの間ずっと前に出しておく形にするか決めたい。待ち時間を入れないと Logic が取りこぼすことがある。

### 2. Mix Time Machine ⇄ Reference Monitor：前のバウンスをワンクリックで参照曲にする
- 種類: 改善（MixTimeMachine と ReferenceMonitor）
- できるようになること: Mix Time Machine の履歴から「昨日のミックス」を選んで送ると、Reference Monitor の REF に入り、今 Logic で鳴っているミックスとそのまま聴き比べ・TONE/WIDTH 比較ができる。直しすぎて前のほうが良かった、にすぐ気づける。
- なぜ今: 2 つのアプリが別々に「聴き比べ」を持っていて、行き来が手作業（ファイルを探してドラッグ）。Reference Monitor にはもう外から命令を受け取る仕組み（分散通知）があるので、つなぐのは小さな変更で済む。
- 中身:
  - Mix Time Machine の各バウンスに「Reference Monitor へ」ボタン（右クリックメニューにも）
  - Reference Monitor 側で受け取り、REF メニューに「履歴: 曲名 v3（日付）」として追加・選択
  - 音量合わせはいつもどおり自動
  - Num Deck の「リファレンス」ページから「一つ前のバウンスを REF に」も押せるようにする
- 大きさ: 小〜中
- 気をつける点: ファイルは FLAC のまま渡せるか（Reference Monitor が読めるか）を確認する。アプリが起動していないときは起動してから送る。

### 3. Gain Stage（GainStage）：トラックの入口の音量をワンクリックで整える → GO 済み（2026-11-04）
- 種類: 新規
- できるようになること: トラックの最初に挿して LEARN を押して少し再生すると、音量が「ちょうどいい大きさ（-18 dBFS 前後）」になるようにゲインを自動で決める。その後ろのコンプやサチュレーター（Wool Fuzz / Porch Drive など）が、説明どおりの効き方になる。
- なぜ今: 歪み系やコンプは入ってくる音量で効き方が大きく変わる。素材ごとに音量がばらばらだと、プリセットやおすすめ設定がそのまま使えない。
- 中身:
  - LEARN（再生中の音量を数秒測ってゲインを決める）、TARGET（RMS か ピークか、目標 dB）
  - GAIN（手で直すこともできる）、POLARITY（極性反転）、MONO、L/R 入れ替え
  - 入力・出力のメーター（RMS とピーク）
  - 決めたゲインはプロジェクトに保存され、LEARN を押すまで変わらない（自動で動き続けない）
- 大きさ: 小
- 気をつける点: Fader Pilot と違い「一度決めたら固定」にする（混同しないよう README で使い分けを書く）。PLUGIN_CODE は未使用の4文字（例: Gnst）。

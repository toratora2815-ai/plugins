### 1. 全プラグイン：ビルドのたびに「Logic に読み込めるか」を自動で検査する
- 種類: 改善（全プラグイン共通。build.yml）
- できるようになること: GitHub でビルドするたびに、Logic と同じ AU の検査（auval）を GitHub の Mac で自動で通す。読み込めない・パラメーターがおかしい・発振するといった問題を、ダウンロードする前に見つけられる。
- なぜ今: 今は「コンパイルが通るか」までしか自動で確認できておらず、Logic に入れて初めて分かる問題が残る。Fader Pilot や Velvet Tamer 1.2 のように、サイドチェーンなど入出力の形が変わる変更が増えてきた。
- 中身:
  - ビルドした .component を GitHub の Mac に入れて `auval -v aufx <コード> Mypl` を実行
  - 失敗したらビルドを赤（失敗）にして、どこで落ちたかをログに残す
  - Releases の latest には、検査に通ったものだけを置く
  - 結果の要約（通った／落ちた）を Actions の画面に表示
- 大きさ: 小
- 気をつける点: GitHub の Mac で auval が見つけられるように、検査の前にプラグインを所定のフォルダに置く必要がある。ビルド時間が 1 本あたり 1 分ほど延びる。

### 2. Low Knot（LowKnot）：キックとベースのぶつかりをほどく
- 種類: 新規
- できるようになること: キックが鳴った瞬間だけ、ベースの「キックとかぶる低域」だけを少し下げる。ベース全体をサイドチェーンコンプで下げるより自然で、低域がにごらずにまとまる。キックとベースの位相（打ち消し合い）も見える。
- なぜ今: ミックスで一番もめる低域の整理を助ける道具がまだない。Velvet Tamer のサイドチェーンは中高域の「居場所を空ける」用で、低域のタイミングと位相には向かない。
- 中身:
  - ベースのトラックに挿し、サイドチェーンにキックを選ぶ
  - DEPTH / FREQ（30〜200 Hz、自動で見つける AUTO あり）/ WIDTH / ATTACK / RELEASE
  - 位相メーター（キックとベースが打ち消し合っていないか）と、ベースの極性反転・数 ms のずらし（ALIGN）
  - 低域のどこを何 dB 下げているかのグラフ
- 大きさ: 中
- 気をつける点: 遅延ゼロで作れるか、少し先読み（数 ms）を入れるかを決めたい。数値テストで、ベースの低域以外が変わらないこと・キックがないときは何もしないことを確認する。PLUGIN_CODE は未使用の4文字（例: Lknt）。

### 3. Snap Shaper（SnapShaper）：ドラムのアタックと余韻を帯域ごとに整える
- 種類: 新規
- できるようになること: スネアのアタックだけ強くする、キックの余韻（ブーン）だけ短くする、タムの胴鳴りを伸ばす、といった「音量ではなく音の形」の調整が、つまみ 2 つでできる。低域と高域で別々に効かせられる。
- なぜ今: Horizon Spread の TRANSIENT はサイド（広がり）だけに効くもので、ドラムそのものの形を変える道具がない。ドラムの打ち込み・生ドラムどちらでもよく使う。
- 中身:
  - ATTACK（-100〜+100%）/ SUSTAIN（-100〜+100%）
  - SPLIT（2 帯域に分ける周波数）と、低域・高域それぞれの ATTACK / SUSTAIN
  - CLIP（アタックを上げたときのピークをやわらかく抑える、4 倍オーバーサンプリング）
  - MIX / OUTPUT、入力と出力の波形の重ね表示
  - プリセット（キック短く / スネアはっきり / ルームを伸ばす など）
- 大きさ: 中
- 気をつける点: 音量の大小に関係なく効くようにする（エンベロープの比で判定）。アタックを上げたときのピークで音が割れないか、数値テストで確認する。PLUGIN_CODE は未使用の4文字（例: Snps）。

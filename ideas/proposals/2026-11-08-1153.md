### 1. Mod Host：つまみを手で動かした「動き」を録って、そのまま MOD にする（GESTURE）
- 種類: 改善（ModHost）
- できるようになること: 中に入れたプラグインのつまみを、再生しながらマウスで「こう動かしたい」と動かすと、その動きが 1〜8 小節のループとして記録され、MOD としてくり返し動く。LFO や STEPS では作れない、人の手のゆらぎのある動きを、オートメーションを書かずに作れる。
- なぜ今: Mod Host は LFO / ENV / SIDECHAIN / RANDOM / STEPS / LINK まであるが、どれも「形を選んで作る」もの。手で触った感じをそのまま残したい場面（フィルターをじわっと開ける、ディレイを一瞬だけ増やすなど）には向かない。テンポ同期の仕組みはもうある。
- 中身:
  - MOD の種類に GESTURE を追加。REC を押して、再生中に動かした分をテンポに合わせて記録
  - 長さ 1 / 2 / 4 / 8 小節、記録の後になめらかにする SMOOTH
  - 録った線は STEPS と同じように画面で手直しできる
  - AMOUNT / 片側（UNI）・両側（BI）は今の MOD と同じ
  - 録った動きはプリセットとプロジェクトに保存
- 大きさ: 中
- 気をつける点: 再生していないときは記録しない（位置が分からないため）。中のプラグインのつまみを Mod Host が動かしている間に手でも触るので、記録中は MOD を止めて元の値を基準にする。

### 2. Num Deck：Logic の「今の状態」をタイルに出す（再生位置・テンポ・選んでいるトラック）
- 種類: 改善（NumDeck）
- できるようになること: Num Deck の画面の上に、Logic の今の小節位置・テンポ・選んでいるトラック名・録音待機かどうかが出る。Logic を半分隠していても、テンキーで何を操作しているかが分かる。ソロやミュートのタイルは、今 ON か OFF かが色で分かる。
- なぜ今: Num Deck は毎日使う道具になり、Logic を後ろに置いて操作する場面が増えた（2 画面、HUD）。今は押した操作は分かっても、Logic が今どうなっているかは見えない。
- 中身:
  - アクセシビリティ（すでに許可済み）で Logic のコントロールバーとトラックヘッダーを読む
  - 上の帯に「小節 23.2.1 / 120 BPM / Vocal 1 / ● REC 待機」
  - ソロ・ミュート・サイクル・メトロノームのタイルは、ON のとき色付き
  - 読み取りは 0.3 秒に 1 回程度にして重くしない。Logic が後ろでも読む
- 大きさ: 中
- 気をつける点: Logic の画面の作りが版で変わると読めなくなることがある（読めないときは何も出さない）。Logic の言語（日本語・英語）で項目名が違うので両方に対応する。

### 3. Ear Rest（EarRest）：耳の疲れを「量」で知らせる、静かな見張り役
- 種類: 新規（メニューバーの小さなアプリ）
- できるようになること: その日に聴いた音の大きさと時間を、Mac の出力から測って「今日の耳の使用量」として積み上げ、メニューバーの小さな目盛りで見せる。耳が疲れた状態でミックスを決めてしまう失敗（翌日聴いたら高域が痛い、など）を減らす。
- なぜ今: ミックスの道具はそろってきたので、最後は「判断する耳」の状態が結果を左右する。Reference Monitor で Logic の音を受け取る仕組み（プロセスタップ）がすでにあり、出力の音量は測れる。
- 中身:
  - Mac から出ている音の大きさを測る（中身は録らない・保存しない）
  - 大きい音ほど速く溜まる「使用量」（目安は一般的な騒音の目安の考え方）。メニューバーに小さな目盛り
  - 一定量を超えたら 1 回だけそっと知らせる（「少し休むと判断が戻ります」）。何度も出さない
  - 1 日・1 週間の記録、時間帯ごとの平均の大きさ
  - 知らせる／知らせないの切り替え。数字だけ見る使い方もできる
- 大きさ: 小〜中
- 気をつける点: 本人は「うっとうしい」アプリを消してきたので、標準は「知らせない、見るだけ」にする。スピーカーとヘッドホンで実際の耳の大きさは違うので、あくまで目安（正確な音圧ではない）と README に書く。作る前に mix-engineer 係に必要性を確認する。

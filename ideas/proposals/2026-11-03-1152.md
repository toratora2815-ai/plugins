### 1. Balance Scope 1.1.0：参照曲の形を覚えて重ねる＋ラウドネス表示
- 種類: 改善（BalanceScope）
- できるようになること: 参考曲を一度再生して「覚える」と、その帯域バランスがグラフに重なり、自分のミックスとどこが何 dB 違うかがひと目で分かる。曲全体の音量（LUFS）とダイナミクスも同じ画面で確認できる。
- なぜ今: いまはジャンル別の決まったカーブとしか比べられない。README には VST3・Windows・スタンドアロンの記述が残っていて、AU だけの今の方針に合っていない。
- 中身:
  - CAPTURE ボタン：いまの平均を「参照カーブ」として保存（スロット3つ、プロジェクトに保存される）
  - 参照カーブとの差を表示するモード（どこが何 dB 多い／少ないか）
  - Integrated / Short-term LUFS と PLR（ピークとラウドネスの差）のメーター
  - 目標カーブの傾きを自分で決められる CUSTOM（Targets.h を書き換えなくてよくなる）
  - README を AU 専用に整理
- 大きさ: 小〜中
- 気をつける点: 音は通すだけのまま変えない。LUFS は ITU-R BS.1770 の計算どおりかテスト信号で確認する。

### 2. Fader Pilot（FaderPilot）：ボーカルの音量を自動でフェーダーを動かして揃える
- 種類: 新規（最初の案「Knit Bus（バスコンプ）」から差し替え。バスコンプは手持ちで足りるため）
- できるようになること: 声の大きさのばらつきを、コンプのように潰さずに、細かくフェーダーを上げ下げして揃える。動かした量は Logic のオートメーションに書き込めるので、あとから手で直せる。オケ（サイドチェーン）を基準に「埋もれない音量」に合わせるモードもある。
- なぜ今: 手でボーカルのオートメーションを書くのは時間がかかる。コンプと違って音色を変えずに音量だけ整える道具がまだない。
- 中身:
  - TARGET（揃えたい音量）/ RANGE（動かす最大量）/ SPEED（動きの速さ）/ FLOOR（これより小さい音＝息や無音は持ち上げない）
  - AUTO RIDE：ON で自動、OFF で「RIDE」パラメーター（オートメーション）の値をそのまま使う
  - FOLLOW MUSIC：サイドチェーンのオケの音量 ＋ OFFSET を目標にする
  - 入力・出力・動かした量の流れるグラフと、今のフェーダー位置
  - 内蔵プリセット
- 大きさ: 中
- 気をつける点: 実在製品の名前・見た目は使わない。息や無音を持ち上げすぎないか、目標に収束して発振しないかを数値テストで確認。PLUGIN_CODE は未使用の4文字（Fdpl）。

### 3. Velvet Tamer 1.2.0：軽い「録り用」モードと外部サイドチェーン
- 種類: 改善（VelvetTamer）
- できるようになること: 遅延 2048 サンプルが気になる録音中や演奏中でも、遅延の少ないモードでそのまま挿しておける。ボーカルの音でギターやシンセの同じ帯域だけを下げる「場所を空ける」使い方もできる。
- なぜ今: 今の遅延は 48k で約 43ms あり、モニター中に挿すとずれて聞こえる。帯域のかぶりを避ける機能は、自動で音を下げる仕組みがある Velvet Tamer に足すのが一番手間が少ない。
- 中身:
  - QUALITY：HIGH（今のまま 2048）/ LOW LATENCY（512）の切り替え
  - SIDECHAIN：Logic のサイドチェーン入力の音で「どこを下げるか」を決めるモード
  - グラフにサイドチェーンの音のスペクトルを重ねて表示
  - 既存のパラメーター ID と音は変えない（HIGH のときは今と同じ結果）
- 大きさ: 中
- 気をつける点: 切り替えたときに Logic へ遅延の変化をきちんと伝える（ズレないか確認）。LOW LATENCY は周波数の細かさが落ちるので、効き方の違いを README に書く。

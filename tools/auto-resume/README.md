# auto-resume … 使用制限で止まった作業を、制限が解除されたら自動で続ける

2026-11-12 本人の指示「今実行中のプラグイン作りとかは、制限が来たら、制限が解除された時に自動的に続きをやるようにしてください」で作ったもの。

## 何をするか
Claude の使用制限（5 時間・1 週間）で止まったセッションを、制限が解除されたら自動で起こして、続きをやらせます。

止まり方は 2 通りあります。
1. 「もうすぐ制限」の合図を受けて、区切りよく止めた（「上限に達したので、ここでいったん止めます」と書いて終わる）
   → Claude のアプリはこちらを自動では続けてくれないので、これが起こします
2. 制限で途中で切れた（「You've hit your 5-hour limit · resets 3:30am」と出る）
   → まず Claude のアプリ自身の自動再開に任せます。解除から 2 分半たっても動いていなければ、これが起こします

- 待っている間に自分で話しかけたセッションは、起こしません
- 待つのが 6 時間以内のときは、待っている間 Mac がスリープしないようにします（ふたを閉じると眠ります。そのときは、開いたあとに起こします）
- 制限と関係なく終わったセッションには、何もしません
- 起こされたセッションは、本人に決めてもらうことが出てきたら、そこで止まって聞きます

## 入れ方（1 回だけ）
ターミナルで、次の 2 行を 1 行ずつ実行します。
```
cd ~/plugins
bash tools/auto-resume/install.sh
```
`~/.claude/settings.json`（Claude Code の設定）に「止まったときにこれを動かす」という登録（フック）を足します。元の設定は `~/.claude/settings.json.backup-auto-resume` に残ります。
新しく開いたセッションから確実に効きます（いま開いているセッションは、アプリを開き直すと効きます）。

## 様子を見る
```
cat ~/.claude/auto-resume/log.txt
```
「制限エラーで停止 → 11/12 03:32 に起こします」「起こしました」「起こさずに終了（セッションがもう動き出した）」のように書かれます。

## 外す
```
cd ~/plugins
bash tools/auto-resume/uninstall.sh
```

## 注意
- Claude のアプリを閉じている間は動きません（待っている分も消えます）
- 解除と同時に、止まっていたセッションが一斉に動き出すので、次の 5 時間の枠も早めに使い切ることがあります
- 解除の時刻がわからないとき（区切りよく止めたのに、ほかのセッションに時刻が出ていない）は、15 分後にいったん起こします。まだ制限中ならすぐ止まって、正しい時刻にまた起こされます（制限中に断られた分は、利用枠を使いません）

## しくみ（Claude 用のメモ）
- Claude Code のフック（Stop と StopFailure、`asyncRewake: true`、`timeout` 7 日）。本体は `auto_resume.py`（`~/.claude/auto-resume/` にコピーして使う。直したら install.sh で入れ直す）
- 起こすときは本体が終了コード 75 → フックの命令が 2 に読み替える（python 自体の失敗で誤って起こさない。本体がなければ何もしない）
- Stop: いまのターンに `[Usage limit reached; …]`（isMeta の user 行、30 分以内）があれば対象。解除の時刻は、5.5 時間以内に書かれたほかの記録の `rate_limit` エラー文から
- StopFailure: `error` が `rate_limit`。時刻はエラー文「resets 3:30am (Asia/Tokyo)」から。アプリの自動再開（解除＋90 秒＋数秒、5 時間の制限で途中で切れたものの一部だけ）に先を譲るため、解除＋150 秒まで待つ
- 同じ止まり方で 2 回起こさない（`~/.claude/auto-resume/state/<セッション>.json`）。同じセッションで新しい止まり方が来たら、前の待ちを止めて引き継ぐ
- 待っている間に、そのセッションの記録に新しい返事や発言が書かれたら、起こさずに終わる。セッションが閉じられたときも終わる
- 動作確認: `echo "<セッションの ID> 20" > ~/.claude/auto-resume/selftest` → そのセッションのターンが終わると 20 秒後に起こされる
- テスト: `/usr/bin/python3 -I tools/auto-resume/test_auto_resume.py`（作り物の記録で、待ち時間を短くして通しで確かめる）
